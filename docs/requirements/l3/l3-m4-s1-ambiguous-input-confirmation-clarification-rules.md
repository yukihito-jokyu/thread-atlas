## 共通条件

明確化は、何を対象にし、何を意図し、どの判断結果または更新を求めるかを一意に確認できるユーザーの明示回答とする。確認要求の文面、曖昧性の判定閾値・アルゴリズム、Prompt、入力検出およびUIはL8が所有する。

本書は、曖昧な入力から確定更新を行わないための権限境界を定める。ユーザー明示訂正の優先・適用範囲は`L3-M4-S2`、状態・遷移・不変条件はL2、提案判断はL3-M2、理解停止の成立・維持・解除はL3-M3が所有する。

## Task固有Review

- [x] 対象・意図・判断結果が複数解釈可能な入力で確定更新を保留した。
- [x] 一意なユーザー明示回答まで未解消を維持し、明確化後だけL2の許可経路へ引き渡した。
- [x] 曖昧な提案回答を3判断成立にせず、未承認提案のまま維持した。
- [x] 要確認と理解停止を混同せず、曖昧入力で理解停止Guardを解除していない。
- [x] 表示、判定方式、Prompt、UI、履歴・保存方式を定義していない。
