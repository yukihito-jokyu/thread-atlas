# L3-M3-S3: 理解停止Guardの明示解除と通常進行復帰

## 解除・復帰表

| Rule ID | 解除の起点 | 成立条件 | 解除後の効果 | 禁止・委譲 |
| --- | --- | --- | --- | --- |
| `L3-M3-S3-R-01` | ユーザーが対象文脈について理解できたことを明示する。 | `L3-M3-S1`で成立し、`L3-M3-S2`で維持されている理解停止Guardについて、対象の現在論点と通知時点の文脈を一意に確認できる。 | 理解停止Guardだけを解除し、停止前と同じ現在論点・文脈を確認してL2が許可する通常進行へ引き渡す。 | AIの推定、沈黙、時間経過、再説明の成功推定、通常質問または同じ通知の反復では解除しない。正式遷移・現在地変更はL2が所有する。 |

| `L3-M3-S3-R-03` | 曖昧または競合する解除・再開入力を受ける。 | 対象文脈、理解の解消または再開意思を一意に確認できない。 | 理解停止Guardを維持する。 | 解釈して解除せず、`L3-M4-S1`の要確認・明確化規則へ委譲する。明確化だけから進行・確定更新を行わない。 |

## 同一文脈への復帰

解除後に確認する同一文脈は、対象の現在論点、ルートからの経路、背景、決めたいこと、完了条件、既知の残り論点および復帰先とする。これらを確認した後、`L1-M1-S2`が所有する通常進行Anchorへ引き渡す。

この引渡しは理解停止Guardを外す出口契約だけを定める。通常進行で次に提示する質問、進行開始、現在地変更、決定更新、正常完了および親復帰は、L2の許可条件と各Ownerに従う。解除を理由に他のGuard、要確認、提案判断、保留または対象外を同時に解除・変更しない。

## 責務境界とTask固有Review

- `L3-M3-S1`は成立と対象文脈、`L3-M3-S2`は維持中のAI許可・禁止、`L3-M3-S3`は明示解除と同一文脈への引渡しを所有する。
- 理解停止は永続状態にしない。正式な状態・遷移・現在地はL2、解除・Guardの履歴はL4、表示はL5、操作/APIはL6、評価はL7、入力検出・UI・説明生成方式はL8が所有する。
- [x] ユーザーによる理解または再開意思の明示だけを解除起点にした。
- [x] AI推定、沈黙、時間経過、説明成功推定、通常質問による暗黙解除を禁止した。
- [x] 解除後は同じ現在論点・文脈を確認して通常進行Anchorへ引き渡し、L2の許可条件を迂回しない。
- [x] 他Guardを同時解除せず、曖昧・競合入力を`L3-M4-S1`へ委譲した。
- [x] 新しい永続状態、履歴・表示・入力検出方式を定義していない。
