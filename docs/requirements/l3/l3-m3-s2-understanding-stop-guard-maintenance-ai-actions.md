# L3-M3-S2: 理解未解消中のGuard維持とAI動作

## 維持条件

`L3-M3-S1`で成立した理解停止Guardは、対象の現在論点と通知時点の文脈を維持し、ユーザーが`L3-M3-S3`で定める明示解除を行うまで有効とする。AIの再説明、時間経過、沈黙、推測または通常の質問は解除を導かない。

## AIの許可・禁止

| 区分 | 動作 | 範囲・制約 |
| --- | --- | --- |
| 許可 | 背景、派生元、決めたいことを再説明する。 | 対象の現在論点・文脈に限る。具体的な生成方式はL8が所有する。 |
| 許可 | 補足を示し、理解できたかを確認する。 | 理解支援だけで解除、決定または進行を確定しない。 |
| 禁止 | 通常質問で議論を前進させる。 | 次の論点開始、別論点への移動を含む。 |
| 禁止 | 現在地を変更し、論点を正常完了し、決定またはその他の確定更新を行う。 | L2の遷移、L3の権限、L4の履歴を迂回しない。 |
| 禁止 | 曖昧または競合する入力を、Guard解除、進行または確定更新として扱う。 | 理解停止Guardを維持し、L3-M4-S1の要確認・明確化規則へ委譲する。明確化だけから進行・確定更新を行わない。 |

## 責務境界とTask固有Review

- 成立・対象文脈はL3-M3-S1、明示解除と同一文脈からの通常進行復帰はL3-M3-S3が所有する。
- 理解停止を永続状態にせず、状態・遷移・現在地はL2、GuardをEvent・履歴として記録するかを含む保存モデルはL4、表示はL5、操作/APIはL6、評価はL7、入力検出・UI・説明生成はL8が所有する。
- [x] 未解消中をユーザー明示解除まで維持し、AIによる暗黙解除を禁止した。
- [x] 理解支援を許可し、議論進行・現在地変更・正常完了・確定更新を禁止した。
