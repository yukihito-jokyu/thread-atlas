# L3-M4-S2: ユーザー明示訂正の優先・適用境界

## 訂正優先・適用表

| Rule ID | 受入対象 | 優先・適用規則 | 適用不能時 | 非導出事項・引渡し |
| --- | --- | --- | --- | --- |
| `L3-M4-S2-R-01` | 対象と訂正内容を一意に示すユーザー明示訂正 | 同じ対象についてAIの推定またはAI生成内容と異なる場合、ユーザー訂正を優先する。適用は明示された対象・内容の範囲だけに限る。 | 訂正内容が曖昧または競合する場合は、確定更新せず`L3-M4-S1`の確認・明確化へ戻す。 | AI推定を正として訂正を無視せず、明示範囲外の状態・決定・構造・現在地を変更しない。 |
| `L3-M4-S2-R-02` | 一意な訂正で、L2に適用可能な許可経路がある場合 | L2の許可遷移・Guard・不変条件を満たす経路へ訂正要求を引き渡す。訂正はL2の許可範囲を広げない。 | L2上の適用経路がない場合は確定更新せず、適用不能理由、代替の許可経路および必要な追加確認を明確化するため`L3-M4-S1`へ戻す。確認後も該当するL2個別経路を満たすまで確定効果を生じさせない。 | 訂正を理由に状態を直接設定し、親子関係・現在地・正常完了・復帰先を迂回変更しない。 |
| `L3-M4-S2-R-03` | 訂正に見えるが、意図的な提案判断の変更または通常論点の状態変更である要求 | 誤認訂正と意図的な意思決定変更を区別し、本書の訂正適用として確定しない。 | 対象・意図が曖昧なら`L3-M4-S1`へ戻す。 | 提案判断の変更は`L3-M2-S3`、通常論点の変更におけるActor・承認は`L3-M1`、状態・遷移・不変条件はL2へ引き渡す。 |

## 共通境界

訂正は履歴削除、暗黙の巻戻し、Undoまたは過去内容の推測置換を意味しない。履歴・Undo・保存はL4、表示はL5、操作/APIはL6、評価はL7、訂正検出・曖昧性判定・Prompt・UIはL8が所有する。

理解停止Guardの成立・維持・解除はL3-M3が所有する。訂正入力だけで理解停止Guardを成立・解除せず、理解停止中の進行効果を持つ更新はL2およびL3-M3のGuardを迂回しない。

## Task固有Review

- [x] 一意なユーザー明示訂正をAI推定・AI生成内容より優先し、明示範囲だけを対象にした。
- [x] 曖昧・競合・L2上の適用経路なしでは確定更新せず、S1の確認・明確化へ戻した。
- [x] 訂正を理由にL2の許可遷移・Guard・不変条件を迂回していない。
- [x] 意図的な提案判断変更と通常論点の状態変更をそれぞれのOwnerへ引き渡した。
- [x] 履歴削除、暗黙巻戻し、Undo、入力検出・UI方式を定義していない。
