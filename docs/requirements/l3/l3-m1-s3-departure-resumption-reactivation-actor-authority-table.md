# L3-M1-S3: 離脱・再開・再活性化系のActor割当表

## 目的

L2で許可された保留・中断・再開・対象外化／再対象化・決定済み再開を、L3-M1-S1の4権限区分へ重複なく割り当てる。これらは通常完了と異なる利用者の意図を伴うため、AIが意図を推測して確定実行しないことを明確にする。

## 共通前提

- 対象はL2-M4-S2の保留・中断・再訪・復元後再開と、L2-M4-S3の通常論点に対する対象外化・再対象化・決定済み論点の訂正である。提案の登録・3判断はL3-M2、要確認・理解停止・訂正の例外規則はL3-M1-S4、L3-M3、L3-M4が所有する。
- 各行はL2の起点、状態組合せ、構造・完了条件、禁止条件を先に満たす。状態を伴わない現在地変更は、保留解除、中断、再訪または復元後再開という元操作に従属し、独立したActor権限を新設しない。
- AIは候補、根拠または選択肢を提示できるが、利用者の離脱・再開・再活性化の意図を無応答、過去の選択または復元事実から推測して確定しない。ユーザー直接実行はその明示操作自体を確認とする。
- 本表の「取消／訂正Owner」は取消権を新設しない。詳細な訂正はL3-M4-S2、履歴・UndoはL4-M4へ引き渡す。

## 禁止・未割当

L2-M4-S4が禁止する不正組合せ、対象外・保留からの無条件再開、未承認提案の論点化、理解停止中の進行、および復元を根拠にした状態補正は`Actor制御対象外`であり、実行Actor・承認Actorを割り当てない。上表にない離脱・再開・再活性化をAIが自動で確定してはならず、候補提示は確定更新ではない。

## 責務境界とReview

- 本表は保留・中断・再開・対象外化／再対象化のActor割当と、決定済み再開のActor区分だけを所有する。状態・現在地・復帰先の意味と遷移可否はL2、提案判断はL3-M2、理解停止はL3-M3、決定訂正のTrigger・根拠・優先・適用可否はL3-M4が所有する。
- Entity・履歴・Undo・保存・復元はL4/L8、表示はL5、論理操作・APIはL6、受入・測定はL7が所有する。
- [x] 保留設定・解除、中断・再訪、セッション再開、対象外化・再対象化、決定済み再開を4権限区分へ割り当てた。
- [x] 状態を伴わない現在地変更を元操作に従属させ、独立したActor権限を追加していない。
- [x] 実行Actor、承認Actor、取消／訂正Owner、詳細Owner、根拠IDを全行に記載した。
- [x] L2の禁止・条件成立GuardへActor権限を付与せず、未割当のAI自動確定を禁止した。
