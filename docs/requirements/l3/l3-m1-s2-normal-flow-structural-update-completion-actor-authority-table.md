# L3-M1-S2: 通常進行・構造更新・正常完了系のActor割当表

## 目的

L2で許可された通常進行、FR-008の構造更新、完了条件、決定更新および正常完了系を、L3-M1-S1の4権限区分へ重複なく割り当てる。L2の遷移可否・Guard内容を変更せず、各行の実行Actor、承認Actor、取消／訂正Ownerおよび詳細Ownerを明確にする。

## 共通前提

- 対象はL2-M4-S1の基本遷移、L2-M2の完了条件規則、L2-M3-S1〜S2の構造・親復帰不変条件、およびFR-008の構造更新である。
- 各行はL2の起点・Guard・禁止条件を先に満たす。AI自動可でもFR-014の更新後の可視化・確認可能性を免除しない。
- 本表の「取消／訂正Owner」は取消権を新設しない。訂正・再判断・Undoの詳細はL3-M4、L3-M2-S3、L4-M4へ引き渡す。

## 禁止・未割当

L2-M4-S4が禁止する不正組合せ、未充足の正常完了、到達不能な構造更新は`Actor制御対象外`であり、実行Actor・承認Actorを割り当てない。上表にない通常更新をAIが自動で確定してはならず、候補提示は確定更新ではない。

## 責務境界とReview

- 保留・中断・再開・対象外・決定済み再開はL3-M1-S3、提案・理解停止・要確認・訂正・UndoはL3-M1-S4が所有する。
- Actor詳細はL3-M2〜M4、履歴・UndoはL4、表示はL5、論理操作・APIはL6、受入はL7、実装はL8が所有する。
