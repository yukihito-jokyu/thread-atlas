# L5-M1-S1: 親子階層・ルート経路・現在地の識別条件

## 目的

任意深度の議論構造で、ルート、親子、同階層、ルートから現在地までの上位経路および論理上の現在地を、具体的な図法・配置・表示フォーカスに依存せず相互に識別できる条件を定める。

## 識別条件表

| 識別対象 | 確認できる条件 | 同時に区別する対象 | 導かないこと |
| --- | --- | --- | --- |
| ルート | 同一議論構造の起点であり、親を持たない論点として確認できる。各議論構造のルートは一つだけである。 | 非ルート論点、別の議論構造のルート。 | ルートを現在地、完了、復帰先、表示フォーカスとして扱うこと。 |
| 親子階層 | 非ルート論点について、同一ルートに属する既存の親を一つだけ確認できる。親は複数の子を持ち得る。 | 派生元、会話上の由来、表示上の近接、決定・提案の関係。 | 親子関係だけから派生、状態、現在地、復帰先またはスコープ所属を導くこと。 |
| 同階層 | 同じ親を持つ複数の子論点を、互いに親子でも祖先・子孫でもない論点として確認できる。 | 別枝、別ルート、派生Relationで結ばれる論点。 | 同階層であることから順序、優先、次に扱う論点、完了または現在地変更を導くこと。 |
| 上位経路 | 任意深度の論点から親子関係を逆向きに一意にたどり、同一ルートまでの全祖先列を確認できる。現在地では、その列をルートから現在地までの経路として確認できる。 | 派生経路、会話の時系列、変更因果、表示上の展開経路。 | 表示の省略・非フォーカス枝の非表示を根拠に、上位接続または親子正本を失わせること。 |
| 論理上の現在地 | 通常進行中は、同一Session内で一つだけの既存論点を現在地として確認でき、その論点のルート経路を確認できる。通常進行しない時点には現在地が0件であることを確認できる。 | 表示フォーカス、選択対象、会話参照、復帰先。 | 現在地の表示方法、状態変更、親復帰、完了、次論点開始を決めること。 |
| 非フォーカス枝を含む上位接続 | 現在地の祖先列と、各祖先の親子関係を確認できる限り、現在地以外の枝が表示対象でない場合でも現在地の上位接続を失わない。 | 全体表示の有無、展開済みの兄弟、表示対象の選択。 | 非フォーカス枝を常時表示すること、全体／フォーカスの切替、具体的なレイアウトを決めること。 |

## 整合条件

- 親子階層と上位経路は、単一ルート、親の一意性、循環・孤立禁止および任意深度の到達可能性について L2-M3-S1 の不変条件を満たす。
- 現在地は通常進行時だけ一意であり、通常進行しない時点の0件を表示上の欠落として補完しない。現在地の設定・移動・復帰は L2-M4 の許可された経路だけが行う。
- 親子Relationと派生Relationは別である。派生元を親、または表示上近接する論点を同階層・上位論点として推測しない。
- 議論マップは論点と親子・派生Relationから導出するProjectionである。表示上の枝、位置、選択、並びまたは省略だけから親子・現在地を更新しない。
- 現在地が親を持つ論点で正常完了し、直後に通常進行を継続する場合の直接親への復帰、ならびにルート完了後に親・復帰先・新たな現在地を生成しない条件は L2-M3-S2 を参照する。本書はその遷移を実行しない。

## 責務境界

- 論理上の現在地と表示フォーカス、選択対象、会話参照との対応、および全体／フォーカス別の情報配分は L5-M5 が所有する。
- 状態語彙・状態組合せ・完了可否は L2-M1〜M2、階層・現在地・復帰先の構造不変条件は L2-M3、遷移・Guardは L2-M4、Actor・承認は L3 が所有する。
- 論点、親子・派生Relation、Session所属、現在地の正本、履歴および復元は L4 が所有する。本書はEntity、Cardinality、保存・復元方式を定義しない。
- 提案・スコープ・決定の意味上の識別は L5-M3、現在論点の背景・目的・完了条件・復帰先の提示は L5-M2、残り論点は L5-M1-S3 が所有する。
- 図法、色、座標、展開・切替操作、コンポーネント、レスポンシブ方式、Projection実装は L8、操作・APIは L6、受入・測定は L7 が所有する。
