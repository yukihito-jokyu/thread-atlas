# L5-M1-S3: 既知の残り論点・残り程度・構造上の要確認範囲の識別要件

## 目的

議論構造全体について、既知の残り論点をどの根拠で含め、又は現在の残り集合から分けるかを識別する。残り程度は既知の情報に基づく概算として扱い、構造上まだ確定できない範囲を完了済み又は存在しないものとして扱わない。

## 残り集合の包含・除外根拠

| 識別対象 | 既知の残り集合との関係 | 確認できる根拠 | 無言で導出・除外しないこと |
| --- | --- | --- | --- |
| 現スコープ内の未完了通常Topic | 含める。未着手、議論中、保留又は進行値が未設定であっても、未完了として確認できる既存通常Topicを既知の残り論点として確認する。 | 通常Topicであり、L2-M1-S3 の有効組合せを満たし、完了済みではないこと。 | 決定済みだけから除外しない。進行値が未設定であることを完了又は対象外へ補完しない。 |
| 保留中の通常Topic | 含める。現時点で通常進行しない扱いであっても、残り集合から分けずに確認する。 | 既存通常Topicが現スコープ内で、保留という進行上の扱いと未完了を確認できること。 | 保留を中断、完了、対象外又は不要と同一視して除外しない。再開可否・優先度を決めない。 |
| 要確認を伴う通常Topic | 含める。要確認は残りの不確定さを示す情報として併記する。 | 既存通常Topicの未完了と、要確認という確認軸の値を別情報として確認できること。 | 要確認を理解停止、完了、除外又は次に扱う優先順位として扱わない。 |
| 完了済み通常Topic | 現在の既知の残り集合には含めない。ただし同一構造内の完了済み論点として区別して確認する。 | L2 の完了・正常完了に関する確定済みの結果と、L2-M3 の構造不変条件。 | 決定済みだけから完了済みと扱わない。除外を根拠に親子・由来・履歴を失わせない。 |
| 対象外の通常Topic | 現スコープ内の既知の残り集合には含めないが、対象外という除外根拠を確認できるようにする。 | L2-M1-S3 に従う対象外の有効な扱いと、通常Topicであること。 | 対象外を却下、削除、完了又は将来も永続的に不要と扱わない。再対象化や通常進行開始を導かない。 |
| 未承認Proposal | 通常Topicから成る既知の残り集合には含めない。候補として存在することと、現スコープとの差異は別に確認する。 | 未承認Proposalであり、L2-M1-S3 が禁止する通常Topic・現在地・決定済みへの暗黙昇格をしていないこと。 | 未承認であることを不存在、却下又は対象外と推測しない。理由、三判断及び論点化は L5-M3 が扱う。 |
| 新たに論点化された通常Topic | L2 の許可経路により既存通常Topicとなり、現スコープ内かつ未完了であれば、その時点から含める。 | Proposalからの論点化に必要な承認・構造・完了条件の条件と、L2-M4 の許可された効果。 | Proposalの登録、再判断又は表示上の存在だけから自動で含めない。親子、現在地、復帰先又は優先度を本書から決めない。 |

## 残り程度と構造上の要確認範囲

| 識別する情報 | 確認できる条件 | 導かないこと |
| --- | --- | --- |
| 既知の残り程度 | 前表に含まれる既知の残り論点と、その未完了・保留・要確認等の別情報を根拠に、残り程度を概算として確認できる。 | 件数の算出方式、工数・期限・進捗率、優先順位又は完了予測を定めない。 |
| 構造上の未確定範囲 | 未完了論点の下位にまだ確認されていない論点があり得ること、進行・決定・確認・完了条件の未設定又は判断不能があることを、既知の残り集合と区別して確認できる。 | 未確認の下位論点を実在する通常Topicとして生成しない。未知範囲をゼロ、完了、対象外又は解消済みと推測しない。 |
| 現在論点内の未確認事項 | 現在論点に属する未確認事項は、残り程度の不確定さに影響し得ることを確認できる。 | その内容・解消条件・提示を本書で定義しない。これは L5-M2-S3 が所有する。 |
| 新規追加の反映 | 新たな通常Topicが許可された経路で構造へ加わった後、前表の包含条件を満たせば既知の残り集合へ反映する。 | AI発見、Proposal登録、会話上の言及又は未承認の三判断だけから、残り集合を自動変更しない。 |
| 既知集合の限界 | 既知の残り集合に含まれない構造上の未知範囲があり得るため、集合だけから議論全体の完了性を保証しない。 | 未知範囲を補完する推測、残りがないとの断定、正常完了、親復帰又は次論点開始を導かない。 |

## 整合条件

- 残り集合は、L5-M1-S1 が識別する単一ルート、親子、上位経路及び論理上の現在地を参照するが、階層、現在地又は復帰先を変更しない。
- 7語彙、軸内排他、軸間の有効／不正組合せ、完了・正常完了可能性は L2-M1〜M2 の正本に従う。未設定、判断不能又は要確認を否定値へ補完しない。
- 保留・要確認を現在の残り集合から無言で外さず、対象外・完了済み・未承認Proposalは、それぞれ異なる除外又は別管理の根拠とともに区別する。
- 残り集合への追加・除外は状態遷移、Actor・承認、提案の三判断又は構造更新を実行しない。許可・更新の根拠は L2〜L4 が所有する。

## 責務境界

- 現在論点内の未確認事項、その内容、解消条件及び復帰先の提示は L5-M2-S3、新規提案の理由・由来・三判断・スコープ差異の意味上の識別は L5-M3 が所有する。
- 状態語彙・組合せは L2-M1、完了条件・充足・正常完了可否は L2-M2、階層・現在地・復帰先の不変条件は L2-M3、遷移・Guard は L2-M4、Actor・承認は L3 が所有する。
- Topic、Proposal、Decision、Relation、現行正本、履歴及び復元は L4 が所有する。本書はEntity、Cardinality、保存・復元方式を定義しない。
- 残り程度の見積アルゴリズム、件数表現、進捗部品、具体的な表示順・図法・装飾・配置は L6／L8、受入・測定は L7、全体／フォーカス別の情報配分は L5-M5 が所有する。
