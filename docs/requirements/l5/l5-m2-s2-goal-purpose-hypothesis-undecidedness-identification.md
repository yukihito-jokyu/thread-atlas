# L5-M2-S2: 決めたいこと・現在目的・検討中仮説・未決定性の識別要件

## 目的

現在論点について、何を決めたいか、上位目的へどう寄与したいか、どの暫定方向性を検討しているか、何が未決定かを別の情報として確認できる条件を定める。仮説を目的、Proposal、Decision又は決定済み状態へ暗黙に変換しない。

## 識別条件

| 識別する情報 | 現在論点との対応を確認できる条件 | 相互に区別する対象 | 導かないこと |
| --- | --- | --- | --- |
| 決めたいこと | 現在論点で解決又は選択の対象としている問いを、背景、上位目的及び根拠会話と区別して確認できる。 | 現在目的、検討中仮説、Decision、完了条件、未確認事項。 | 問いだけから回答、Decision、決定済み、通常進行の開始又は完了を導かない。 |
| 現在目的 | 現在論点を扱うことが上位目的へ寄与する意味を、現在のスコープ及び背景との関係として確認できる。 | 上位目的、決めたいこと、議論理由、Proposalの目的関連、Decision。 | 現在目的だけからスコープ変更、優先順位、Proposal承認又は通常Topic化を導かない。 |
| 検討中仮説 | 現在論点の問いに対する暫定方向性又は比較対象を、根拠会話又は既存の論理情報との関係で確認できる。仮説は導出提示概念であり、新たなEntityを作らない。 | 現在目的、未承認Proposal、Decision、決定済み、完了条件。 | 仮説だけから確定、承認、Decision記録、決定済み化、現スコープ内化又は論点化を導かない。 |
| 未決定性 | 現在論点の問い又は検討中仮説について、Decisionとして確定していない論点又は比較が残ることを、その根拠会話又は既存情報との関係で確認できる。 | 未確認事項、要確認、保留、中断、理解停止、完了可否。 | 未決定性だけから状態遷移、未確認事項の生成、要確認化、保留、中断、正常完了不可又は通常進行停止を導かない。 |
| 根拠会話・既存情報 | 問い、現在目的、仮説又は未決定性の根拠となる発言、ターン、既存Topic・Decision等との関係を確認できる。 | 会話の時系列、表示上の近接、親子・派生Relation、Decision又はProposalの正本。 | 表示された会話、近接又は欠落から問い、目的、仮説又は未決定性を推測補完しない。 |

## 関係の整合条件

- 決めたいこと、現在目的、検討中仮説及び未決定性は、同一の現在論点に対応する別情報として確認できる。一方の不在又は未設定を、他方から補完しない。
- 現在目的は上位目的への寄与を確認する情報であり、現在論点で何を決めるかを示す決めたいこととは同一にしない。上位目的そのもの及び議論理由は L5-M2-S1 の条件に従う。
- 仮説は問いを検討するための暫定方向性に留める。Proposalの由来・理由・三判断、Decisionの現行正本、決定済み状態及び通常Topicへの論点化を仮説から導かない。
- 未決定性はDecision未確定の確認に留め、完了条件の充足／未充足／判断不能、現在論点内の未確認事項及び復帰先を置き換えない。これらは L5-M2-S3 と L2 の正本に従って別に確認する。
- 通常進行中の一意な現在地、又は通常進行しない時点に現在地が0件である条件は L2-M3 と L5-M1-S1 を参照する。本書は現在地を設定、移動又は復帰しない。

## 責務境界

- 背景、派生元、上位目的、議論理由は L5-M2-S1、完了条件、充足状況、未確認事項、復帰先は L5-M2-S3 が所有する。
- Decision、決定済み状態、通常Topic、未承認Proposal、三判断、スコープ差異及びProposal固有の理由は L5-M3 が所有する。
- 状態語彙・有効組合せ・完了可否・階層及び現在地不変条件・遷移とGuardは L2、Actor・承認・理解停止Guardは L3、Topic・Proposal・Decision・会話・Relation・現行正本・履歴・復元は L4 が所有する。
- 情報の生成・更新・再説明・操作・APIは L6、仮説の導出方式、文面、引用、配置、展開、図法及びコンポーネントは L8、受入・測定は L7 が所有する。本書はEntity、Cardinality、状態、表示又は操作方式を定義しない。
