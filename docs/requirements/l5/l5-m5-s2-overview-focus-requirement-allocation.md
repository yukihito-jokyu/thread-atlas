# L5-M5-S2: 全体／フォーカス別の必須情報と省略可能範囲

## 目的

L5-M1〜M4が定めた提示Requirementを、全体把握とフォーカスのどちらで常時識別し、同時に確認でき、要求時に参照でき、省略可能とするかを割り当てる。ここでの配分は情報の提示契約であり、表示領域、配置又は展開操作を定めない。

## 配分区分

| 区分 | 意味 |
| --- | --- |
| 常時識別 | 当該ビューを見れば、情報そのもの又はその値を常に他と区別して認識できる。 |
| 同時確認可能 | 同じ表示文脈で、他の指定情報との対応関係を確認できる。具体的な同時表示の配置は定めない。 |
| 要求時参照 | 常時展開を要求しないが、情報の存在と参照可能性を認識でき、利用者の要求に応じて確認できる。 |
| 省略可 | 当該ビューでは常時識別又は要求時参照を要求しない。ただし、情報の正本を失わせず、別の区分又はビューでの確認可能性を妨げない。 |

## 配分の整合条件

- フォーカスでは、論理的現在地、ルート経路、上位目的、背景、完了条件及び復帰先を、他の情報を省略しても同一表示文脈で確認できる。
- 全体把握では、全論点の文脈・履歴・根拠会話を常時展開することを要求しない。ただし、前表で常時識別又は同時確認可能とした情報を、詳細の省略だけで失わせない。
- 要求時参照又は省略可の情報は、論理情報、状態、判断、現在地、構造、履歴又は正本の欠落を意味しない。存在しない理由、未記録の理由又は内容を表示近接・時系列・AI推測で補完しない。
- 全体／フォーカスの配分は、表示フォーカス又は選択対象を定めず、論理的現在地を変更しない。表示文脈との対応はL5-M5-S3、切替前後の不変条件はS4が所有する。

## 責務境界

- L5-M1〜M4は各情報の意味・識別条件を所有し、本書はそれらのビュー別配分だけを所有する。表現方式の適用条件とMVP複数図法非必須境界はL5-M5-S1が所有する。
- 状態・完了・階層・現在地・復帰先及び遷移はL2、Actor・承認・GuardはL3、Entity・Relation・正本・履歴・UndoはL4、検索・参照・操作能力はL6が所有する。
- 表示領域、並び、サイズ、色、展開部品、具体的な同時表示、図法、配置及び実装方式はL8、受入・測定はL7が所有する。
