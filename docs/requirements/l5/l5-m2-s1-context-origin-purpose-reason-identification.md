# L5-M2-S1: 背景・派生元・上位目的・議論理由の文脈提示要件

## 目的

現在論点について、どの文脈から生まれ、どの上位目的のため、なぜ今扱うかを意味上たどれる条件を定める。背景、派生元、上位目的及び議論理由は別の情報として扱い、同一の現在論点へ対応付ける。

## 文脈の識別条件

| 識別する情報 | 現在論点との対応を確認できる条件 | 相互に区別する対象 | 導かないこと |
| --- | --- | --- | --- |
| 背景 | 現在論点で検討を始める前提となる既知の状況、会話又は関連する既存論理情報を確認できる。 | 派生元、上位目的、現在目的、決めたいこと、完了条件、Decision。 | 背景だけから提案承認、状態、決定、通常進行又は完了を導かない。 |
| 派生元 | 現在論点が別のTopic、Proposal又は会話上の契機から派生した場合、その由来Relation又は起点情報を意味上たどれる。派生元がある場合も、親と同一である必要はない。 | 親、祖先、復帰先、表示上の近接、会話順序。 | 派生元を親子Relation、現在地、復帰先又は通常進行順に補完しない。 |
| 上位目的 | 現在論点が属するルート又は祖先の目的との関係を、親子の上位経路を通じて確認できる。 | 現在目的、議論理由、仮説、Decision、完了条件。 | 上位目的だけから現在論点の結論、優先順位、スコープ又は次の操作を決めない。 |
| 議論理由 | 現在論点を今扱う意味として、背景・派生元・上位目的との関係を確認できる。 | 現在目的、提案固有の発見理由、完了条件、ユーザーの承認。 | 理由だけから未承認Proposalを通常Topic化、現在地化、決定済み化又は現スコープ内化しない。 |
| 根拠会話・既存情報 | 背景又は派生元を裏付ける発言、ターン、既存Topic・Decision等との関係を確認できる。 | 表示上の引用、会話の時系列、親子・派生の正本。 | 表示された会話又は近接だけから内容、由来又は関係を推測補完しない。 |

## たどり方の整合条件

- 現在論点から、背景・派生元・上位目的・議論理由を同一論点に対応する別情報として確認できる。いずれかの情報の不在又は未設定を、別情報で補完しない。
- 親子・祖先経路は、上位目的へ意味上たどるために参照する。派生元は親と異なり得るため、親子Relationと派生Relationを相互に変換しない。
- 派生元又は背景がProposalに関係する場合も、Proposalの理由、三判断、承認及び論点化は L5-M3 と L2〜L3 の許可経路に従う。本書は由来文脈を識別するだけである。
- 議論理由は、現在目的、仮説、未決定性、完了条件又は充足状況を置き換えない。これらは L5-M2-S2〜S3 と L2 の正本に従って別に確認する。
- 通常進行中の一意な現在地、又は通常進行しない時点に現在地が0件である条件は L2-M3 と L5-M1-S1 を参照する。本書は現在地を設定・移動・復帰しない。

## 責務境界

- 親子・ルート・上位経路・現在地の識別は L5-M1、決めたいこと・現在目的・仮説・未決定性は L5-M2-S2、完了条件・未確認事項・復帰先は L5-M2-S3 が所有する。
- 決定・通常Topic・未承認Proposal・三判断・スコープ差異の意味上の識別は L5-M3、提案固有の発見理由は同Ownerが所有する。
- 状態、完了可否、階層・現在地不変条件、遷移・Guardは L2、Actor・承認・理解停止Guardは L3、Topic・Relation・会話・正本・履歴・復元は L4 が所有する。
- 再説明・情報取得・操作・APIは L6、文面、引用、配置、展開、図法及びコンポーネントは L8、受入・測定は L7 が所有する。本書はEntity、Cardinality、表示・操作方式を定義しない。
