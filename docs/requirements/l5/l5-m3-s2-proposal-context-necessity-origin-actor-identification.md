# L5-M3-S2: 新規Proposalの文脈・必要性・由来・主体の識別要件

## 目的

未承認Proposalについて、発見理由、派生元、今回の目的との関係、今扱う必要性及び既存Actor由来を同一Proposalに対応付けて確認できる条件を定める。ユーザー由来内容を一律にProposalとして扱わない。

## 識別条件

| 情報 | 同一Proposalへの対応を確認できる条件 | 区別する対象 | 導かないこと |
| --- | --- | --- | --- |
| 発見理由 | Proposalが検出又は登録された理由を、Proposalの内容及び根拠会話・既存情報との関係で確認できる。 | Decision理由、通常Topicの議論理由、現在目的、承認。 | 理由だけからProposalの承認、論点化、現スコープ内化又はDecision化を導かない。 |
| 派生元 | Proposalが既存Topic、Proposal又は会話上の契機から派生した場合、その由来を確認できる。 | 親、祖先、復帰先、現在地、会話順序。 | 派生元を親子、現在地又は通常進行順へ補完しない。 |
| 目的関連 | 今回の目的又は上位目的との関係を確認できる。 | Proposal内容、発見理由、今扱う必要性、通常Topicの現在目的。 | 目的関連だけからスコープ追加、優先順位又は承認を導かない。 |
| 今扱う必要性 | 今の通常進行で扱う必要性又は後続へ回せる理由を、現スコープとの差異とともに確認できる。 | 三判断結果、承認、状態、完了条件。 | 必要性だけから「今議論する」、通常Topic化、現在地設定又は決定を導かない。 |
| 発見／入力主体 | Proposalの由来となる既存Actor又は入力契機を確認できる。Actorが不明な場合は未記録として扱い推測しない。 | 新しいActor種別、承認Actor、権限、AIの自動判断。 | 主体だけから登録権限、承認、三判断又はスコープ変更を導かない。 |
| 根拠会話・既存情報 | 上記情報を裏付ける発言、ターン、既存Topic・Decision等との関係を確認できる。 | 表示上の近接、会話時系列、Entity又はRelationの正本。 | 近接、時系列又は欠落から理由、由来、目的関連、必要性又は主体を推測補完しない。 |

## 整合条件

- 発見理由、派生元、目的関連、今扱う必要性及び主体は同一Proposalに対応する別情報として扱い、一方の不在を他方から補完しない。
- ユーザー由来の通常Topic追加又は更新は、AI由来の未承認Proposal登録と区別し、L3-M1-S2 と L2 の通常更新経路に従う。本書はその権限又は遷移を再定義しない。
- Proposalの登録、三判断、再判断、撤回、論点化及び現在スコープへの反映は L2〜L4 の正本・許可経路に従う。本書は文脈を識別するだけである。

## 責務境界

- Decision等の種別識別は L5-M3-S1、三判断結果と論点化後由来は S3、スコープ所属と追加由来は S4 が所有する。
- 状態・遷移は L2、Actor・登録権限・承認は L3、Proposal・Relation・会話・正本・履歴は L4、情報生成・更新・操作/APIは L6、具体文面・表示・入力検出は L8、受入はL7が所有する。
