# L5-M3-S4: 現在スコープ・未承認候補・承認済み追加及び追加由来の識別要件

## 目的

現在スコープに属する通常Topic、未承認Proposal、承認済みの追加Topic及びProposalを経ない正規追加を区別し、新規追加が既知の残り集合へ反映された後も、その追加由来を確認できる条件を定める。

## スコープ所属・追加由来の識別条件

| 識別する情報 | 確認できる条件 | 区別する対象 | 導かないこと |
| --- | --- | --- | --- |
| 現在スコープ内の通常Topic | 既存の通常Topicについて、L2が定める有効なスコープ上の扱いとして現在スコープ内であることを確認できる。 | 未承認Proposal、対象外の通常Topic、Decision、完了済み、現在地。 | スコープ所属だけから通常進行、現在地設定、完了、Decision化又は優先順位を導かない。 |
| 判断待ちのProposal | 三判断の現行結果がない未承認Proposalについて、現スコープ内の通常Topicとは別の候補として確認できる。 | 現在スコープ内、後で議論する、対象外、通常Topic。 | 登録、表示又は判断待ちだけから現在スコープ追加、残り集合への算入又は論点化を導かない。 |
| 今議論するによる承認済み追加 | ユーザーの明示承認後に生成された通常Topicについて、元Proposalとの由来Relation及び現在スコープ所属を確認できる。 | 未承認Proposal、判断待ち、Decision、親子、現在地。 | 識別だけから承認、論点化、構造更新、現在地設定又は通常進行開始を導かない。 |
| 後で議論するのProposal | 現行結果が後で議論する未承認Proposalについて、将来のユーザーTriggerで再判断する候補として確認できる。 | 現在スコープ内の通常Topic、対象外、保留、承認済み追加。 | 後で議論するだけから現在スコープ追加、残り集合への算入、通常Topic化又は自動再判断を導かない。 |
| 今回は対象外のProposal | 現行結果が今回は対象外である未承認Proposalについて、今回のスコープに含めない候補として確認できる。 | 却下、削除、後で議論する、対象外の通常Topic。 | 対象外だけからProposal削除、恒久的不採用、通常Topic化又は将来の再判断禁止を導かない。 |
| Proposalを経ない正規追加 | ProposalではないL2・L3の許可済み経路による通常Topic追加又は既存Topicの正規更新で追加された通常Topicについて、Proposal由来ではない追加由来を確認できる。 | AI由来の未承認Proposal登録、Proposalからの論点化、表示上の新規性。 | Proposal由来を推測補完しない。追加だけから現在地、親子、復帰先、完了又はDecisionを導かない。 |
| 新規追加由来の保持 | 現在スコープに含まれる追加Topicについて、Proposalからの論点化又はProposalを経ない正規追加のいずれであるかを、既存の由来情報から確認できる。 | 現在スコープへの所属、追加時点、旧スコープ、残り程度。 | 残り集合へ反映されたこと、会話時系列、表示上の近接又は欠落から追加由来を補完・消去しない。 |

## 整合条件

- 三判断と現在スコープとの関係は、判断待ち・後で議論する・今回は対象外のProposalを未承認候補として現スコープ内の通常Topicと区別し、今議論するで論点化された通常Topicだけを、L2・L3・L4の許可済み経路に従って確認する。
- 現在スコープに含まれる新規追加は、Proposalからの論点化又はProposalを経ない正規追加という由来を失わない。追加由来は新規性を識別する情報であり、追加時点、旧状態又は過去のスコープ差分を定めない。
- 新規追加が L5-M1-S3 の既知の残り集合へ反映された後も、残り集合への包含と追加由来を別情報として確認する。M1-S3 は残り集合への算入だけを所有し、本書は件数、残り程度、優先順位又は未知範囲を定めない。
- Proposalを経ない正規追加は、AI由来の未承認Proposal登録と区別し、L2・L3が定める通常更新の許可経路に従う。Proposalが存在しないことを理由・由来・Actor又は承認の欠落として推測しない。
- 現在スコープ所属、追加由来及び残り集合への反映の確認だけから、状態変更、Decision、完了、親子・復帰先、現在地又は通常進行を導かない。

## 責務境界

- 種別と確定度は L5-M3-S1、Proposalの文脈・主体はS2、三判断結果と論点化後由来はS3、追加時点・旧状態・過去のスコープ変化の提示要件は L5-M4 が所有する。
- 状態・スコープ上の意味・遷移・構造条件はL2、Actor・登録権限・承認・再判断はL3、Topic・Proposal・由来Relation・現行正本・履歴はL4、操作/APIはL6、具体的な差分表現・表示・入力検出はL8、受入はL7が所有する。
- 残り集合への算入、残り程度及び未知範囲は L5-M1-S3、全体／フォーカス別の情報配分はL5-M5が所有する。本書はEntity、Cardinality、保存・復元、追加時点又は表示方式を定義しない。
