# L1-M1-S1 新規壁打ち開始シナリオ

## シナリオ情報

| 項目 | 内容 |
| --- | --- |
| Scenario ID | `L1-M1-S1`（Task IDと同一） |
| 名称 | 新規壁打ちを開始し、通常進行へ引き渡す |
| 主Actor | ユーザー |
| 支援Actor | AIエージェント、UI |
| 目的 | ユーザーが入力した目的から作られた初期構造と現在の論点を確認し、一問一答による通常進行を始められる状態にする |

## 事前条件

- ユーザーが新しい壁打ちを開始しようとしている。
- ユーザーが今回の壁打ちで達成したい目的を入力できる。
- AIエージェントとの対話、および議論状態を参照できるUIを利用できる。
- 既存の未完了セッションを復元する再開操作ではない。

## Trigger

ユーザーが新規セッションを開始し、今回の壁打ちの目的を入力する。

## 主要フロー

| # | Actor | 操作 | ユーザーが確認できる結果 |
| --- | --- | --- | --- |
| 1 | ユーザー | AIエージェントとのチャットに目的を入力する。 | 入力した目的が新規セッションの対話として扱われる。 |
| 2 | AIエージェント | 入力された目的から読み取れる範囲を、目的を起点とする領域・論点の初期構造として整理する。 | 議論全体の初期構造を確認できる。 |
| 3 | AIエージェント | 初期構造の中から最初に扱う論点を現在の論点として設定する。 | ルートの目的から現在の論点までの経路と、現在地を確認できる。 |
| 4 | AIエージェント | 現在の論点に、背景、決めたいこと、完了条件、既知の残り論点、完了後の復帰先を関連付ける。 | 現在の論点について、なぜ議論するか、何を決めるか、何が決まれば終わるか、残りの確認事項、終了後に戻る親論点を確認できる。 |
| 5 | UI | 初期構造、現在地、背景、決めたいこと、完了条件、既知の残り論点、復帰先を参照可能にする。 | ユーザーはチャットを続ける前に、議論の全体と現在の論点の関係を確認できる。 |

## 観測可能な成立結果

- ユーザーが入力した目的を起点とする初期構造が存在する。
- 現在の論点が一つ設定され、目的から現在の論点までの経路を追える。
- 現在の論点の背景、決めたいこと、完了条件、既知の残り論点、復帰先をユーザーが確認できる。
- ユーザーは、現在何をなぜ議論するのか、全体のどこにいるのか、何が決まれば終わるのか、終了後にどこへ戻るのかを把握できる。
- 初期構造の作成と現在の論点の設定が完了しており、通常進行へ引き渡せる。

## 終了・通常進行への引渡し

次の条件がすべて成立した時点で、本シナリオを終了する。

- 目的を起点とする初期構造を参照できる。
- 現在の論点と、目的から現在の論点までの経路を参照できる。
- 現在の論点の背景、決めたいこと、完了条件、既知の残り論点、復帰先を参照できる。
- ユーザーが上記の内容を確認できる。

引渡し先は `L1-M1-S2` が所有する一問一答の通常進行とする。引渡し後も現在の論点を維持し、AIエージェントがその論点について一問だけ質問するところから通常進行を開始する。本シナリオでは、質問への回答、議論状態の更新、次の質問、認識修正、論点の正常完了を扱わない。

## 責務境界

- FR-003〜FR-007の表示内容を参照するが、具体的な画面配置・表現方式は定義しない。
- 初期構造、完了条件、現在地などの正式な状態・遷移規則は定義しない。
- AIとユーザーの更新権限、承認条件、曖昧な発言の扱いは定義しない。
- 会話・議論状態・履歴のデータモデル、永続化方式は定義しない。
- Discussion Toolの操作名、Tool API、JSON Schema、AI内部の処理手順は定義しない。
- 新規提案の判断はL1-M2、理解停止と背景再確認はL1-M3、セッションの中断・再開はL1-M4が所有する。
- 一問一答の通常進行はL1-M1-S2、AI認識の修正はL1-M1-S3、論点の正常完了と親復帰はL1-M1-S4が所有する。
