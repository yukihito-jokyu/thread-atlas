# L1-M3-S1 理解停止の通知・次論点非進行シナリオ

## シナリオ情報

| 項目 | 内容 |
| --- | --- |
| Scenario ID | `L1-M3-S1`（Task IDと同一） |
| 名称 | 文章入力なしで理解不足を通知し、現在の論点に留まる |
| 主Actor | ユーザー |
| 支援Actor | AIエージェント、UI |
| 目的 | ユーザーが理解不足を文章入力なしで通知したとき、現在の論点・文脈を失わず、次の論点へ進まないことを確認して、背景再説明の入口へ進めるようにする。 |

## 事前条件

- `L1-M1-S2` が所有する通常進行Anchorを参照できる通常進行中である。
- 現在の論点と、ルートから現在地までの経路を確認できる。
- 現在の論点について、背景、決めたいこと、完了条件、既知の残り論点、完了後の復帰先を確認できる。
- 現在の論点の正常完了、AI認識の修正、ユーザー都合の中断・再訪を処理中ではない。

## Trigger

ユーザーが、現在の論点について「ここが分からない」という理解不足を、文章を入力せずに通知する操作を行う。

## 主要フロー

| # | Actor | 操作 | ユーザーが確認できる結果 |
| --- | --- | --- | --- |
| 1 | ユーザー | 文章を入力せずに、現在の論点への理解不足を通知する。 | 理解不足の通知が、現在の論点に対する操作として受け付けられたことを確認できる。 |
| 2 | AIエージェント、UI | 通知を受け、現在の論点を処理対象として維持する。 | 通知前後で、現在の論点、ルートからの経路、背景、決めたいこと、完了条件、既知の残り論点、復帰先を確認できる。 |
| 3 | AIエージェント | 次の論点へ進む質問、別の論点への移動、論点の正常完了を行わない。 | 次論点が開始されず、現在地が変わっていないことを確認できる。 |
| 4 | AIエージェント、UI | 理解不足の通知を反映したことを、既存の情報を暗黙に書き換えず確認可能にする。 | 何が通知されたかを確認でき、現在の論点に関する既存の情報との照合を続けられる。 |
| 5 | AIエージェント | `L1-M3-S2` が所有する背景再説明の入口へ引き渡す。 | 現在の論点を保ったまま、背景再説明を求める次の経路へ進める。 |

## 通知中に確認できる不変条件

理解不足を通知した時点から`L1-M3-S2`への引渡しまで、ユーザーは次を確認できる。

| 確認対象 | 観測可能な不変条件 |
| --- | --- |
| 現在地 | 現在の論点とルートからの経路は、通知前と同じである。 |
| 論点の文脈 | 背景、決めたいこと、完了条件、既知の残り論点、復帰先は、通知前と同じ値を確認できる。 |
| 進行 | 次の論点の開始、別の論点への移動、論点の正常完了は観測されない。 |
| 更新の可視性 | 理解不足の通知以外に既存の議論構造が暗黙に書き換えられていないことを確認できる。 |

この表は現在の論点に関する値を新たに定義するものではなく、通常進行で参照可能な同じ値を、通知の前後で照合できるという利用者向けの不変条件だけを示す。

## 終了・背景再説明への引渡し

次の条件がすべて成立した時点で、本シナリオを終了し、`L1-M3-S2` の背景再説明・理解未解消反復・通常進行復帰シナリオへ引き渡す。

- ユーザーが文章を入力せずに理解不足を通知できた。
- 通知が現在の論点に対するものとして確認できる。
- 通知前後で、現在の論点、経路、背景、決めたいこと、完了条件、既知の残り論点、復帰先を確認できる。
- 次の論点の開始、別の論点への移動、論点の正常完了が観測されない。

本シナリオは、背景の再説明、理解未解消時の反復、理解解消の確認、通常進行への復帰を実行または確定しない。これらは`L1-M3-S2`が所有する。

## 責務境界

- 本シナリオは、文章入力なしの理解不足通知、同じ現在論点・文脈の観測、次論点非進行、背景再説明への引渡しという入口の時系列だけを定義する。
- 背景再説明の内容、理解未解消時の反復、理解解消後の通常進行への復帰は`L1-M3-S2`が所有する。
- AIの認識誤りの修正は`L1-M1-S3`、ユーザー都合の中断・再訪はL1-M4、新規提案の判断はL1-M2が所有する。
- 論点の正式な状態語彙、遷移、現在地変更の許可・禁止はL2へ残す。
- 理解停止中のAI統制、成立・維持・解除条件、Actor権限はL3へ残す。本シナリオは理解停止を永続状態として定義しない。
- 会話・通知・議論状態の保持単位と履歴はL4、具体的な表示方法はL5、論理操作・Tool APIはL6以降へ残す。
