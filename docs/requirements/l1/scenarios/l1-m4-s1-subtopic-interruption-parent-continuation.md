# L1-M4-S1 下位議論の中断・親論点継続シナリオ

## シナリオ情報

| 項目 | 内容 |
| --- | --- |
| Scenario ID | `L1-M4-S1`（Task IDと同一） |
| 名称 | 未完了の下位論点を中断し、親論点の通常進行を継続する |
| 主Actor | ユーザー |
| 支援Actor | AIエージェント、UI |
| 目的 | 下位論点の議論中にユーザー都合で中断を選び、完了扱いにせず途中内容を失わず、親論点側の通常進行へ戻れるようにする。 |

## 事前条件

- 現在の論点は、親論点を持つ下位論点であり、通常進行中である。
- 現在の下位論点と、その親論点までを含むルートからの経路を確認できる。
- 現在の下位論点の背景、決めたいこと、完了条件、既知の残り論点、完了後の復帰先を確認できる。
- 下位論点の正常完了・親復帰、AI認識の修正、理解停止、ユーザーによる過去の中断論点の再訪を処理中ではない。

## Trigger

ユーザーが、下位論点の議論を完了させずに中断し、親論点の議論へ戻ることを選ぶ。

## 主要フロー

| # | Actor | 操作 | ユーザーが確認できる結果 |
| --- | --- | --- | --- |
| 1 | ユーザー | 現在の下位論点を中断し、親論点へ戻ることを選ぶ。 | 中断の対象が現在の未完了の下位論点であることを確認できる。 |
| 2 | AIエージェント、UI | 下位論点を正常完了として扱わず、現在までの会話、論点の文脈、未確認事項を後から選択できる形で維持する。 | 下位論点が完了扱いになっておらず、途中内容を失わず後から扱えることを確認できる。 |
| 3 | AIエージェント、UI | 現在地を親論点へ戻し、親論点の背景、決めたいこと、完了条件、既知の残り論点、復帰先を確認可能にする。 | 親論点へ戻った現在地と、親論点で継続するための文脈を確認できる。 |
| 4 | AIエージェント | `L1-M1-S2`が所有する通常進行Anchorで、親論点について次に確認する質問を一問だけ提示する。 | 親論点の通常進行を一問一答で継続できる。 |

## 中断時に確認できること

- 下位論点の完了条件を満たしたという結果、論点の正常完了、完了による親復帰は観測されない。
- 中断した下位論点の現在までの会話、背景、決めたいこと、完了条件、未確認事項、親論点との関係を、後から選択できる形で確認できる。
- 親論点へ戻った後、下位論点を中断した事実と、親論点側の通常進行を区別して確認できる。

この節は中断論点の正式な状態、履歴の保持単位、再訪方法を定義するものではなく、ユーザーから観測できる中断結果だけを示す。

## 終了・親論点の通常進行への引渡し

次の条件がすべて成立した時点で、本シナリオを終了し、親論点について`L1-M1-S2`が所有する通常進行Anchorへ引き渡す。

- ユーザーが現在の下位論点を中断することを選んだ。
- 下位論点を正常完了として扱わず、完了条件を満たしたという結果が観測されない。
- 下位論点の途中内容を失わず後から選択できることを確認できる。
- 親論点の現在地、背景、決めたいこと、完了条件、既知の残り論点、復帰先を確認できる。

中断した下位論点の経緯確認・再訪は`L1-M4-S2`が所有する。本シナリオは再訪を実行または確定しない。アプリ終了後のセッション復元・再開は`L1-M4-S3`が所有する。

## 責務境界

- 本シナリオは、未完了の下位論点を中断し、親論点の通常進行へ戻る利用者から見える時系列だけを定義する。
- 論点の正常完了・完了による親復帰は`L1-M1-S4`、中断論点の経緯確認・再訪は`L1-M4-S2`、アプリ終了後の復元・再開は`L1-M4-S3`が所有する。
- 論点の正式な状態語彙、遷移、親復帰規則はL2へ残す。中断を永続状態として定義しない。
- 会話・途中内容・履歴・Undo・復元のデータモデルと保持単位はL4、具体的な表示方法はL5、論理操作・Tool APIはL6以降、永続化・障害復旧方式はL8へ残す。
