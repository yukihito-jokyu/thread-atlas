# L1-M2-S2 新規提案への3判断と継続先シナリオ

## シナリオ情報

| 項目 | 内容 |
| --- | --- |
| Scenario ID | `L1-M2-S2`（Task IDと同一） |
| 名称 | 新規提案を3つの選択肢で判断し、対応する継続先へ進む |
| 主Actor | ユーザー |
| 支援Actor | AIエージェント、UI |
| 目的 | AIが発見した新規提案をユーザーが「今議論する」「後で議論する」「今回は対象外」から明示的に判断し、暗黙の論点昇格を起こさず、判断に対応する継続先または復帰先を確認できるようにする |

## 事前条件

- `L1-M2-S1` の終了条件が成立し、新規提案へのユーザー判断前の入口へ引き渡されている。
- 新規提案の内容、派生元、発見理由、今回の目的との関係、今議論する必要性、現在スコープとの差異を確認できる。
- 提案がAI由来の新しい候補として現在の議論から区別されている。
- 提案の発見だけでは現在地と現在スコープが変更されていない。
- 提案判断前に進行していた論点と、`L1-M1-S2` が所有する通常進行Anchorを確認できる。
- 対象の提案について、ユーザー判断はまだ行われていない。

## Trigger

UIが新規提案と判断に必要な情報を参照可能にし、ユーザーが「今議論する」「後で議論する」「今回は対象外」の3つの選択肢から判断できる状態になる。

## 判断前の共通フロー

| # | Actor | 操作 | ユーザーが確認できる結果 |
| --- | --- | --- | --- |
| 1 | UI | 新規提案を現在の議論から区別したまま、提案内容と判断に必要な情報、および3つの選択肢を参照可能にする。 | 何を判断するのか、当初または承認済みのスコープから何が増えるのか、判断後の違いを確認できる。 |
| 2 | ユーザー | 「今議論する」「後で議論する」「今回は対象外」のいずれか1つを選択する。 | AIではなくユーザーが、対象の提案に対する判断を明示したことを確認できる。 |
| 3 | AIエージェント | ユーザーが選択した判断だけを対象の提案へ反映し、判断に対応する継続先または復帰先を準備する。 | 選択していない判断へ置き換えられず、AIだけの判断で現在の議論へ昇格していないことを確認できる。 |
| 4 | UI | 判断結果、判断対象、判断によって変わった内容、次に進む先を参照可能にする。 | ユーザーは自身の選択が正しく反映されたことと、次の現在地または復帰先を確認できる。 |

判断が選択されていない間は、新規提案を現在の議論へ昇格させず、提案判断前の現在地と現在スコープを維持する。AIは提案の妥当性、優先度、採否を理由に選択を代行しない。

## 分岐

### A. 今議論する

1. ユーザーが「今議論する」を選択する。
2. AIエージェントは、対象の提案がユーザーにより今扱う議論対象として承認されたことを反映する。
3. UIは、提案判断前の通常進行を復帰先として確認できる状態を保ち、承認された提案に基づく論点へ進むことを参照可能にする。
4. 承認された論点で、背景、決めたいこと、完了条件、元の通常進行への復帰先を確認できる状態から、`L1-M1-S2` の通常進行Anchorへ引き渡す。
5. 承認された論点の通常進行が終了または中断した後は、L1-M1またはL1-M4が所有する経路を介して、提案判断前に進行していた論点の通常進行Anchorへ戻れる。

この分岐では、ユーザーの選択を確認する前に提案を論点化しない。承認された論点を開始したまま元の通常進行との接続を失わせず、判断前の論点を並行して自動進行させない。

### B. 後で議論する

1. ユーザーが「後で議論する」を選択する。
2. AIエージェントは、対象の提案を今は議論対象へ昇格させず、後で判断または議論できる候補として扱うことを反映する。
3. UIは、対象の提案が現在スコープへ追加されていないことと、後で再判断できる対象として残っていることを参照可能にする。
4. 現在地を対象の提案へ移さず、提案判断前に進行していた論点の有効な議論状態を引き継いで、`L1-M1-S2` の通常進行Anchorへ戻る。

ユーザーが後日、この提案を再び扱うことを求めた場合は、提案内容、派生元、発見理由、今回の目的との関係、扱う時点での必要性とスコープ差異を再確認したうえで、本シナリオの判断入口へ戻る。以前に「後で議論する」と選択されたことだけを根拠として、AIが再判断を開始したり、自動的に現在の議論へ昇格させたりしない。

### C. 今回は対象外

1. ユーザーが「今回は対象外」を選択する。
2. AIエージェントは、対象の提案を今回の目的と現在スコープでは扱わないというユーザー判断を反映する。
3. UIは、対象となった提案と「今回は対象外」という判断結果を、現在の議論および承認済みの内容と区別して参照可能にする。
4. 現在地を対象の提案へ移さず、提案判断前に進行していた論点の有効な議論状態を引き継いで、`L1-M1-S2` の通常進行Anchorへ戻る。

この分岐では、対象外とした提案を現在スコープ、決定事項、既知の残り論点として暗黙に組み込まない。別の目的や将来の議論で再提示できる条件、記録の保持期間、再提案の抑止規則は本シナリオでは定義しない。

## 各判断の継続・復帰対応

| ユーザー判断 | 現在の議論への扱い | 直後の継続先 | 復帰・再判断先 |
| --- | --- | --- | --- |
| 今議論する | ユーザー承認後に議論対象として扱う | 承認された論点の通常進行Anchor | 終了・中断後、判断前の論点の通常進行Anchor |
| 後で議論する | 今は昇格せず、再判断可能な候補として扱う | 判断前の論点の通常進行Anchor | 後続のユーザーTriggerで必要性とスコープ差異を再確認し、本シナリオの判断入口 |
| 今回は対象外 | 今回の目的と現在スコープへ組み込まない | 判断前の論点の通常進行Anchor | 本シナリオでは定義しない |

## 観測可能な成立結果

- ユーザーが3つの選択肢から1つを明示的に判断できる。
- 判断対象、選択結果、変更内容、次の継続先または復帰先を確認できる。
- 「今議論する」では、ユーザー承認後にだけ提案を議論対象として扱い、元の通常進行への復帰先を確認してから進める。
- 「後で議論する」では、提案を今の議論へ昇格させず通常進行へ戻り、後続のユーザーTriggerによる再判断入口を確認できる。
- 「今回は対象外」では、提案を現在スコープへ組み込まず通常進行へ戻る。
- どの判断でも、AIがユーザーの選択を代行せず、選択前に現在地または現在スコープを変更しない。
- 判断後の有効な議論状態を引き継いで、一問一答の通常進行へ接続できる。

## 終了・引渡し先

本シナリオは、ユーザーの判断とその反映結果を確認し、次のいずれかへ引き渡した時点で終了する。

- 「今議論する」では、承認された論点の背景、決めたいこと、完了条件、復帰先を確認できる状態で、同論点の通常進行Anchorへ引き渡す。
- 「後で議論する」では、再判断可能な候補として残ったことを確認し、提案判断前の論点の通常進行Anchorへ引き渡す。
- 「今回は対象外」では、現在スコープへ組み込まれないことを確認し、提案判断前の論点の通常進行Anchorへ引き渡す。

通常進行中の質問・回答・更新、承認された論点の正常完了・中断、通常進行Anchorへ戻った後の次の一問は、それぞれL1-M1またはL1-M4が所有する。

## 責務境界

- 3つの判断、各判断直後の継続先、通常進行への復帰、「後で議論する」の再判断経路という、ユーザーから見える時系列だけを定義する。
- 正式な状態語彙、許可・禁止遷移、現在地変更、論点化・正常完了・中断時の不変条件はL2へ残す。
- AIとユーザーの更新権限、承認が必要な提案の範囲、自動追加・自動昇格の禁止条件、再提案の権限はL3へ残す。
- 提案、判断、会話、議論状態、変更履歴、後日参照のデータモデルと保持方法はL4へ残す。
- 3つの選択肢、判断結果、差分、復帰先、再判断入口の具体的な画面配置・表現方式はL5へ残す。
- 提案判断と論点化の論理操作、Discussion Toolの責務、Tool API、JSON SchemaはL6以降へ残す。
- 新規提案の発見、現在スコープとの差異の識別、判断前の引渡しはL1-M2-S1が所有する。本シナリオは同じ情報を再決定しない。
- 一問一答の質問・回答・更新、論点の正常完了・親復帰はL1-M1、論点の中断・再訪はL1-M4が所有する。本シナリオは各経路への引渡しと復帰Anchorだけを定義する。
- 「今回は対象外」とした提案の将来再提示条件や、「後で議論する」とした提案の保持・通知方法を決めない。
- 新規提案の妥当性、優先度、採否、実現方法をAIだけで確定しない。

## Task固有Review

- Actor、事前条件、Trigger、判断前フロー、3分岐、観測可能結果、終了・引渡し先を記述している。
- 「今議論する」「後で議論する」「今回は対象外」の3判断が漏れなく相互に区別されている。
- 各判断について、直後の継続先と通常進行への復帰先または再判断先を追跡できる。
- 「今議論する」で承認された論点が孤立せず、判断前の通常進行への復帰先を持つ。
- 「後で議論する」で通常進行へ戻り、後続のユーザーTriggerで必要性とスコープ差異を確認して再判断できる。
- 「今回は対象外」で提案が現在スコープへ暗黙に組み込まれない。
- ユーザー判断前の昇格を禁止し、AIが3判断を代行しない。
- `L1-M2-S1` の判断前引渡しと `L1-M1-S2` の通常進行Anchorへ一意に接続している。
- §5.6、FR-011、FR-014、AR-008、§17、MVP 12〜13、Q7〜Q8との対応を追跡できる。
- 正式状態、状態遷移、権限、データモデル、表示方式、Tool API、受入基準、具体設計を追加していない。
- MVP項目の追加・削除を行っていない。
- 本シナリオ本文に未解決の契約差異とTBDはない。
