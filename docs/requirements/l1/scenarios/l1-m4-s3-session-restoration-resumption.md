# L1-M4-S3 アプリ終了後のセッション復元・再開シナリオ

## シナリオ情報

| 項目 | 内容 |
| --- | --- |
| Scenario ID | `L1-M4-S3`（Task IDと同一） |
| 名称 | 未完了セッションを復元し、通常進行を再開する |
| 主Actor | ユーザー |
| 支援Actor | AIエージェント、UI |
| 目的 | 未完了のセッションをアプリ終了後に再び開き、前回位置と未完了内容を確認して、その論点の通常進行へ戻れるようにする。 |

## 事前条件

- 未完了の論点を含むセッションが、アプリ終了前に保存されている。
- ユーザーが後からアプリを再起動し、当該セッションを開ける。
- 復元結果として、会話、議論マップ、現在地、決定事項、保留事項、新規提案、未完了論点を確認できる。
- 同一セッション内での中断論点の経緯確認・再訪、AI認識の修正、論点の正常完了を処理中ではない。

## Trigger

ユーザーが、アプリを終了した後に未完了のセッションを再び開く。

## 主要フロー

| # | Actor | 操作 | ユーザーが確認できる結果 |
| --- | --- | --- | --- |
| 1 | ユーザー | アプリを再起動し、未完了のセッションを開く。 | 再開対象が前回終了した未完了セッションであることを確認できる。 |
| 2 | AIエージェント、UI | 会話、議論マップ、現在地、決定事項、保留事項、新規提案、未完了論点を継続可能な形で復元する。 | 前回までの議論内容と、再開可能な未完了事項を確認できる。 |
| 3 | ユーザー | 復元された現在地、前回位置、未完了内容を確認し、当該論点の議論を再開することを選ぶ。 | どこから何を続けるかを把握して、再開対象を確認できる。 |
| 4 | AIエージェント | `L1-M1-S2`が所有する通常進行Anchorで、再開した論点について次に確認する質問を一問だけ提示する。 | 復元された内容を引き継いで、一問一答の通常進行を再開できる。 |

## 観測可能な成立結果

- アプリ終了後に、未完了セッションの会話、議論マップ、現在地、決定事項、保留事項、新規提案、未完了論点を確認できる。
- 前回位置と未完了内容を把握し、復元された論点の通常進行を再開できる。
- 再開によって論点の正常完了、決定、保留の解除、新規提案の判断、構造修正を暗黙に確定しない。
- 同一セッション内の中断・再訪とは区別できる。異常終了、強制終了、電源断からの無損失復旧を保証するものではない。

## 終了・通常進行への引渡し

次の条件がすべて成立した時点で、本シナリオを終了し、復元された論点について`L1-M1-S2`が所有する通常進行Anchorへ引き渡す。

- 開いたセッションがアプリ終了前に未完了だったことを確認できる。
- 会話、議論マップ、現在地、決定事項、保留事項、新規提案、未完了論点を確認できる。
- 現在の論点・経路・背景・決めたいこと・完了条件・既知の残り論点・復帰先と、前回位置を確認できる。

再開しない場合は、このセッションの通常進行を開始しない。復元後に中断論点の経緯確認・再訪、AI認識の修正、理解停止、新規提案、正常完了が必要になった場合は、それぞれの所有シナリオへ引き渡す。

## 責務境界

- 本シナリオは、アプリ終了後の未完了セッションについて、復元結果を確認して通常進行Anchorへ戻る利用者から見える時系列だけを定義する。
- 同一セッション内の中断と親論点継続は`L1-M4-S1`、中断論点の経緯確認・再訪は`L1-M4-S2`、正常完了・親復帰は`L1-M1-S4`が所有する。
- 論点の正式な状態・遷移はL2、会話・議論マップ・論点等のEntity、関連、保存・復元単位、履歴・UndoはL4、提示方法はL5、論理操作・Tool APIはL6以降へ残す。
- 永続化方式、異常終了・障害復旧、無損失保証はL8へ残す。

## Task固有Review

- FR-020の7項目を観測可能な復元結果としてすべて確認できる。
- アプリ終了後の復元と、同一セッション内の中断・再訪を混同していない。
- 前回位置と未完了内容を確認して`L1-M1-S2`通常進行Anchorへ戻る。
- Entity、関連、保存・復元単位、履歴・Undo、表示、状態遷移、永続化・障害復旧を先取りしていない。
