# L1-M1-S2 一問一答による議論進行シナリオ

## シナリオ情報

| 項目 | 内容 |
| --- | --- |
| Scenario ID | `L1-M1-S2`（Task IDと同一） |
| 名称 | 一問一答で議論状態を更新し、通常進行を継続する |
| 主Actor | ユーザー |
| 支援Actor | AIエージェント、UI |
| 目的 | 一度に一問ずつ回答し、回答に基づく議論状態の更新結果を確認しながら、現在の論点を継続するか、認識修正または正常完了の確認へ進めるようにする |

## 事前条件

- 新規開始または既存経路から、一問一答による通常進行へ引き渡されている。
- 現在の論点が一つ定まり、ルートから現在地までの経路を確認できる。
- 現在の論点の背景、決めたいこと、完了条件、既知の残り論点、復帰先を確認できる。
- AIエージェントとの対話、および議論状態とその更新結果を参照できるUIを利用できる。
- AIの認識差異を修正中でも、論点の正常完了を処理中でもない。

## Trigger

AIエージェントが、現在の論点を進めるための質問を一問だけ提示する。

## 主要フロー

| # | Actor | 操作 | ユーザーが確認できる結果 |
| --- | --- | --- | --- |
| 1 | AIエージェント | 現在の論点で決めたいこと、または残っている確認事項に関する質問を一問だけ提示する。 | 今の質問と現在の論点との関係を保ったまま、一度に一問へ集中できる。 |
| 2 | ユーザー | 提示された質問へ回答する。 | 回答が現在の論点に対する会話として記録される。 |
| 3 | AIエージェント | 回答に基づき、Discussion Toolを介して必要な議論状態の更新を行う。回答から決定事項が成立した場合は、その内容も議論状態へ反映する。 | 回答を根拠として、論点、決定事項、既知の残り論点などの何が追加・変更されたかを確認できる。 |
| 4 | UI | 更新された内容と、その根拠となった会話を参照可能にする。 | ユーザーは会話と議論状態を照合し、AIの認識どおりに反映されたかを確認できる。 |
| 5 | AIエージェント | 更新後も同じ論点で確認が必要な場合、その論点を維持して次の質問を一問だけ提示する。 | 現在地を変えずに次の一問が提示され、主要フローの手順2から反復できる。 |

## 継続時の通常進行Anchor

次の条件が成立している箇所を、本シナリオが所有する通常進行Anchorとする。

- 現在有効な議論状態と、ルートから現在の論点までの経路を参照できる。
- 現在の論点の背景、決めたいこと、完了条件、既知の残り論点、復帰先を確認できる。
- AIの認識差異が示されていない。
- 論点の正常完了はまだ確定していない。
- 現在の論点で次に確認する質問が一問だけ提示されている。

主要フローを回答後に反復する場合は、この共通条件に加えて、直前の回答に基づく更新結果を参照でき、更新結果から根拠会話へ遡れることを確認してから次の質問を提示する。

`L1-M1-S1` からは最初の質問を一問だけ提示する初回入口として、このAnchorへ入る。`L1-M1-S3` で認識修正が完了した場合は修正後の有効な議論状態から、このAnchorへ戻る。L1-M2の提案判断、L1-M3の理解停止解除または直接再説明、L1-M4の中断・再訪・復元が完了した場合も、それぞれが所有する処理結果を有効な議論状態として引き継ぎ、このAnchorへ戻る。各復帰元の処理内容は本シナリオでは定義しない。

## 分岐

### A. 同じ論点で継続する

更新後も現在の論点の完了条件を満たしておらず、同じ論点に確認事項が残る場合は、現在地を維持して次の質問を一問だけ提示し、主要フローの手順2へ戻る。

### B. 下位論点で通常進行を継続する

現在の議論構造に既に存在するか、ユーザーが提示または承認済みであり、現在の目的とスコープの範囲内にある下位論点を扱う場合は、次の質問を提示する前に、下位論点が必要な理由、決めたいこと、完了条件、親論点との関係を議論構造へ反映し、現在地を更新する。ユーザーが更新後の経路、背景、完了条件、復帰先を確認できる状態で、下位論点について一問だけ提示し、主要フローの手順2へ戻る。

AIが新しく発見した論点・観点・案を、下位論点として暗黙に組み込む経路は本分岐に含めない。AIによる新規発見とユーザー判断はL1-M2が所有する。

### C. AIの認識を修正する

ユーザーが、質問の前提または更新結果に目的・論点・回答解釈などの認識差異を見つけた場合は、誤った認識のまま次の質問へ進まず、`L1-M1-S3` の認識修正シナリオへ引き渡す。修正後は、同シナリオから本シナリオの通常進行Anchorへ戻る。

### D. 論点の正常完了を確認する

更新結果から現在の論点が完了可能となった場合は、本シナリオ内で論点完了や親復帰を確定せず、`L1-M1-S4` の結果確認・正常完了シナリオへ引き渡す。

## 観測可能な成立結果

- AIエージェントの質問が一度に一問だけ提示される。
- AIエージェントの応答は一問一答に必要な説明へ留まり、議論構造の大量な内容はチャットへ挿入せずUIで参照できる。
- ユーザーの回答後、回答に基づく議論状態の更新結果を確認できる。
- 何が追加・変更されたかを確認でき、更新結果から根拠となる会話へ遡れる。
- 決定事項が成立した場合は、通常の論点や未決定の内容と区別して確認できる。
- 同じ論点を継続する場合は現在地を維持し、次の質問を一問だけ提示して反復できる。
- 下位論点へ進む場合は、移動後の現在地、必要な理由、決めたいこと、完了条件、親論点への復帰先を確認してから一問一答を継続できる。
- AIの認識差異がある場合は認識修正へ、論点が完了可能な場合は正常完了の確認へ進める。

## 終了・引渡し先

本シナリオは、一問一答を継続する間は通常進行Anchorを反復し、次のいずれかで終了する。

- AIの認識差異が示された場合は、`L1-M1-S3` へ引き渡す。
- 現在の論点が完了可能となった場合は、`L1-M1-S4` へ引き渡す。
- AIが新しい論点・観点・案を発見した場合は、既存の議論へ直接組み込まず、L1-M2へ引き渡す。
- ユーザーが理解停止を通知した場合、または理解停止の確定を伴わず背景確認や再説明を直接求めた場合は、L1-M3へ引き渡す。
- ユーザーが議論の中断を求めた場合は、L1-M4へ引き渡す。

同じ論点または承認済みの下位論点で確認事項が残る場合は終了せず、本シナリオ内の通常進行Anchorへ戻る。L1-M2、L1-M3、L1-M4から各処理の完了後に復帰する場合も、同じAnchorを用いる。

## 責務境界

- 質問、回答、更新確認、継続・認識修正・正常完了への分岐という、ユーザーから見える時系列だけを定義する。
- 論点や決定の正式な状態語彙、許可・禁止遷移、完了条件の成立・充足判定はL2へ残す。
- AIとユーザーの更新権限、決定として扱う条件、曖昧な発言の扱いはL3へ残す。
- 会話・議論状態・変更履歴・トレーサビリティのデータモデルと保持単位はL4へ残す。
- 議論マップ、更新差分、決定事項、根拠会話の具体的な画面配置・表現方式はL5へ残す。
- 更新操作の意味、Discussion Toolの責務、Tool API、JSON SchemaはL6以降へ残す。
- AIが発見した新しい論点・観点・案とユーザーの3判断はL1-M2、理解停止と背景確認・直接再説明はL1-M3、ユーザー都合の中断・再訪・状態復元はL1-M4が所有する。本シナリオは各処理への引渡しと共通Anchorへの復帰だけを定義する。
- AI認識の修正内容はL1-M1-S3、正常完了・親復帰・次論点への引渡しはL1-M1-S4が所有する。

## Task固有Review

- Actor、事前条件、Trigger、操作、観測可能結果、終了・引渡し先を記述している。
- 一問の提示、ユーザー回答、更新結果の確認、同じ論点での継続がユーザーから見える時系列になっている。
- 一度に複数の質問を要求せず、一問一答の反復を維持している。
- 更新内容と根拠会話を確認でき、FR-001、FR-008、FR-012〜FR-014との対応を追跡できる。
- 下位論点へ進む場合の現在地、理由、完了条件の更新を観測でき、AR-002〜AR-004との対応を追跡できる。
- `L1-M1-S1` からの初回入口、`L1-M1-S3` とL1-M2〜M4からの復帰Anchor、`L1-M1-S4` への完了確認引渡しが一意である。
- 認識修正、正常完了・親復帰、新規提案、理解停止、中断・再訪を本シナリオへ取り込んでいない。
- 状態遷移、権限、データモデル、表示方式、Tool API、受入基準、具体設計を追加していない。
- MVP項目の追加・削除を行っていない。
