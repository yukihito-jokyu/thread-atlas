# L1-M5-S2 成果物生成機能のMVP外・将来Issue境界

## 判断

議論状態、議論マップ、決定記録そのものを保持・参照するMVP機能と、それらから別の文書またはファイルを生成する機能を区別する。

後者は、完成した要件定義書の自動生成を含め、現MVPの対象外とする。Issue #1 §20のMVP外判断を維持し、§23が示す広義の「議論から成果物を生成する機能」についても、現MVPへ暗黙に含めない。

## MVPに含める範囲

- 議論状態、議論マップ、決定記録を、議論を継続するために確認・更新・参照できること。
- `L1-M5-S1`が扱うMVP 15項目およびL1シナリオの被覆／Owner割当。

これらは別の文書・ファイルを出力する機能を意味しない。

## MVP外とする範囲

- 議論状態、議論マップ、決定記録から、完成した要件定義書を自動生成すること。
- 議論内容から、別の文書またはファイルを生成すること。

本判断は、原典にない成果物種別を追加して列挙するものではない。MVP 15項目の追加・削除、`L1-M5-S1`の被覆表の変更も行わない。

## 将来への受渡し

成果物生成機能を扱う必要が生じた場合は、別Issueで要件化する。そのIssueでは、対象とする成果物、利用目的、形式、生成Trigger、生成・承認方法、品質基準を明示して検討する。

この文書は将来Issueを作成・更新するものではなく、将来の要件化に必要な境界だけを記録する。

## 責務境界

- 成果物の形式、生成Trigger、生成方式、品質基準、UI、API、実装は本シナリオで決めない。
- L7は将来、要件台帳・受入仕様として参照できるが、本判断の検証方法や合格条件をここで定義しない。
- L8の現MVP設計へ、成果物生成機能を暗黙に含めない。

## Task固有Review

- 議論状態・議論マップ・決定記録と、別文書・ファイルの生成機能を区別している。
- 完成した要件定義書の自動生成を含め、成果物生成機能を現MVP外としている。
- MVP 15項目と`L1-M5-S1`の被覆表を変更していない。
- 将来の検討を別Issueへの受渡し方針に留め、Issue作成・更新、形式、生成方式、UI、API、実装を先取りしていない。
- Issue #1 §20と§23の境界に未解決の契約差異とTBDはない。
