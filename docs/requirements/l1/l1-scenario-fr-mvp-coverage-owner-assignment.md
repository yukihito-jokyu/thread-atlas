# L1シナリオ・FR・MVP被覆／Owner割当表

## 目的と読み方

この表は、L1-M1〜L1-M4の利用シナリオが直接扱う原典要件と、MVP 15項目の被覆を確認するための台帳である。`直接被覆Scenario`は利用者から観測できる時系列を定義する成果物、`主Owner`はそのMVP項目の意味を確定するL2〜L6の親Task、`参照先`はその意味を実現する他の横断要件Ownerを示す。たとえば、表示される情報の意味はL2またはL4、提示要件はL5、操作・連携能力はL6が所有する。

L7は全行の受入仕様・検証・証跡の共通後続であり、本表の主Ownerにはしない。本表は要件ID体系、全要件トレーサビリティ、検証方法、合格条件を定義しない。

## 被覆判定

- MVP 15項目は追加・削除せず、すべて少なくとも一つの直接被覆ScenarioとL2〜L6の主Ownerを持つ。
- 主Ownerは、MVP項目の意味を確定する観点で選ぶ。状態・完了・決定はL2、AIと人の統制はL3、会話・由来・復元の正本はL4、利用者へ提示する情報はL5、会話・Toolの論理能力はL6が主Ownerとなる。
- L1で直接被覆するのは利用者から見える時系列であり、主Ownerの状態・統制・モデル・提示・操作を確定するものではない。
- `L1-M4-S3`のMVP 15は復元結果の確認に限る。保存・復元の物理方式および障害復旧はL8が扱う。
- 完成した要件定義書など、議論から別文書・ファイルを生成する機能のMVP外境界は`L1-M5-S2`が所有する。本表はその判断を変更しない。
