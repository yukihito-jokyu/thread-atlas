# L4-M2-S1: 論点文脈・完了条件・未確認事項の論理関係

## 目的

通常論点の意味を構成する文脈、完了条件、未確認事項および現行の充足判定を、状態・判断結果・履歴とは別の現行論理情報として関連付ける。

本書は各情報の意味、生成・変更・判定、Actor、状態遷移、表示、保存方式を定めない。

## 対象と共通前提

- 対象は通常論点である。未承認Proposal、状態軸、現在地、復帰先、Decisionおよび判断結果は、それぞれ L4-M2-S2〜S4 のOwnerへ残す。
- 文脈・完了条件・未確認事項は、同一Sessionに所属する一つのTopicへ関連付ける。Session・Topicの論理識別とSession所属は L4-M1-S1〜S2、親子・派生関係は L4-M1-S3 を参照する。
- 「現行」は現在参照する論理情報を指す。旧版、変更Event、ChangeSet、訂正、再判断およびUndo後の履歴関係は L4-M3〜M4 が所有する。

## 文脈・条件・未確認事項の関係表

| 論理情報 | Topicとの関係・Cardinality | 他情報との関係 | 非導出事項 |
| --- | --- | --- | --- |
| 背景 | 一つのTopicは 0..N 件の背景情報を持てる。各背景情報は一つのTopicに属する。 | 派生理由、決めたいことと併せて、そのTopicを扱う理由を構成する。 | 背景だけから親子関係、状態、Decision、完了可否を導かない。 |
| 派生理由 | 一つのTopicは 0..N 件の派生理由を持てる。各派生理由は一つのTopicに属する。 | 背景・決めたいことと区別して、当該Topicを扱う契機を関連付ける。派生TopicとのRelationそのものは L4-M1-S3 が所有する。 | 派生理由の有無だけから派生Relation、現在地、通常進行を導かない。 |
| 決めたいこと | 一つのTopicは 0..N 件の決めたいことを持てる。各項目は一つのTopicに属する。 | 背景・派生理由とともに到達点を表し、完了条件との意味上の対応を確認できる。 | Decisionの作成、決定済み、正常完了を導かない。DecisionとのRelationは L4-M2-S3 が所有する。 |
| 完了条件 | 一つの通常Topicは、条件なし例外を除き 1..N 件を持つ。条件なし例外のTopicは 0 件を持てる。各完了条件は一つのTopicに属する。 | 背景・決めたいこと・現スコープ・確認済みDecision・未確認事項との関係を確認できる。 | 条件数、条件なし例外または条件の存在だけから充足、状態変更、正常完了、親復帰を導かない。 |
| 未確認事項 | 一つのTopicは 0..N 件を持てる。各未確認事項は一つのTopicに属する。 | 決めたいこと・完了条件に対して残る不明点または確認対象を関連付ける。 | 未確認事項を、L2の要確認状態、L3の理解停止Guard、曖昧入力の確認要求と同一視しない。 |
| 現行充足判定 | 各現行完了条件は 0..1 件の現行判定を持てる。まだ評価していない条件は 0 件を許す。各現行判定は一つの完了条件に属する。条件なし例外のTopicは、架空の条件を作らず、論点単位の現行充足判定を 0..1 件持てる。 | 判定値は充足・未充足・判断不能のいずれかを参照し、通常時の集約は同じTopicの現在有効な条件集合へ関連付ける。 | 判定の生成・更新、複数条件の集約、正常完了可否、状態遷移を定めない。 |

## 現行充足判定の整合条件

- 現行充足判定は、通常時には当該Topicの現在有効な完了条件だけに関連付ける。条件なし例外では、条件がないこと自体を判定として補わず、既知内容の確認と新たな検討対象がないことを意味上確認できる場合だけ、L2-M2-S3に従う論点単位の現行充足判定を関連付けられる。
- 完了条件ごとの判定値は、現スコープ、確認済みDecisionおよび未確認事項と意味上照合できる。背景と決めたいことは、条件を設定した理由と到達点を説明する文脈として関連付ける。
- 条件集合の集約判定および論点単体の正常完了可否は、別の現行情報として本書で新設しない。L2-M2-S3の判定規則を参照し、L4-M2-S2〜S3の状態・Decisionと二重の正本を作らない。
- 未評価・未記録の情報を、AI推測で背景、条件、未確認事項または判定値として補わない。

## 用語の分離

| 概念 | 本書での扱い | 分離先 |
| --- | --- | --- |
| 未確認事項 | Topicの文脈・到達点に関係する現行論理情報。0 件でもよい。 | 意味上の設定・変更・完了判定は L2-M2。 |
| 要確認 | L2-M1の状態軸値。曖昧入力などへの適用・解消は L2-M4およびL3-M4。 | L4-M2-S2。 |
| 理解停止Guard | 一時的な統制情報であり、永続状態または未確認事項ではない。 | L3-M3、L4-M2-S2。 |
| 充足・未充足・判断不能 | 完了条件に対する現行判定の値。永続状態語彙ではない。 | 意味・集約・正常完了可否は L2-M2-S3。 |

## 責務境界

- 完了条件の意味上の入力、初期設定、条件なし例外は L2-M2-S1、変更・旧判定非流用・再判定は L2-M2-S2、充足判定・集約・正常完了可否は L2-M2-S3 が所有する。
- 状態割当・現在地・復帰先は L4-M2-S2、Decision・保留・対象外は L4-M2-S3、Proposalとユーザー3判断は L4-M2-S4 が所有する。
- 生成・更新・承認のActorおよび理解停止・曖昧入力の統制は L3、旧版・Event・ChangeSetは L4-M3、Undoは L4-M4、復元の採用と単位は L4-M5 が所有する。
- 文面、物理ID、保存形式、DB Schema、API、表示方式、試験・測定は L8、L6、L5、L7 がそれぞれ所有する。
