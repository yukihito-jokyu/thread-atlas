# L4-M5-S1: FR-020の7復元対象とEntity／Projection対応

## 目的

FR-020が利用者から確認できる復元対象として列挙する7項目を増減せず、既存の論理Entity、RelationおよびProjectionへ対応付ける。これにより、復元後に同じ論理正本を参照でき、議論マップを別の正本として作らない。

本書は各対象を復元する方式、順序、保存形式または表示方法を定めない。

## 共通前提

- 対象は一つの未完了Sessionである。Session、発言、ターン、Topicの論理識別と所属は `L4-M1-S1〜S2`、Topicの親子・派生Relationと議論マップProjectionの境界は `L4-M1-S3` を参照する。
- 「論理正本」はEntityおよびRelationとして保持する情報を指す。Projectionは論理正本を参照して確認可能にする結果であり、Projectionの追加・欠落・並びから論理正本を補完または更新しない。
- 7対象のいずれも、新たな状態、Entity型または第8の復元対象を導入しない。状態・完了条件・履歴は、対応する既存の横断Relationとして参照する。

| 会話 | 同一Sessionに所属する発言およびターン、発言・ターンの論理順序、Topicとの会話Relation（`L4-M1-S1〜S2`）。 | Session内の会話と、その会話が関係するTopicを確認できる。 | 会話の順序や文面から、親子、現在地、状態、Decision、完了を推測しない。 |
| 議論マップ | 同一SessionのTopic、親子Relationおよび派生Relation（`L4-M1-S3`）。 | ルートから各Topicへ至る階層構造と派生上の関係を確認できる。 | Projection自体を正本にせず、表示上の近接・選択・並替からTopicまたはRelationを生成・変更しない。 |
| 現在地 | 同一Sessionの論理上の現在地TopicとのRelation（`L4-M2-S2`）およびその到達経路（`L4-M1-S3`）。 | 復元時点で通常進行の対象となる一意のTopicとルートからの経路を確認できる。 | 現在地を表示フォーカス、復帰先、完了、通常進行の開始と同一視しない。 |
| 決定事項 | 同一Sessionの通常TopicとDecisionのRelation、Decisionの内容・理由・根拠（`L4-M2-S3`）。 | Topicに関係するDecisionとその根拠を確認できる。 | Decisionの存在だけから、Topicの正常完了、状態変更、現在地移動または親復帰を導かない。 |

| 未完了論点 | 同一Sessionの通常Topic、状態軸、現行完了条件・未確認事項・現行充足判定とのRelation（`L4-M2-S1〜S2`）。 | 通常完了していないTopic、現在の検討内容および再開に必要な文脈を確認できる。 | 「未完了」を追加の永続状態にせず、Topicの存在だけから正常完了、保留、現在地または再開を確定しない。 |

## 正本一意性と横断参照

- 会話、Topic、Decision、保留の判断結果およびProposalは、それぞれ対応表のEntity／Relationを正本とする。複数の復元対象に同じTopicや会話が現れても、複製された別Entityを作らない。
- 議論マップはTopicとRelationのProjectionであり、会話、現在地、Decision、保留、新規提案および未完了論点は、それぞれの正本を参照してProjectionへ現れてよい。ただし、マップを更新元にしない。
- 状態、完了条件、未確認事項、Event／ChangeSet、訂正・再判断・業務上取消およびUndoは、7対象を追加せず各正本との横断参照として扱う。現行／旧内容の選択、履歴・由来・Undoの整合は `L4-M5-S3`、Session単位の参照閉包は `L4-M5-S2` が定める。

## 責務境界

- Sessionの復元範囲、必要なRelationの参照閉包、孤立・循環・他Session混入の防止は `L4-M5-S2` が所有する。
- 現行正本とEvent／ChangeSet、訂正、Undo、根拠会話の横断整合は `L4-M5-S3`、復元後のL2不変条件と通常進行への再開条件は `L4-M5-S4` が所有する。
- 状態語彙・有効組合せ・完了可否・階層／現在地の意味はL2、Actor・承認・GuardはL3、履歴およびUndoの規則は `L4-M3〜M4` が所有する。
- Projectionの提示方式はL5、再開などの操作・APIはL6、受入評価はL7、物理ID、Serialization、DB取得、復元順、Transaction、欠損補正および障害復旧はL8が所有する。
