# L4-M4-S3: Undoの因果・参照依存閉包と拒否・連動規則

## 目的と共通前提

`L4-M4-S2`の全適用／全拒否規則を前提に、Undo候補ChangeSetから因果又は参照により整合を失う後続ChangeSetを判定する。Undo対象は、整合を保つ連動対象の閉包が一意に確定できる場合だけ、起点を含む連動Undo計画として扱える。一意に確定できない場合、必要な関係が欠ける場合又は無関係な変更を含める必要がある場合は、計画全体を拒否する。

本書の依存は`L4-M3-S2`の直接／派生原因及び`L4-M3-S4`の現行結果・由来を参照する論理関係である。物理的な参照解析、検出アルゴリズム、実行順、Transaction、Rollback及び補償は定めない。

## Rule

| Rule ID | 規則 | 非導出事項・Owner |
| --- | --- | --- |
| `L4-M4-S3-R-01` | 起点はS1で`可能`又は`条件付き`に分類され、S2に従い全体として扱うChangeSetに限る。`不可`、既Undo対象又はUndo自身を起点にしない。 | 起点選択のActor・操作はL3／L6、分類はS1が所有する。 |
| `L4-M4-S3-R-02` | 起点を戻すことで、後続ChangeSetの因果根拠、現行Entity／Relationの参照又は由来経路が整合しなくなる場合、その後続ChangeSetを連動候補にする。依存しない単なる後続時系列、同じSessionの無関係な変更及び表示上の近接は候補にしない。 | 会話時系列、物理時刻、表示は依存根拠にしない。因果・参照Relationの定義はL4-M3が所有する。 |
| `L4-M4-S3-R-03` | 各連動候補について同じ規則を反復し、起点から必要な因果・参照依存だけを辿った集合を依存閉包とする。閉包中の各ChangeSetはS2に従い全Eventを含める。 | 閉包内のEvent又はChangeSetの部分適用はS2が禁止する。 |
| `L4-M4-S3-R-04` | 依存閉包が一意に確定し、全ChangeSetがS1の分類及びS2の原子性に適合し、閉包外の変更を戻さず整合を維持できる場合だけ、閉包全体を連動Undo計画としてS2へ渡す。 | L2の有効状態・不変条件、L3の権限・Guard及び適用後の履歴整合はS4が判定する。 |
| `L4-M4-S3-R-05` | 依存Relationが欠ける・矛盾する、複数の異なる閉包が成立する、閉包に`不可`のChangeSetが含まれる、又は閉包外の変更も戻さなければ整合できない場合、連動Undo計画を全拒否する。 | 推測でRelationを補完しない。拒否理由の表示・記録、代替操作及び実行障害の扱いは後続Ownerへ残す。 |

## 依存閉包表

| 観測された関係 | 連動対象への扱い | 許されない読み替え |
| --- | --- | --- |
| 起点ChangeSetを直接又は派生原因として必要とする後続ChangeSet | 整合を失うなら連動候補とし、R-03で必要な閉包へ含める | 同じ時刻帯・同じ会話ターンだけで依存とみなすこと |
| 起点が更新した現行Entity／Relation又は由来を、後続ChangeSetが意味上参照する関係 | 起点のみのUndoで参照整合を失うなら連動候補とする | 表示された近接、同名又は内容の類似だけで参照と推測すること |
| 起点と無関係な後続ChangeSet | 閉包に含めない | 「後に起きた」だけで一括Undoすること |
| Relation不足・矛盾・閉包の分岐又は`不可`対象への到達 | 計画全体を拒否する | 一部を省略し、別のChangeSetを任意に足して適用すること |

## 後続責務との分離

- S3は連動対象の論理集合及び拒否／連動の条件を定めるだけで、Undoの逆変更内容、適用順又は実行結果を定めない。S2が全適用／全拒否、S4がUndo後のL2/L3整合・新Event／ChangeSet・履歴保持を所有する。
- 訂正、再判断及び業務上取消は後続ChangeSetとして保持され、依存根拠になり得るが、Undoへ読み替えない。これらをUndo候補にできるかはS1の条件付き分類及び本書の閉包規則による。
- Redo、時間制限、物理的な依存検索、Transaction、Rollback、補償、保存形式、UI又はAPIを追加しない。

## Task固有Review

- [x] 因果・参照依存だけを連動候補とし、単なる後続・無関係変更を除外した。
- [x] 一意な依存閉包だけを連動Undo計画とし、欠損・矛盾・分岐・不可対象では全拒否とした。
- [x] Event／ChangeSetの部分適用、推測補完及び無関係変更の巻込みを禁止した。
- [x] S2の原子性、S4の事後整合、L2/L3/L6/L8の責務を先取りしていない。
