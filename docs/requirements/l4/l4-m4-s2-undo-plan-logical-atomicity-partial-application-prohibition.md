# L4-M4-S2: Undo計画の論理原子性と部分適用禁止

## 目的と共通前提

`L4-M4-S1`で`可能`又は`条件付き`に分類されたChangeSetだけを、Undo計画の候補にできる。本書は、選択ChangeSet又は後続Taskが必要と判断した連動対象を一つの論理的なUndo計画として扱い、全適用又は全拒否だけを許す。因果・参照依存に基づく連動対象と動的可否は`L4-M4-S3`、適用後のL2/L3整合と履歴Relationは`L4-M4-S4`が所有する。

論理原子性は、物理的なTransaction、障害時Rollback、補償、保存方式又は実行順を意味しない。これらは`L8`が所有し、操作の起動・API・UIは`L6`、実行権限・Guardは`L3`が所有する。

## Rule

| Rule ID | 規則 | 後続Owner・非導出事項 |
| --- | --- | --- |
| `L4-M4-S2-R-01` | Undo計画は、選択した一つの分類済みChangeSetを起点として、単独計画又は連動計画として定義する。起点が`不可`なら計画を拒否する。 | `条件付き`の動的可否、連動対象及び拒否理由はS3、L2/L3の適用可否はS4が定める。 |
| `L4-M4-S2-R-02` | 単独計画は、選択ChangeSetに所属する全Eventを一体として全適用又は全拒否する。所属Eventの一部だけを戻す計画、同一Eventの変更前後の一部だけを戻す計画、又は任意のEntity／Relationだけを選ぶ計画を作らない。 | Eventの対象・ChangeSet所属・順序・因果はL4-M3が所有する。逆変更の内容・実行手順を定義しない。 |
| `L4-M4-S2-R-03` | 連動計画は、S3が一意に認めた各ChangeSetを全て含め、一つの計画全体として全適用又は全拒否する。連動対象の一部だけを適用又は拒否して残りを適用することを許さない。 | 依存閉包の検出、一意性、無関係な後続を含めない条件はS3が所有する。 |
| `L4-M4-S2-R-04` | 計画に含まれるいずれかのChangeSet又はEventについて、全体として扱えないこと、必要な連動対象が未確定であること、又は後続Ownerの条件を満たせないことが分かった場合、計画全体を拒否する。 | 失敗の検出方法、実行中の障害、部分成功後の回復・補償はL8が所有する。 |
| `L4-M4-S2-R-05` | 全拒否は、選択対象、含まれるEvent、現行値、状態、Decision、親子、現在地又は履歴を変更しない。全適用が可能と判断されたこと自体も、正常完了、親復帰、Guard解除、Proposalの論点化又は訂正の確定を導かない。 | L2の状態・遷移・構造不変条件、L3のActor・Guard、S4の適用後整合を先取りしない。 |

## 原子性表

| Undo計画の対象 | 計画として許す単位 | 禁止する部分適用 | 結果の扱い |
| --- | --- | --- | --- |
| 単独ChangeSet | そのChangeSetに所属する全Event | Event単位、Event内の属性単位、Entity／Relation単位の選択 | 全Eventを対象にした全適用、又は全拒否 |
| 複数Entity／Relationを更新した単独ChangeSet | 同じChangeSetに含まれる全変更 | Topicだけ、Decisionだけ、親子だけ、現在地だけ又は会話関連だけを抜き出すこと | 全変更を一体として全適用、又は全拒否 |
| S3が認める連動ChangeSet群 | 起点及び連動対象の全ChangeSetと各所属Event | 起点だけ、連動先の一部だけ、又は順序の一部だけを対象にすること | 計画全体を全適用、又は全拒否 |
| `不可`のChangeSet又は連動対象が未確定・不整合な計画 | 計画を作らない | 可の部分だけを救済して適用すること | 全拒否。理由・表示・記録方式は後続Ownerへ残す |

## 非Undo変更及び後続責務との分離

- 訂正、再判断及び業務上取消は、過去ChangeSetの一部を逆に適用する計画へ読み替えず、後続ChangeSetとして扱う。これらを含む候補の`条件付き`分類と動的可否はS1／S3に従う。
- Undo計画はRedo、時間制限、履歴巻戻し又は物理Rollbackを導入しない。Undo自身を新Event／ChangeSetとして記録し、元対象・旧Event・根拠会話を保持する責務はS4に残す。
- S2は、計画に採用するChangeSet集合と論理的な全適用／全拒否だけを定める。因果・参照依存の閉包、L2の有効状態・不変条件、L3の基準権限・Guard、実行後の現行正本を判定しない。

## Task固有Review

- [x] 選択ChangeSet及び連動Undo計画を全適用／全拒否に限定した。
- [x] 所属Event、Event内変更、Entity／Relation及び連動対象の部分適用を禁止した。
- [x] 物理Transaction・Rollback・補償、依存閉包、L2/L3整合、履歴Relationを後続Ownerへ残した。
- [x] Redo、時間制限、保存方式及び操作・UI/APIを追加していない。
