# L4-M2-S2: 状態・現在地・復帰先・一時Guardの論理関係

## 目的

Topicに割り当てる状態軸値、Sessionの論理上の現在地、Topicの復帰先および理解停止Guardを、相互に同一視しない現行論理情報として関連付ける。

## 関係表

| 情報 | 所属・Cardinality | 関係と不変条件 | 導かないこと |
| --- | --- | --- | --- |
| 状態軸値 | 各Topicは、L2-M1が定める各状態軸について 0..1 の現行値を持つ。未評価・未記録は未設定とする。 | 値域内は一値だけであり、軸間の有効組合せはL2-M1-S3に従う。 | 現在地、復帰先、完了、Decision、Guard成立を導かない。 |
| 論理上の現在地 | 各Sessionは通常進行時に 1 件の現行Topicを持つ。通常進行しない時点は 0 件を許す。現在地Topicは同一Sessionに属する。 | 現在地にはルートからの一意な到達経路がある。表示フォーカスとは異なる。 | 状態値、親復帰、完了、表示選択を導かない。 |
| 復帰先 | 各Topicは 0..1 の復帰先Topicを持てる。復帰先は同一Session・同一ルートの既存の直接親であり、ルートは持たない。 | 現在地と同一視せず、親子Relationと整合する。 | 復帰、現在地変更、通常進行開始、完了を導かない。 |
| 理解停止Guard | 有効な理解停止Guardは、ちょうど一つのSession、その一意な現在地Topicおよび通知時点の文脈に結び付く一時制御情報である。各Session（またはその現在地Topic・文脈）は有効Guardを 0..1 件だけ持てる。 | 永続状態軸値ではなく、Sessionの現在地・親子・復帰先を変更しない。 | 未確認事項、要確認、状態値、履歴Event、解除、通常進行再開を導かない。 |

## 整合条件

- 状態軸値の意味、軸内排他、軸間組合せ、完了との関係はL2-M1、完了可否はL2-M2が所有する。
- 現在地・復帰先はL2-M3の単一ルート、親一意、循環・孤立禁止、現在地一意および直接親制約を満たす。変更Trigger・Guard・遷移はL2-M4が所有する。
- 親を持つTopicが正常完了し、その直後に通常進行を継続する場合、現行現在地は直接親へ関連付く。ルートTopicの正常完了後は、親・復帰先または新たな現在地を生成しない。完了可否はL2-M2、これらの構造事後条件はL2-M3-S2、Trigger・許可・遷移はL2-M4だけが所有する。
- 理解停止Guardの成立・維持・明示解除はL3-M3が所有する。曖昧入力はL3-M4へ委譲し、Guardを暗黙解除しない。
- 中断は状態軸へ追加せず、再訪・復元時も現在地・到達経路・復帰先との意味上の対応を保持する。履歴・保存・復元単位はL4-M3〜M5が所有する。

## 責務境界

- 本書は現行情報の所属・Cardinality・非同一性だけを定義する。状態意味・遷移=L2、Actor/承認/Guard規則=L3、Event・旧版=L4-M3、Undo=L4-M4、復元=L4-M5へ残す。
- Entity識別、Session所属、親子RelationはL4-M1、Decision・保留・対象外はL4-M2-S3、ProposalはL4-M2-S4が所有する。
- 表示、API、物理Schema、試験はL5、L6、L8、L7が所有する。
