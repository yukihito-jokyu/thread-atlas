# L4-M5-S2: Session単位の復元範囲と参照閉包

## 目的

一つの未完了Sessionを復元単位とし、FR-020の7対象を確認するために必要な構造・文脈Relationの参照閉包を定める。個別のEntityだけを取り出して、親子、現在地、Proposal由来または会話根拠を切断しない。

本書はDB取得範囲、復元順、Transaction、欠損補正または物理的な復元方法を定めない。

## 復元単位

- 復元対象は、一つの未完了Sessionと、そのSessionに所属する既存の論理正本だけである。別SessionのEntity、Relation、会話、Decision、ProposalまたはChangeSetを混在させない。
- Session内のEntityとRelationは、`L4-M1〜M4` が定める論理識別、所属、Cardinalityおよび同一Session制約を満たす。参照が別Sessionを指す、端点が存在しない、または同一Entityを複製する状態は復元可能な閉包としない。
- 7対象の対応は `L4-M5-S1` を入力とする。本書は第8対象や新しい状態を追加しない。

## 構造・文脈参照閉包表

| 確認する対象 | 同じSessionで閉包に含める正本・Relation | 閉包が満たす条件 | 閉包から導かないこと |
| --- | --- | --- | --- |
| 会話 | 発言、ターン、両者の論理順序、発言／ターンからTopic・Eventへの既存Relation。 | 会話の各項目は所属Sessionと順序を確認でき、関連するTopicまたは変更の由来を失わない。 | 会話の欠落箇所を生成・補完せず、文面や順序から状態・親子・Decisionを推測しない。 |
| 議論マップ | Topic、ルート、親子Relation、派生Relation、および各Topicがルートへ至る既存経路。 | 非ルートTopicは親を一つ持ち、循環・孤立・別Session接続なしにルートから到達できる。 | ProjectionからTopicやRelationを新設・更新せず、表示上の位置を現在地にしない。 |
| 現在地・復帰先 | 現在地Topic、ルートからの到達経路、当該Topicの既存復帰先と直接親。 | 通常進行時は現在地が一つであり、復帰先は同じルートの既存直接親、ルートは復帰先なしを確認できる。 | 現在地・復帰先を理由に通常進行、親復帰、完了または状態変更を実行しない。 |
| 決定事項 | 通常Topic、現行Decision、およびDecisionの理由・根拠への既存参照。 | Decisionは対応Topicと同じSessionに属し、内容・理由・根拠を切断しない。 | 旧Decisionを現行へ補正せず、Decisionから完了、現在地変更または親復帰を導かない。 |
| 保留事項 | 通常Topic、現行保留判断結果、および保留の理由・根拠への既存参照。 | 保留判断結果は対応Topicと同じSessionに属し、Decisionや対象外の正本と複製しない。 | 保留を中断、対象外、解除または通常進行の再開と同一視しない。 |
| 新規提案 | Proposal、派生元Topic、必須情報、現行3判断、論点化済みなら生成Topicと由来Relation。 | Proposalと生成Topicは別Entityのまま由来を確認でき、未承認Proposalの必要情報と判断を切断しない。 | Proposalを通常Topic・現在地・Decision・現スコープへ暗黙昇格させない。 |
| 未完了論点 | 未完了の通常Topic、現行の状態軸値、完了条件、未確認事項、現行充足判定、現在地・復帰先との既存Relation。 | 未完了の検討内容と再開に必要な経路・文脈を確認でき、状態軸の有効組合せを損なわない。 | 未完了を新たな永続状態にせず、条件・判定から正常完了や再開を確定しない。 |

## 横断的に閉じる既存参照（FR-020対象外）

Event、ChangeSet、訂正・再判断・業務上取消の新旧Relation、根拠会話RelationおよびUndo Relationは、7対象の各現行正本が既に持つ横断参照である。復元範囲ではその端点を同じSession内で確認できるよう閉じるが、これらをFR-020の第8対象にしない。

- 横断参照により、各対象の旧内容・根拠会話・有効Undo結果への既存参照を失わせない。
- 現行／旧内容の選択、Event・ChangeSet、訂正・再判断・取消、根拠会話およびUndo Relationの採用整合は `L4-M5-S3` が所有する。本書は参照を閉じる条件だけを定める。
- 横断参照だけから、現行値の選択、Undo可否または適用を決めない。

## 閉包の整合条件

- 閉包は、必要なRelationを端点まで同一Session内で確認できる範囲とする。端点の欠落、親子循環、孤立Topic、複数現在地、無効な状態組合せ、Proposalと生成Topicの同一視、または別Session混入があれば、参照閉包が成立したと扱わない。
- Relationの存在だけから未記録のEntity、理由、根拠、会話、状態値または判断結果をAI推測で補完しない。
- Projectionは閉包に含まれる正本を参照するだけで、正本の欠落をProjectionから補わない。

## 責務境界

- 7対象と既存正本の対応は `L4-M5-S1`、現行正本・履歴・由来・Undo参照の横断整合は `L4-M5-S3`、復元後のL2不変条件と通常進行への再開は `L4-M5-S4` が所有する。
- 階層・現在地・復帰先・状態・完了の意味と遷移はL2、Actor・承認・GuardはL3、各Entity／Relation、Event・ChangeSet、Undoの個別規則は `L4-M1〜M4` を参照する。
- DB取得範囲、復元順、Transaction、物理ID、Serialization、欠損補正、障害復旧はL8、提示はL5、操作・APIはL6、評価はL7が所有する。

## 要件対応とTask固有Review

- Issue #1 FR-020、FR-013、FR-018〜019、NFR-004／006に対し、一Session内で7復元対象に必要な構造・文脈・履歴参照を閉じる条件を定めた。
- [x] 一Sessionを復元単位とし、別Session混入、孤立、循環、端点欠落および複製正本を禁止した。
- [x] 7対象ごとに必要な構造・文脈Relationを対応付け、未承認Proposal・現在地・親子・由来を切断しない。
