# L6-M3-S5: 照会結果の意味分類・推定補完禁止契約

## 目的

L6-M3-S1〜S4の照会結果について、成功、対象不存在、情報欠落、該当なし、権限不足、部分取得及び利用不能を区別し、取得できない値をAI又は利用者が正本として推定補完しない契約を定める。

## 共通結果分類

| 結果 | 意味 | 取得済み／不足範囲 | 導かないこと |
| --- | --- | --- | --- |
| 成功 | 指定対象について、要求した記録済み正本又はRelationを参照できた。 | 返却された記録済み範囲を取得済みとして区別する。 | 対象外の情報、未記録情報又は将来の変化を完全に含むとみなさない。 |
| 対象不存在 | 指定したTopic、Proposal、Decision、Event、ChangeSet、Session又はRelation端点が記録済み対象として存在しない。 | 対象自体が存在しないことと、既存対象の情報不足を分ける。 | 表示名、近接対象又は履歴から代替対象を選ぶこと。 |
| 情報欠落 | 対象は記録済みだが、要求した属性、Relation、根拠、理由又は値が記録済み参照として存在しない。 | 対象は取得済み、欠落した項目だけを不足範囲として区別する。 | 欠落を不存在、否定値、空のDecision、根拠なしの理由又は状態値として補完すること。 |
| 該当なし | 照会条件を満たす記録済み対象がない。 | 照会可能な範囲と、その範囲内で該当がないことを区別する。 | 全Session、未知範囲又は未取得範囲に該当がないと一般化すること。 |
| 権限不足 | 対象又は情報は存在し得るが、該当するActorの権限・Guardにより参照を許可しない。 | 許可されなかった範囲を不足範囲として区別する。 | 対象不存在、情報欠落、状態変更又は権限の暗黙付与。 |
| 部分取得 | 対象又は照会範囲の一部だけを記録済み結果として参照できた。 | 取得済み部分と未取得部分を分ける。 | 取得済み部分を全体、完全な履歴、完全な部分木又は完全な根拠集合とみなすこと。 |
| 利用不能 | 処理又は参照先が利用できず、照会結果を確定できない。 | 利用不能な対象又は範囲を他の取得済み結果と区別する。 | 対象不存在、該当なし、情報欠落又は権限不足への置換、過去結果の現行採用。 |

## 整合条件

- 各結果は照会時点の記録済み参照範囲に対する意味であり、状態、Decision、Proposal判断、完了、現在地、構造又はスコープの新たな語彙・値ではない。
- 情報欠落と、記録済み参照が0件である根拠会話・Actor・Ruleは同じく補完しない。不存在、未記録、利用不能その他の理由を、追加の記録がない限り推測しない。
- 権限不足の判定、Actor、Guard及び許可はL3が、対象と正本・Relation・履歴はL4が、対象不存在等の検出方式、再試行、検索、API、UI及びエラー処理はL8が所有する。
- S1〜S4は本書の意味結果を用いて照会対象ごとの成功又は不足を返せるが、本書は再説明、構造探索、履歴選択、表示コンテキスト又は結果の復旧を実行しない。

## 責務境界

- L2/L3は状態・遷移、判断、Actor、承認及びGuardを、L4はEntity、Relation、現行正本、履歴及びUndoを所有する。本書はそれらの意味を再定義しない。
- L5は結果の提示、優先、要約及び表現を所有する。L6-M3-S1〜S4は照会対象と論理結果を、S5は結果の意味区分だけを所有する。
- L8はQuery実装、検索、Pagination、エラー分類の検出、再試行、API、UI及び障害処理を所有する。本書は技術的な例外形式又は回復手順を定めない。

## Task固有Review

- 成功、対象不存在、情報欠落、該当なし、権限不足、部分取得及び利用不能を相互に区別した。
- 取得済み範囲と不足範囲を分離し、欠落値・空結果・過去結果を正本として補完しないことを確認した。
- 状態・判断・正本・表示・Query実装の各Ownerを再定義せず、全照会共通の意味結果に限定した。
