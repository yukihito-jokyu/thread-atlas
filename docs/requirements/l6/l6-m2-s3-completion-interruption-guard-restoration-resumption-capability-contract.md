# L6-M2-S3: 離脱・Guard成立／解除・再開のCapability契約

## 目的

正常完了・親復帰、未完了中断・再訪、理解停止、復元後再開を、状態を不正に補正せずに実行できるCapabilityとして定める。

## 共通契約

- Capabilityは対象と利用者の明示意図をL2の許可遷移・構造条件、L3のActor・Guardへ渡す。満たさない場合、ToolはL4へ更新を記録せず、現在地・状態・構造を変更しない。
- 成功時はL2が定める状態・現在地・復帰先の効果だけをL4の現行正本とChangeSetへ記録する。UIの選択、AI推測、無応答、時間経過、復元事実だけから実行しない。
- 中断と理解停止を永続状態にしない。理解停止の維持中の再説明・補足・理解確認は許すが、通常進行、次論点開始、決定更新、正常完了を導かない。

## 責務境界

- 理解停止の成立・維持・解除、曖昧・競合入力はL3が所有する。再説明はL6-M3、復元整合はL4、復元方式・障害時配送はL8/L6-M4が所有する。
- 正常完了可否はL2-M2、構造事後条件はL2-M3、遷移はL2-M4、Actor・承認はL3、Entity・履歴・保存・UndoはL4が所有する。本書はそれらを再定義しない。
- UI表示はL5、公開API・Schema・実装方式はL8、受入・測定はL7へ残す。
