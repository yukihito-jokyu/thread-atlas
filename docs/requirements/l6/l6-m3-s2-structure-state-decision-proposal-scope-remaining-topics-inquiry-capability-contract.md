# L6-M3-S2: 議論構造・状態・判断・提案・スコープ・残り論点照会Capability契約

## 目的

同一Sessionの任意論点、部分木又は議論全体について、記録済み正本に基づく構造、状態、Decision、Proposal、スコープ及び既知の残り論点を横断して照会するCapabilityを定める。

## 対象と共通契約

- 対象は同一Session内の任意の通常Topic、部分木又は全体とする。現在論点だけのSnapshotと背景再説明はL6-M3-S1、履歴・根拠会話はL6-M3-S3が所有する。
- 照会はL4が保持する記録済み現行正本及びRelationを参照する。会話順、表示近接、履歴の新しさ、欠落又は部分木の外側から、親子、派生元、状態、Decision、Proposal、スコープ又は残り論点を推測補完しない。
- 照会だけでは、現在地、状態、完了条件、充足状況、Decision、Proposal判断、親子、派生、復帰先又はスコープを変更しない。対象の不存在、情報欠落、該当なし、権限不足、部分取得又は利用不能の意味結果はL6-M3-S5が所有する。
- 状態・判断の意味、遷移、Guard及びActor・承認はL2/L3、Entity・Relation・現行正本・履歴はL4、提示・集約・優先はL5、Query・検索・API・Pagination・UIの具体方式はL8が所有する。

## 横断整合条件

- 親子Relationは構造経路、派生Relationは由来として別に照会する。部分木の外側にある親・祖先又は派生元が記録済みRelationで参照できない場合に、近接情報で補わない。
- 状態、Decision、Proposal及び論点完了は別情報として取得する。決定済みだけから完了、完了だけからDecision、Proposalの登録・表示だけから通常Topic又は現スコープ内化を導かない。
- 残り論点はL5-M1-S3が定める既知集合・包含／除外根拠を参照する。残り程度は見積り方式を定めず、未知又は未記録の範囲を完全性の保証に変換しない。
- 復元後も同一Sessionの現行正本及び成立済みRelationから同じ照会対象を参照できる。旧内容、Undo前の値、履歴上の後続又は欠落Relationを現行情報として採用しない。

## 責務境界

- L6-M3-S1は現在論点だけのSnapshotと、その項目に対応する背景再説明を所有する。本書は任意Topic・部分木・全体の照会に限定し、再説明を生成しない。
- L6-M3-S3は変更履歴、現行／旧結果、順序、主体、理由及び根拠会話を所有する。本書は記録済みの現行正本及びRelationを照会するが、履歴から現行を選択しない。
- L5は情報提示の優先、集約、残り程度の表現及び表示コンテキストを所有する。本書は照会可能な論理情報を定め、表示順・フォーカス又は要約を定めない。
- L2/L3は意味、許可、遷移、Guard、Actor及び承認を、L4は論理正本とCardinalityを、L8はQuery実装・検索・API・UIを所有する。

## Task固有Review

- 任意Topic・部分木・全体の構造、状態、Decision、Proposal、スコープ及び残り論点を、現在論点Snapshot・履歴照会と重複させずに照会対象化した。
- Decision、Proposal、状態及び論点完了を別情報として取得し、照会から遷移、判断、昇格又はスコープ変更を導かないことを確認した。
- 既知集合、未知範囲、記録済み由来及び現行正本を参照し、欠落、会話順又は履歴から補完しないことを確認した。
