# L6-M3-S4: 表示コンテキスト・フォーカス・選択・会話参照Capability契約

## 目的

論理的現在地や議論状態を変更せず、議論全体又はフォーカスの表示コンテキスト、対象選択及び対応会話参照を切り替えて照会するCapabilityを定める。

## 対象と共通契約

- 本Capabilityは全体／フォーカス、表示フォーカス、選択対象及び会話参照を別の論理的コンテキストとして扱う。論理的現在地、表示フォーカス、選択対象及び会話参照を同一視しない。
- 切替前後に、記録済みの現在論点、ルートからの接続、未完了内容及び選択対象との対応を再識別できる。現在論点が0件の時点を、選択又は表示フォーカスから補完しない。
- 複数表現方式はMVPで必須ではない。採用する場合だけ、同じ記録済み正本を参照する表現方式の切替を照会できる。方式の種類、配置、図法及びUI部品はL8が所有する。
- 切替、選択又は会話参照だけでは、状態、Decision、Proposal判断、現在地、親子、派生、復帰先、完了、スコープ又は履歴を変更しない。

## コンテキスト照会契約

| コンテキスト | 照会できる記録済み情報 | 導かないこと |
| --- | --- | --- |
| 全体／フォーカス | 同一Sessionの全体構造又は指定Topic・部分木の構造、上位接続及び既知の未完了内容 | 表示範囲外の削除、現在地変更、未知Topicの生成又は残り論点の完全性保証 |
| 表示フォーカス | 表示上の注目対象と、同一ルート内の上位経路・周辺の記録済み構造 | 論理的現在地への設定、選択対象との同一視、状態・構造変更 |
| 選択対象 | 記録済みTopic、Decision、Proposal、判断結果、ChangeSet又は会話参照を対象とした照会コンテキスト | Proposalの論点化、Decision化、スコープ内化、選択したTopicの通常進行開始 |
| 会話参照 | 選択又は照会結果からL4の由来Relationを介してたどる根拠Event・起点発言／ターン | 会話順から状態・現在地・親子・理由を補完すること、会話から全影響結果の逆引きを必須化すること |
| 条件付き表現方式 | 採用済みの表現方式について、同一の構造・状態・結果を参照する方式コンテキスト | 複数方式の採用必須化、方式ごとの正本複製、切替による状態更新 |

## 整合条件と責務境界

- 表示コンテキストはL5の情報配分・優先・不変条件に従う。本書は論理的な参照範囲と非変更条件を定め、表示順、集約、要約又はフォーカス配分を定めない。
- 対象選択はL6の照会対象を指定するだけであり、L2の許可遷移、L3のActor・承認・Guard、L4の正本Relationを迂回しない。
- 会話参照はL6-M3-S3の結果→根拠Event→起点会話の経路を参照する。履歴、現行／旧結果、因果又はUndoの選択・解釈はS3及びL4が所有する。
- Query、状態保持、画面遷移、選択操作、表現切替操作、UI及びAPIはL8が所有する。対象不存在、情報欠落、該当なし、権限不足、部分取得又は利用不能の意味結果はL6-M3-S5が所有する。
