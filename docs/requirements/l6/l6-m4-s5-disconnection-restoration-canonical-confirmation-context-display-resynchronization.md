# L6-M4-S5: 途絶・復元後の正本確認／参照文脈・表示再同期契約

## 目的

要求、正本更新又は応答の前後で途絶した場合に、最後のAI参照文脈、会話又はUI表示を正本と誤認しない。再接続又はSession復元後はL6-M3の照会で記録済み正本を確認し、過去会話を書き換えずAI参照文脈と表示Projectionを再同期する。正本と会話上の更新主張が異なる場合は差異を通知し、通常進行を確定扱いで続けず、修復を明示的な別操作へ渡す。

## 共通前提

- 更新・照会の確認点はS1、失敗・部分到達・結果不明はS2、競合・古い参照はS3、再試行・重複はS4に従う。途絶又は復元はL2の業務状態、Decision、Proposal判断、完了又は現在地を新設・変更しない。
- 正本はL4が記録済みの正本・Relation・現行結果である。AI参照文脈、会話上の主張、表示Projection、UIローカル状態又は過去応答だけから正本を補完・更新しない。
- 途絶検出、再接続、Session復元、Snapshot、再同期の通信・保存・順序・障害復旧方式はL8が所有する。本書は意味上の確認・通知・通常進行停止条件だけを定める。

## 途絶状態と正本確認・再同期条件表

| 途絶した時点 | 正本・会話・応答の扱い | 再接続／復元後の条件 | 導かないこと |
| --- | --- | --- | --- |
| 要求受理前又は要求未確認 | 要求が生じたかを会話・UIだけから確定しない。 | 記録済み要求又は正本をL6-M3で照会し、確認できない場合は要求未確定として扱う。 | 要求の生成、更新の推測、会話の書換え。 |
| 正本更新前 | 未検証・処理中要求は更新済みを意味しない。 | L4正本を照会し、反映済み確認点を確認できるまで再適用・成功通知をしない。 | 途絶前要求の自動実行、失敗又は拒否への推測。 |
| 正本更新後・応答前 | 正本反映済みでも、要求元・AI・UIが結果を受け取ったとは限らない。 | 同じ確認点の正本を照会し、AI参照文脈・表示を再同期する。 | 正本更新の取消、応答未到達を業務失敗とすること、重複適用。 |
| 応答後・表示前又は表示不明 | 会話又はAI応答は存在しても、表示が正本と整合するとは限らない。 | 記録済み正本の照会結果を基準に表示Projectionを再同期する。 | 表示・会話から正本を採用すること、表示未到達の推測補完。 |
| 照会中又は照会結果の一部到達 | 照会結果の範囲・完全性・利用可能性を推測しない。 | L6-M3-S5の結果分類を参照し、同じ確認点の正本を再照会できるまで確定表示・通常進行をしない。 | 部分結果の完全化、照会結果による正本更新。 |
| Session復元後に正本と会話上の更新主張が異なる | 会話記録と正本の双方を保持し、どちらかを暗黙に書換えない。 | 差異を通知し、通常進行を確定扱いで再開しない。修復は明示的な別操作へ渡す。 | 会話の削除・訂正、正本の自動上書き、AIによる差異解消。 |
| 正本、参照文脈又は表示を同じ確認点で確認できない | 成功・失敗・拒否又は整合済みを推定しない。 | 再同期未了として扱い、通常進行の質問・更新・完了へ進めない。 | 古い文脈による通常進行、再試行・修復の自動実行。 |

## 再同期と通常進行停止の整合条件

- 再同期は、L6-M3で照会した記録済み正本・RelationをAI参照文脈及び表示Projectionと同じ確認点へ対応付けることを意味し、正本又は会話を変更する操作ではない。
- 正本と会話上の更新主張、AI参照文脈又は表示が異なる場合は、差異の存在を確認可能にする。差異の理由、優先、訂正、取消又は修復内容を推測しない。
- 差異が未解消、照会結果が部分的・利用不能、又は同じ確認点を確認できない間は、通常進行の質問、次論点開始、状態変更、Decision、Proposal判断、完了又は親復帰を確定扱いで実行しない。
- 修復、訂正、再判断、再試行又は再適用は、ユーザーの明示意図及び該当するL2/L3/L6経路へ渡す。再同期だけからGuard解除、承認、権限付与又は業務変更を導かない。
- 再同期が同じ確認点の正本・AI参照文脈・表示Projectionに整合した後も、更新又は照会の通常処理はS1の確認点、競合はS3、再送はS4に従う。

## 責務境界

- L2は状態・遷移・構造・完了・Guard、L3はActor・承認・明示訂正、L4は正本・会話履歴・Relation・ChangeSet・Undoを所有する。本書は途絶後の確認と再同期条件だけを定める。
- L6-M3は正本照会と結果分類を、S2は失敗・部分到達、S3は競合・古い参照、S4は再試行・重複を所有する。本書は照会・修復・再試行を実行しない。
- L5は差異・再同期・停止の提示内容を、L7は時間・成功率等の測定を、L8は接続、復元、Snapshot、保存、再同期、通信、Transaction及び障害復旧の方式を所有する。
