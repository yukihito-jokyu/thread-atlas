# L6-M2-S1 初期化・構造・文脈・完了条件の Capability 契約

## 目的

新しい Session の開始から通常進行に必要な初期構造、通常 Topic の構造・現在地、文脈及び完了条件を、論理能力として対応付ける。各能力は L2 の遷移・Guard、L3 の Actor・承認、L4 の正本・ChangeSet を参照し、それらを置き換えない。

## 共通契約

- 利用者又は AI の要求は、L6-M1-S3 の更新情報流に従って Tool へ渡る。Capability は API 名、引数 Schema、呼出順又は Transaction を定めない。
- Tool は、各能力に対応する L2 Guard と L3 の権限を満たす場合だけ、L4 の論理正本を更新する ChangeSet へ接続する。拒否時は正本を更新せず、未適用を適用済みとして通知しない。
- 「新規開始」は新しい Session の初期化であり、既存 Session の選択又は復元後再開ではない。後者は L6-M2-S3 が所有する。
- 通常 Topic の能力だけを扱う。未承認 Proposal の登録・三判断・論点化、状態の再活性化及び判断結果は L6-M2-S2 が所有する。

## Capability 契約表

| --- | --- | --- | --- | --- | --- | --- |
| Session を開始する | 新しい議論の目的と初期化に必要な入力 | 新しい Session、ルート及び最初の通常 Topic を通常進行の対象として扱える | L2-M3-S1 の単一ルート・親一意・到達可能性と、L2-M4-S1-T-01 の開始条件に従う | 初期構造作成に対する L3-M1-S2 の Actor・承認規則 | Session、Topic、初期構造・現在地に関する論理更新を 1 ChangeSet として扱う | 既存 Session の復元、既存 Topic の完了、Proposal の承認又は状態の直接設定 |

| 親子関係を設定・変更する | 同一 Session 内の親 Topic、子 Topic 及び関係の変更理由 | 子が一意の親を持ち、ルートから到達できる構造を保つ | L2-M3-S1 の単一ルート・親一意・非循環・非孤立条件に従う | 構造更新に対する L3-M1-S2 の Actor・承認規則 | 親子 Relation を対象 ChangeSet に含める | 派生元、復帰先、表示上の近接又は会話順から親子を導くこと |

| 完了条件を設定・変更する | 現スコープ、確認済み Decision、未確認事項、背景及び決めたいこと | 条件単位又は許可された条件なし例外を、対象 Topic の現行完了条件として扱える | L2-M2-S1 の初期設定・条件なし例外・評価可能性、変更時は L2-M2-S2 の再照合条件に従う | 完了条件更新に対する L3-M1-S2 の Actor・承認規則 | 完了条件と対象 Topic の現行 Relation を対象 ChangeSet に含める | 充足・未充足・判断不能の決定、正常完了、親復帰又は状態遷移 |
| 未確認事項を設定・変更する | 対象 Topic で確認が必要な内容と変更理由 | 未確認事項を文脈・完了条件の評価に参照可能な現行情報として扱える | L2-M2-S1 の評価可能性及び L2-M2-S2 の意味上の見直し条件に従う | 未確認事項の通常更新に対する L3-M1-S2 の Actor・承認規則 | 未確認事項と対象 Topic の現行 Relation を対象 ChangeSet に含める | 要確認状態、理解停止 Guard、Proposal、Decision、完了可否又は通常進行の停止 |
| 復帰先を設定・変更する | 対象 Topic の同一ルート上の直接親と、復帰先を扱う必要がある文脈 | 非ルート Topic の復帰先を既存の直接親として参照可能にする | L2-M3-S1 の直接親・同一ルート・ルートは復帰先なしという不変条件に従う | 復帰先を伴う構造更新に対する L3-M1-S2 の Actor・承認規則 | 復帰先と対象 Topic の現行 Relation を対象 ChangeSet に含める | 子孫・別枝・表示選択を復帰先にすること、親復帰又は現在地移動の実行 |

## 能力利用時の不変条件

- 各 Capability は意味入力、成功時の論理結果、L2 Guard、L3 権限及び L4 ChangeSet を対応付ける。Guard 不成立又は権限不足では論理更新を行わない。
- Capability の結果は、正本への反映後だけを成功として通知する。要求、検証中、拒否、未適用及び適用済みを混同しない。
- 構造、現在地、文脈及び完了条件は別の論理情報である。一方の設定・変更だけから、他方の設定・変更を推測又は暗黙実行しない。
- L2 の状態・遷移・Guard、L3 の Actor・承認、L4 の Entity・Relation・ChangeSet の内容は、それぞれの Owner だけが定める。本書は Capability 名に対応する能力 ID、API 又は共有索引を新設しない。

## 責務境界

- L6-M2-S2 は状態、Decision、Proposal、三判断及び再活性化、L6-M2-S3 は正常完了、親復帰、中断・再訪、理解停止及び復元後再開、L6-M2-S4 は訂正、再判断、業務取消、Undo と複合操作の原子性を所有する。
- L2 は構造・現在地・完了条件の意味、遷移及び Guard、L3 は Actor・承認、L4 は Entity・Relation・現行正本・ChangeSet・履歴を所有する。
- UI の提示・フォーカスは L5、照会・再説明は L6-M3、失敗・競合・再試行・同期は L6-M4、API・Schema・Transaction・実装方式は L8 が所有する。
