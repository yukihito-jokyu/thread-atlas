# L6-M1-S2: 会話／読取情報流

## 目的

利用者入力、AI 会話生成、会話記録、議論状態参照および UI 提示の正常系情報流を定める。会話ログへの追記と、議論状態を変更しない参照とを別の論理処理として扱う。

本書は L6-M1-S1 の Initiator、Executor、Validator、Canonical Updater、Presenter を用いる。Actor・承認の意味は L3、会話・議論状態の論理正本は L4 が所有する。

## 用語と共通条件

- **会話記録**は、利用者入力又は AI 応答を L4 の会話正本へ追記する論理処理である。会話本文を生成する処理ではない。
- **議論状態参照**は、L4 の既存の論理正本を読み取る処理であり、論点、親子・派生、現在地、状態、Decision、Proposal、完了条件又は履歴を更新しない。
- **議論状態更新**は本書の対象外であり、L6-M1-S3 の変更要求・検証・正本更新情報流だけが扱う。
- 同じ会話上の要求から会話記録と参照が行われても、それぞれの完了、順序又は一方の成否から、他方の正本更新を推測しない。

## 正常系情報流表

| 情報流 | 起点・送信主体 | 受信・実行主体 | 論理処理と正本への効果 | 受取先・提示主体 | 非導出事項 |
| --- | --- | --- | --- | --- | --- |
| 利用者入力の受領 | 利用者が意図又は会話内容を UI へ送る。 | UI が入力を受け、AI へ会話入力として渡す。 | UI は入力を受領・転送するだけである。入力の受領だけでは L4 の会話記録又は議論状態を更新しない。 | UI は受領した入力を利用者が確認できるよう提示し得る。 | 入力だけで Actor 承認、Proposal の三判断、通常進行、現在地又は Decision を確定しない。 |
| 利用者入力の会話記録 | 記録対象となる利用者入力を UI が Discussion Tool へ渡す。 | Discussion Tool が会話記録の追記を実行し、L4 の会話正本へ反映する。 | 会話記録の追加だけを行う。記録対象の由来・関連・履歴の正本は L4 に従う。 | Tool の記録結果を UI 又は AI が受け取り、必要に応じて提示する。 | Tool は入力本文を会話として生成・解釈しない。追記だけで論点、状態、現在地、Decision、Proposal、完了又はスコープを更新しない。 |
| AI 会話生成 | UI から受け取った利用者入力又は既存の会話文脈を AI が会話応答の起点として受け取る。 | AI が質問、再説明、候補又は応答を生成し、UI へ渡す。 | 会話内容を生成するだけであり、議論状態正本を更新しない。 | UI が AI 応答を利用者へ提示する。 | Discussion Tool を質問生成者、会話相手、提案判断者又は承認者にしない。AI 応答だけで利用者承認又は状態更新を導かない。 |
| AI 応答の会話記録 | UI が提示対象となる AI 応答を Discussion Tool へ渡す。 | Discussion Tool が会話記録の追記を実行し、L4 の会話正本へ反映する。 | 会話記録の追加だけを行う。 | Tool の記録結果を UI 又は AI が受け取り、必要に応じて提示する。 | 追記だけで AI 応答を Decision、Proposal、通常 Topic、現在地又は確定更新として扱わない。 |
| 議論状態参照 | UI 又は AI が参照要求を Discussion Tool へ送る。 | Discussion Tool が L4 の既存正本を照会し、結果を UI 又は AI へ返す。 | Tool は Query の Executor であり、Canonical Updater ではない。参照時点の既存情報を返すだけである。 | UI 又は AI が参照結果を利用者へ提示し得る。 | Query、表示、ローカル選択又は参照結果から会話記録、議論状態、現在地、状態、Decision、Proposal、完了条件又は履歴を更新しない。 |
| 背景再説明・根拠会話閲覧 | AI 又は UI が既存の背景、目的、派生元又は根拠会話の参照を要求する。 | Discussion Tool が既存正本を照会し、AI 又は UI へ返す。AI は返された参照結果だけを用いて再説明を生成し得る。 | 参照と再説明は別処理である。Tool は会話本文を生成せず、AI は参照結果を議論状態へ反映しない。 | UI が再説明又は根拠会話を利用者へ提示し得る。 | 背景再説明、根拠会話閲覧又は表示フォーカス変更から、論点移動、状態変更、Decision、Proposal の判断、承認又は正本更新を導かない。 |

## 送受信の不変条件

- 会話記録の追記は、会話正本への限定された更新であり、S3 が所有する議論状態更新の許可経路を代替しない。
- 議論状態参照は非更新である。Discussion Tool、AI 又は UI は参照の実行・受領・提示を理由に正本を暗黙更新しない。
- UI の入力欄、ローカル選択、表示フォーカス又は再説明の表示は、共有正本の現在地又は状態を変更しない。
- AI は会話を生成し、Discussion Tool は会話記録又は既存正本の照会を実行する。Tool が自然言語会話の主体、提案の三判断者、承認者又は L3 Actor の代理になることはない。
- 記録対象が欠落していること、参照結果が利用できないこと、送受信順又は鮮度が異なることの扱いは、本書では決めない。

## 責務境界

- L6-M1-S3 は、利用者意図・AI 判断を変更要求へ変換する経路、L2 Guard と L3 権限の検証、議論状態正本の更新および更新結果通知を所有する。
- L6-M3 は個別の照会・再説明 Capability、L6-M4 は鮮度、順序、失敗、競合、重複及び遅延を所有する。本書は正常系の送受信主体と更新／非更新の区別だけを定める。
- L2 は状態・遷移・現在地・構造、L3 は Actor・承認・理解停止等の統制、L4 は会話・議論状態の Entity、Relation、現行正本及び履歴、L5 は提示要件を所有する。
- Query API、Prompt、Model、入力 UI、通信、会話の記録方式、保存 Component、DB、時刻、順序制御及び障害処理は L8 が所有する。
