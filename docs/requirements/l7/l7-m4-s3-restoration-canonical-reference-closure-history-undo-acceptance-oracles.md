# L7-M4-S3: 復元後の正本・参照閉包・履歴整合の合格Oracle

## 目的

FR-020の7対象を復元した後、階層・経路・現在地・復帰先・派生元・Session所属、現行Decision等、Event／ChangeSet、根拠会話及びUndoへの既存参照が、同一Sessionの論理正本として矛盾なく閉じていることを確認する合格Oracleと不合格条件を定める。

履歴、由来及びUndoは第8の復元対象ではなく、7対象の現行正本を照合する横断条件である。

## 入力と共通前提

- `L7-M4-S1` が定める7対象、値あり・正当な空・欠落、対象Session及び無関係SessionのProfileを入力とする。
- `L4-M5-S1〜S3` が定める7対象と正本の対応、Session参照閉包、現行／旧内容・由来・Undoの採用整合を参照する。
- 本書の「確認」は記録済みのEntity及びRelationを照合することであり、欠落内容の推測、正本の更新、履歴の修復又はUndoの適用を含まない。

## 参照閉包・正本整合Oracle

| ID | 照合対象 | 合格Oracle | 不合格条件 |
| --- | --- | --- | --- |
| O-01 | Session境界 | 7対象及び照合に必要なTopic、Proposal、Decision、Event、ChangeSet、旧内容、根拠会話、Undo Relationの端点が、対象の一つの未完了Sessionへ所属する。 | 別Session混入、所属不能又は対象Sessionの特定不能。 |
| O-02 | 階層・経路 | 議論マップのTopicはルート一つ、非ルートTopicの親一つ、ルートからの到達経路一つを満たし、親子循環及び孤立がない。派生元は親子・復帰先・会話順と別Relationとして追跡できる。 | ルート不在又は複数、親の重複、経路欠落、親子循環、孤立、派生元の混同又は端点欠落。 |
| O-03 | 現在地・復帰先 | 通常進行時の現在地は一意で到達経路を持つ。通常進行しない時点の現在地0件は既存現行値として許容する。復帰先があるTopicは同じルートの既存直接親を参照し、ルートは復帰先を持たない。 | 複数現在地、現在地の経路欠落、別枝・別Session・子孫への復帰先、ルートの復帰先、又は旧現在地の現行誤採用。 |
| O-04 | 7対象の現行正本 | 会話、議論マップ、現在地、Decision、保留、Proposal、未完了Topicの各値あり／正当な空／欠落が、対応する記録済み現行正本と一致する。欠落は値又は空へ補完しない。 | 値あり・空・欠落の取り違え、複製正本、Projectionによる正本代替、又は現行正本を確認不能な対象。 |
| O-05 | Decision・保留・Proposal | Decision及び保留は対応Topicの現行結果・既存理由／根拠参照に、Proposalは必須情報・現行3判断・論点化済みなら生成Topicとの由来Relationに対応する。Proposalと通常Topicは別Entityのまま確認する。 | Decisionと完了の同一視、保留と中断・対象外・再開の同一視、未承認Proposalの通常Topic・現在地・Decision・現スコープへの暗黙昇格、又は必要な記録済み参照の欠落。 |
| O-06 | Event・ChangeSet・根拠会話 | 変更を追跡する場合、結果は根拠Eventを経由して起点会話、操作、Actor又はRuleの記録済み参照へ到達でき、Eventはちょうど一つのChangeSetに所属する。ChangeSetは会話又は結果を直接結ばない。 | EventのChangeSet所属欠落・重複、結果又は会話をChangeSetへ直接結ぶこと、必要な根拠Event・端点の欠落、又は会話順からの因果推測。 |
| O-07 | 旧内容・訂正・再判断・取消 | 訂正、再判断及び業務上取消は後続Event／ChangeSetと新旧Relationにより旧内容を追跡できる。新旧Relationは同一Session・同粒度の新→旧有向履歴で自己・循環がなく、旧内容を現行正本と混同しない。 | 旧内容又は新旧Relationの削除・欠落、現行旧逆転、自己・循環、異なる粒度の未正規化Relation、又は後続順・時系列だけからの現行選択。 |
| O-08 | Undo | 有効なUndo結果を含む現行正本は記録済み現行Relationで確認できる。Undoが適用済みなら新Undo Event／ChangeSetから同一Sessionの元対象ChangeSetへのUndo Relationを追跡でき、元対象はUndo自身又は既Undo対象でない。 | Undo Relation又は端点の欠落、別Session・自己参照、再Undo、Undo前値の現行誤採用、又はUndo可否・依存閉包・適用結果の推測。 |

## 横断不合格規則

- O-01〜O-08の一つでも不合格なら、対象Sessionについて正本・参照閉包・履歴整合が成立したと扱わない。
- 欠落、重複、混入、孤立、循環、現行旧逆転又は因果破損を、AI推測、古いUI状態、表示Projection、別Session又は時系列上の近接で補正・相殺しない。
- 起点会話がないEvent、正当な空、現在地0件又は未実施Undoだけでは不合格にしない。ただし当該現行値の追跡に必要と記録された参照が欠落又は矛盾する場合は不合格とする。
- 不合格時に通常進行を停止する条件、影響範囲及び次行動の識別は `L7-M4-S4` が所有する。本書は安全停止の実行、修復又は障害復旧を定めない。

## 責務境界

- `L7-M4-S1` は7対象・正常終了境界・Profile、`L7-M4-S2` は正常再開、`L7-M4-S4` は不合格時の安全停止を所有する。本書は横断参照の照合と不合格条件だけを所有する。
- 階層・状態・完了・遷移はL2、Actor・承認・GuardはL3、Entity／Relation・現行正本・Event／ChangeSet・訂正／再判断／取消・UndoはL4が所有する。
- 表示はL5、操作・APIはL6、評価の実施・証跡はL7-M4-S5、復元方式、Snapshot／Replay、DB、Transaction、欠損補正、因果検出及び障害復旧はL8が所有する。
