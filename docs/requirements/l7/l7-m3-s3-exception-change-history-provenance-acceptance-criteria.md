# L7-M3-S3: 例外変更・Undoの履歴／由来整合受入条件

## 目的と共通Oracle

訂正、再判断、業務上の取消及びUndoを別種の論理変更として検証し、現行／旧結果、理由、Actor、Rule、Entity、ChangeSet、根拠会話及び試行結果を記録済みの論理正本から追跡できることを合格条件とする。

現行結果は、`L4-M2`が保持する記録済みの現行正本Relationだけを参照して確認する。後続Event／ChangeSet、新旧Relation、論理順序、発生時点又は表示上の近接から現行を選択又は補完してはならない。旧結果は`L4-M3-S3`の新旧Relationで区別し、元Event／ChangeSet、旧内容及び既存Relationを保持する。

由来は「結果 → 根拠Event → Eventの起点発言又はターン・Actor・Rule」で追跡し、各Eventの所属ChangeSetを併記する。ChangeSetはEventの一意所属を確認するだけで、会話又は結果を直接結ばない。記録済み参照が`0..N`件であること、又は記録済みでも利用不能であることから、不存在・未記録の理由、Actor、Rule又は根拠会話を推測しない。

## 現行／旧・由来・試行結果の横断判定

| ID | 確認する経路又は状態 | 合格条件 | 単独不合格条件 |
| --- | --- | --- | --- |
| `T-01` | 現行結果 | 各対象の現行結果がL4-M2の記録済み現行正本Relationから一意に参照できる。 | 新旧Relation、後続履歴、論理順序又は時刻だけから現行を選択する。 |
| `T-02` | 旧結果と新旧Relation | 訂正・再判断・業務上取消の新旧Relationは同一Session内で同粒度の`Event→Event`又は`ChangeSet→ChangeSet`であり、新側は旧対象を`1..N`、旧側は後続変更を`0..N`持つ。新→旧の有向履歴DAGと旧内容保持を満たす。 | EventとChangeSetを混在させる、自己・循環Relation、旧対象を持たないRelation、旧内容又は旧Relationの削除・上書き、暗黙の最新選択。 |
| `T-03` | Actor・Rule | 各有効変更Eventについて、記録済みのActor及びRule参照を`0..N`として確認し、Actor／Ruleが未記録又は利用不能ならその事実を区別する。 | 会話、結果、表示又は試験者の推測でActor／Ruleを補完する。 |
| `T-04` | 根拠会話 | 根拠会話を持つ場合は、結果から根拠Eventを経て起点発言又はターンへ追跡し、当該Eventの所属ChangeSetを確認できる。 | ChangeSetと会話又は結果を直接結ぶ、会話の近接・要約・自動解釈から由来を補完する。 |
| `T-05` | 適用済み例外変更 | 許可された後続Event／ChangeSetだけが現行正本への接続を持ち、旧内容・理由・由来を残す。 | 許可経路・Actor／承認・Guardを確認せず、試行だけで現行正本を変更する。 |
| `T-06` | 拒否・失敗・no-op試行 | 拒否、失敗又はno-opは、試行結果・記録済み理由・確認時点を業務変更履歴と分離して追跡でき、既存現行正本と旧履歴を不変に保つ。 | 拒否・失敗・no-opを有効な論理変更Event／ChangeSet、新旧Relation、Undo Relation又は現行結果として記録・採用する。 |
| `T-07` | Undo後 | 新Undo ChangeSetは同一Sessionの別の元対象ChangeSetを`1..N`件参照し、元対象側はUndo Relationの終点を`0..1`件持つ。Undo自身又は既Undo対象を再対象化しない。 | Undo Relationの欠落、自己Relation、複数回のUndo、元対象・由来・旧内容の削除又は隠蔽。 |
| `T-08` | 4種の非混同 | `E-01`〜`E-04`の各追跡対象・Relation・試行結果を区別し、一方の結果から他方を導かない。 | Undoを業務上取消として記録する、訂正／再判断／取消をUndo結果で置換する、又は一つの試行を複数種の業務変更として採用する。 |

## 受入上の境界

- 試行の実施順、証跡の採取、未実施／合格／不合格／無効／ブロック及び非相殺集約は`L7-M3-S4`が所有する。本書は試行結果を業務変更履歴と混同しないOracleだけを定める。
- L5は現行／旧結果・理由・根拠会話の提示・要約、L6は照会・検索・Undo実行、L8はUI、API、索引、保存、時刻、Transaction及び障害処理を所有する。
- Event、ChangeSet、現行正本、新旧Relation、Undo Relation及び由来RelationのEntity／Cardinality／保存方式はL4が所有する。本書は受入で確認する経路を定め、正本又はRelationを複製しない。
