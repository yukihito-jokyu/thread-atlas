# L7-M5-S3: Capability不足時の対象限定禁止・明示縮退受入表

## 目的

L7-M5-S1で分類されたCapabilityが提供できない構成について、影響範囲を必要な操作へ限定し、正規代替又は明示縮退以外で不足を隠さない受入条件を定める。Provider、SDK、検出方式又は表示文面は定めない。

## 共通受入規則

- 不足判断はCapabilityごと、かつ必要な対象シナリオ又はTriggerごとに行う。あるCapabilityの不足から、無関係な操作、Session又はProviderを失敗・禁止・縮退としない。
- 表の明示結果又は縮退は利用者に識別可能とし、当該結果を利用するAIがいる場合にも同じ区別を渡す。表示方式、通知経路又は文面はL8が所有する。
- 明示縮退は、AI支援を省略するか、同じ意味Capabilityを満たすUI又はDiscussion Toolの正規経路へ切り替える結果である。状態、遷移、Actor承認、L4正本・履歴又はL5提示意味を変更しない。
- 正規代替がない不足を、入力到着、会話の連続性、表示近接、AIの説明、ローカルCache又は過去結果で補完しない。結果が確認できないときは成功・拒否を推測せず、記録済みの該当結果だけを示す。
- 技術上のCapability検出、交渉、Adapter、Protocol、SDK、認証、相関、Timeout、通知文面及び縮退実装はL8が所有する。本書は受入上の禁止・明示結果だけを定める。
