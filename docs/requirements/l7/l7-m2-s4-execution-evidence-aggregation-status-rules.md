# L7-M2-S4 性能受入の実施・証跡・集約・実施状態規則

## 目的と入力

L7-M2-S1の結果別観測点・測定区間、L7-M2-S2の規模・負荷・利用状態・冷温・環境プロファイル、及びL7-M2-S3の結果・区間・プロファイル別の指標、標本、閾値、Timeout、未完了率及び有効結果率を、再現可能な性能受入の実施単位へ統合する。

本書は実施順、採否、外れ値、生データ、実施状態、再試験及び集約を定める。観測点・区間の意味、プロファイルの意味、数値の閾値又は結果意味は変更しない。

## 実施単位、評価サイクルと事前固定

- 一つの**要求実施**は、一つの `結果区分 × 測定区間 × プロファイル` に対して、S1の始点・終点とS2の該当P-S/P-L/P-U/P-T/P-Eを確認し、開始した一要求の生データを採取する単位とする。
- 一つの**評価サイクル**は、同じ `結果区分 × 測定区間 × プロファイル × S3基準版` の要求実施を集め、S3の最小有効標本、percentile、Timeout、未完了率及び有効結果率を照合して採否を確定する単位とする。合格・不合格は要求実施単体ではなく評価サイクルにだけ付ける。
- 実施前に、結果区分、適用区間、プロファイル、S3の基準版、評価サイクル及び再試験なら元サイクルとの関係を固定する。実施中又は結果確認後に、別の結果区分・区間・プロファイルで置き換えない。
- S1で非該当の観測点又は区間は、生データ、欠測又はゼロ時間として作らない。非該当を別区間の値で補完又は代替しない。
- 同一論理要求の再送・重複はL6-M4-S4に従い、既存結果を再観測する場合を除き、別の業務変更又は別の成功標本を生成しない。結果不明・競合又は反映前失敗では、L6の確認経路が成立するまで再適用しない。

## 準備、Warm-up及び実施順

各評価サイクルは、次の順に扱う。プロファイルがP-L-03又はP-L-04を含む場合も、同プロファイルが要求する並行経路は各測定要求内で保持する。

1. S1の始点・終点、S2のプロファイル及びS3の適用基準を確認する。
2. P-T-01（冷状態）はWarm-upを0回、P-T-02（温状態）はWarm-upを1回実施してから測定する。Warm-upは要求実施ではない事前準備とし、結果は採取対象の前に記録するが、S3の「開始した全要求」の分母、有効標本、percentile、未完了率又は有効結果率へ含めない。
3. 固定した一つの結果区分・区間・プロファイルについて、S3の最小有効標本を満たすまで要求実施を反復し、各要求の存在する観測点と生データを対応付ける。無効又はブロックとなった要求は有効標本に数えず、新たな要求実施を追加する。
4. 生データの完全性、外れ値の扱い及び個別要求の実施記録を確認する。
5. 同じ評価サイクル内でのみS3の基準へ照合し、集約状態と採否を確定する。

異なる冷温状態、結果区分、区間又はプロファイルの実施順から、結果の優劣、閾値の緩和又は別条件の採否を導かない。端末準備、Cache、Warm-upの具体方式、計測起動、Clock・Traceの取得及び実施自動化はL8が所有する。

## 要求実施の状態と評価サイクルの採否

個別の要求実施は未実施、実施済み（有効・無効・ブロック）として記録する。評価サイクルは、個別要求の記録を集約した未実施、実施中、合格、不合格、無効又はブロックのいずれかとする。個別要求が無効又はブロックでも、S3及び本書に従って追加要求で継続できる間は、評価サイクルを無効又はブロックへ読み替えず実施中とする。

| 実施状態 | 定義 | 標本・採否への扱い |
| --- | --- | --- |
| 未実施 | 固定した評価サイクルの要求実施を一度も開始していない。 | 有効標本に数えず、合格・不合格・無効・ブロックへ読み替えない。 |
| 合格 | 評価サイクルで必要な始点・終点、生データ及びプロファイルを確認でき、S3の当該条件の全基準を満たす。 | S3の最小有効標本を満たしたサイクルの合格として記録する。 |
| 不合格 | 評価サイクルで必要な始点・終点、生データ及びプロファイルを確認できるが、S3のpercentile、Timeout、未完了率、有効結果率又は最小有効標本の適用基準を一つでも満たさない。 | サイクルの不合格として記録する。別条件・別区間・別プロファイルの合格で相殺しない。 |
| 無効 | 除外可否をS3及び本書に従って確定しても、S3照合に必要な記録を回復できず、追加要求でも解消できない。 | サイクルを無効として記録し、原因と確認不能な項目を残す。結果意味を成功・拒否等へ推測しない。 |
| ブロック | 必要な入力、環境又は確認経路を利用できず、評価サイクルを開始又は完了できず、追加要求でも進行できない。 | 有効標本に数えず、未実施・無効と区別して原因を残す。外部途絶、利用者判断待ち又は計測不能を除外できるかはS3に従い、実施状態の確定は本書に従う。 |

- S3が未完了率の分子とする検証段階又はTool処理中の失敗、正本更新済み・応答未到達及び部分到達は、観測できた事実を生データに残す。始終点を確認できない場合に合格又は不合格へ丸めず、無効又はブロックの根拠と区別する。
- 合格又は不合格は、L6の成功・拒否・競合・結果不明確認・再同期の意味を変更しない。拒否の性能基準を満たすことは、拒否の解除又は要求の再適用を意味しない。

## 生データ、外れ値及び証跡

各実施には、少なくとも次を対応付ける。保存形式、識別子の生成、Clock・Trace・相関方式及び生データの格納先は定めない。

| 証跡項目 | 内容 |
| --- | --- |
| 実施参照 | 評価サイクル、実施及び再試験関係を区別する参照。 |
| 入力基準 | 結果区分、S1の観測点・区間、S2のP-S/P-L/P-U/P-T/P-E、S3の基準版。 |
| 生データ | 存在する始点・終点、結果確認、区間値、適用可否及び確認不能な観測点。 |
| 実施状態・採否 | 未実施、合格、不合格、無効又はブロックと、その根拠。 |
| 外れ値判断 | 外れ値候補、判断根拠、集約へ含めるか除くか及び元の生データへの参照。 |
| 非相殺判定 | 満たさなかったS3の個別基準、又は全適用基準を満たした根拠。 |
| 証跡参照 | 元の観測記録、プロファイル、集約結果及び再試験関係をたどるための参照。 |

- 外れ値候補は、生データを削除、改変又は別条件の値で置換しない。集約から除く場合は、事前に固定した判断根拠と元データを証跡に残す。
- 外れ値であることだけから無効、合格又は不合格を導かない。外れ値を除いた後にS3の最小有効標本、有効結果率又は未完了率を満たせない場合は、当該条件を合格として集約しない。
- 外れ値をpercentile集約から除いても、開始済み要求はS3の未完了率及び有効結果率の分母に残す。外れ値だけを理由に、無効・ブロック又は分母除外へ変更しない。
- 実装上の異常、外部途絶、利用者判断待ち又は計測不能を外れ値として隠さない。各事実を無効・ブロック・未完了率又はS3が定める除外対象として区別する。

## 非相殺の集約

集約は同じ `結果区分 × 測定区間 × プロファイル × 基準版` ごとに独立して行う。異なる結果区分、区間、P-S/P-L/P-U/P-T/P-E又は基準版の値を平均、代替又は相殺しない。

| 集約状態 | 条件 |
| --- | --- |
| 未実施 | 固定した評価サイクルで要求実施を一度も開始しておらず、実施記録がない。 |
| 実施中 | 要求実施の記録はあるが、S3の最小有効標本に達していない、又は実行中の追加要求が残っており、採否をまだ確定していない。 |
| 無効 | 実施記録はあるが、除外可否を確定しても必須の生データ又は確認点を回復できず、追加要求でもS3の基準へ照合できない。無効の原因を解消して有効実施を追加するまで、合格へ丸めない。 |
| 不合格 | S3の最小有効標本に達した評価サイクルが、有効な生データに対するS3のpercentile、Timeout、未完了率又は有効結果率の適用基準を一つでも満たさない。 |
| 合格 | S3の最小有効標本・有効結果率を満たし、すべての適用基準を満たす。 |
| ブロック | 必要条件が利用できず、実施を進められない。未実施・実施中・不合格へ置き換えない。 |

- percentile、Timeout、未完了率及び有効結果率はS3の条件ごとに照合する。一つの区間又はプロファイルの余裕で、別の区間又はプロファイルの超過・未完了・不足を覆い隠さない。
- 外れ値を除外した場合も、元データ、除外根拠及び除外後の集約根拠を残す。除外により合格へ見せかけることを禁止する。
- L7-M2全体及び性能測定可能性Gateへの受渡しは、適用するすべての条件の集約状態、各不合格・無効又はブロックの個別根拠、基準版及び証跡参照とする。全体の合否を、条件別の不合格・無効又はブロックを平均化して決めない。

## 再試験

- 無効又はブロックの原因を解消した後は、同じ固定条件で新しい実施を追加できる。元の実施、原因及び証跡を削除・置換しない。
- 合格又は不合格の後に、実装、計測環境、S1の区間、S2のプロファイル又はS3の基準版が変わった場合は、新しい評価サイクルとして扱う。前のサイクルの合格を新しい基準へ流用しない。
- 再試験は不合格、未完了又は外れ値を消すための上書きではない。元実施、新規実施、変更有無及び集約状態を区別して証跡に残す。
- 同一論理要求の再送はL6-M4-S4の既存結果観測であり、本節の再試験を意味しない。再試験は新しい実施単位として開始する。

## 責務境界

- S1は観測点・区間と非該当、S2は規模・負荷・利用状態・冷温・環境、S3は結果区分、数値指標、標本、閾値、Timeout、未完了率及び有効結果率を所有する。本書は実施・証跡・外れ値・状態・採否・集約・再試験に限る。
- L6は要求、Guard、結果意味、正本・応答・表示同期、冪等性及び再同期を所有する。L2〜L5の状態・構造・Actor・正本・表示内容を、性能結果から更新しない。
- L8はClock、Trace、Harness、計測データの保存、相関、Warm-up・Cacheの実装方式、実施自動化、端末・通信、Timeout機構及びUIを所有する。本書は統計計算・計測実装・保存形式を定めない。
- L7-M6は全要件とのTraceability及び証跡索引を所有する。本書は性能条件ごとの集約状態、個別根拠、基準版及び証跡参照を受け渡すだけで、索引形式を定めない。
