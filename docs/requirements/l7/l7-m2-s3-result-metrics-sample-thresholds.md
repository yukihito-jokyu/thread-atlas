# L7-M2-S3 結果区分別の性能指標・標本・合格閾値

## 目的

L7-M2-S1の観測点・区間とL7-M2-S2のプロファイルを入力に、結果区分ごとの性能受入指標、最小有効標本、合格閾値、Timeout、未完了率及び有効結果率を定める。L6の結果意味、遷移又は正本を変更しない。

## 共通規則

- 各結果は、該当するS1の区間及びS2のP-S/P-L/P-U/P-T/P-Eプロファイルごとに測定する。異なる結果・区間・プロファイルを合算して閾値を満たしたとは扱わない。
- percentileは p50、p95、p99、最小有効標本は30件、Timeoutは30秒、未完了率は1%、有効結果率は99%を共通の受入基準とする。結果区分ごとの追加基準は表に従う。
- 外部途絶、利用者の判断待ち、計測不能又は非該当は成功・拒否・競合・結果不明確認・再同期のいずれにも数えない。除外可否、欠測及び再試験はS4が所有する。
- S1の検証段階又はTool処理中の失敗、正本更新済み・応答未到達及び部分到達は、5結果区分へ暗黙に丸めない。各測定では未完了率として記録し、無効・ブロック等の実施状態及び採否はS4へ委譲する。
- 有効結果は、始点・終点・結果区分・プロファイルを記録して区間を確認できる結果をいう。計測値だけから正本、成功又は失敗を推測しない。
- 未完了率及び有効結果率は、各〈区間×プロファイル×結果区分〉で開始した全要求を母数とする。検証段階又はTool処理中の失敗、正本更新済み・応答未到達及び部分到達のうち始終点を確認できない要求を未完了率の分子とし、始終点・結果区分・プロファイルを確認できる完了結果を有効結果率の分子とする。
- 外部途絶、利用者の判断待ち、計測不能又は非該当は、S4が実施状態を確定した場合に限り分母から除外できる。本書だけで除外又は有効化を決めない。

## 責務境界

- S1は観測点・区間、S2は規模・負荷・利用状態・冷温・環境、S4は実施順、外れ値、証跡、採否、再試験及び集約を所有する。
- L6はCapability、Guard、結果意味、冪等性及び同期を、L8はClock、Trace、計測方式、Timeout機構及びHarnessを所有する。本書は受入上の数値だけを定める。
