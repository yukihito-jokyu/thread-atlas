# L7-M2-S1 応答性の観測点・測定区間・待ち時間分解

## 目的

L6-M4が定めた要求、正本、応答及び表示の同期契約を入力に、応答性を評価するための結果別観測点と測定区間を定める。Tool処理、AI生成、UI到達、可視反映、会話再開可能及び最終表示同期を別の待ち時間として扱い、異なる区間を合算又は代替しない。

本書は区間の意味上の始点・終点を定める。規模、負荷、環境はL7-M2-S2、指標・標本・百分位・閾値・**受入上のTimeout**はL7-M2-S3、実行、欠測及び証跡集約はL7-M2-S4、Clock・Trace・計測実装・**実装上のTimeout機構**はL8が所有する。

## 共通の観測規則

- 観測は、会話ターン又は利用者操作から生じた要求と、その要求に対応するL6-M4の確認点を同じ論理要求として対応付けて行う。会話本文、AIの主張、UIローカル状態又は表示近接から始点・終点を推測しない。
- 正本確定、照会成立、応答到達、UI到達、可視反映、会話再開可能及び最終表示同期は別の観測点である。正本確定だけから応答・表示の到達を、可視反映だけから会話再開可能を導かない。
- 各区間の開始・終了が当該結果に存在しないときは**非該当**とする。非該当は欠測、失敗、ゼロ時間又は他区間での代替ではない。存在する観測点を確認できない場合の実施状態・除外・再試験はL7-M2-S4が定める。
- AI生成はTool処理及びUI処理と別区間で扱う。AI生成を伴わない利用者直接操作、又はToolを伴わない会話応答について、存在しない区間を補完しない。
- 同じ確定Snapshot又は確認点への整合はL6-M4の意味契約に従う。本書はSnapshotの取得方法、時計、相関ID、通信、再試行又はUI実装を定めない。

## 観測点の辞書

| ID | 観測点 | 確認できること | 導かないこと |
| --- | --- | --- | --- |
| O-01 | 要求開始 | 会話ターン又は利用者操作から、更新又は照会の要求を受け付けた。 | Guard・権限の成立、Tool実行、正本変更。 |
| O-02V | 検証開始 | 要求の対象、内容、L2 Guard及びL3のActor・承認を検証対象として受け取った。 | 検証の許可・拒否・失敗、Tool処理又は正本変更。 |
| O-02R | 検証結果 | 許可、拒否又は更新・照会前の処理失敗を確認できる。許可時だけ後続のTool処理へ渡せる。 | 正本確定、AI又はUIへの到達、拒否理由の変更。 |
| O-02 | Tool処理開始 | 検証で許可された更新又は照会の処理をToolへ渡した。 | Tool結果、正本確定、AI又はUIへの到達。 |
| O-03 | 結果確認点 | 更新ではL4正本反映済み、照会では照会成立、又はL6-M4-S2以降の拒否・失敗・競合・結果不明・再同期の該当結果を確認できる。 | 全受取先への応答又は表示の完了、再実行可否。 |
| O-04 | AI結果到達 | AIがO-03に対応する結果を参照できる。 | AI生成文の完了、利用者への可視反映、業務変更の追加。 |
| O-05 | AI生成完了 | AIが当該結果に基づく応答生成を完了し、会話へ返せる。 | UI到達、可視反映、次の通常進行の開始。 |
| O-06 | UI結果到達 | UIがO-03に対応する結果を受け取り、表示反映に使える。 | 利用者が可視に確認済みであること、全表示の同期。 |
| O-07 | 可視反映 | 利用者が当該結果を確認できる表示反映に到達した。 | 会話再開可能、他の表示Projectionの同期、正本更新。 |
| O-08 | 会話再開可能 | 同じ確認点・文脈を前提に、次の通常進行の一問を扱える。 | 次の質問の生成・送信、状態遷移、理解停止Guardの解除。 |
| O-09 | 最終表示同期 | 当該要求に関係する表示が、O-03と同じ確認点へ整合している。 | 別の正本変更、全画面・全端末への到達、表示方式。 |

## 測定区間と待ち時間の分解

| ID | 区間 | 開始 → 終了 | 適用 | 他区間と混同しないこと |
| --- | --- | --- | --- | --- |
| I-01 | 検証開始待ち | O-01 → O-02V | 更新又は照会を検証する場合。 | 利用者の入力時間、検証、Tool処理又はAI生成時間。 |
| I-02 | 検証待ち | O-02V → O-02R | 更新又は照会を検証する場合。 | Tool処理、正本確定、AI生成又はUI到達。 |
| I-02A | Tool要求開始待ち | O-02R → O-02 | 検証で許可され、Toolを用いる更新又は照会。 | 検証そのもの、Tool処理、正本確定又はAI生成。 |
| I-03 | Tool処理待ち | O-02 → O-03 | 検証で許可され、Toolを用いる更新又は照会。 | AI生成、UI到達、可視反映及び表示同期。 |
| I-04 | AI結果到達待ち | O-03 → O-04 | 結果をAIが参照する場合。 | Tool処理又はAI生成そのもの。 |
| I-05 | AI生成待ち | O-04 → O-05 | AIが応答を生成する場合。 | Tool処理、UI到達又は利用者の読解時間。 |
| I-06 | UI到達待ち | O-03 → O-06 | 結果をUIへ反映する場合。 | 可視反映、AI生成又は会話再開。 |
| I-07 | 可視反映待ち | O-06 → O-07 | UIが受け取った結果を利用者へ反映する場合。 | 表示内容の読解、全表示同期又は正本確定。 |
| I-08 | 会話再開待ち | 当該結果に必要なO-03、O-05及びO-07がすべて成立した最後の観測点 → O-08 | AI応答と利用者向け表示の双方を経て通常進行へ戻る場合。 | 次の一問の実行時間、理解停止の解除又は別論点への移動。 |
| I-09 | 最終表示同期待ち | O-03 → O-09 | 複数の表示反映を同じ確認点へそろえる必要がある場合。 | O-07だけを全表示同期とみなすこと、再同期による業務変更。 |
| I-10 | 利用者待ち時間 | O-01 → O-08 | 当該結果の後に通常進行へ戻れる場合。 | I-01〜I-09の合算、利用者の入力・読解時間又は次の一問の実行時間。 |

I-08の開始は、当該結果で必要なO-03、O-05又はO-07だけを用いる。必要観測点の一つでも確認できない場合はI-08を成立させず、他の区間で埋めない。会話再開可能でない結果にはI-08を適用しない。

## 責務境界

- L6-M4は結果分類、正本・応答・表示の意味上の同期及び再試行・競合・再同期の契約を所有する。本書はそれらを性能観測点へ対応付けるだけで、成功、拒否又は再開の意味を変更しない。
- L7-M2-S2は階層規模、履歴量、更新頻度、連続操作、冷温状態、環境及び同時進行を、S3は数値指標、標本、percentile、**受入上のTimeout閾値・未完了率**及び有効結果率を、S4は実施、外れ値、欠測、再試験及び証跡集約を所有する。
- L2は状態・遷移・完了・構造、L3はActor・承認・Guard、L4は正本・Relation・履歴・Undo、L5は表示内容と優先、L6はCapabilityと結果意味を所有する。本書は論理状態、正本又は表示内容を新設・更新しない。
- L8はClock、Trace、相関、計測Harness、非同期処理、通信、Queue、**実装上のTimeout機構・設定**、再試行、UI及び保存方式を所有する。本書は技術方式、実装又は計測データ形式を定めない。

## Task固有Review

- Tool要求、正本又は結果確認、AI結果到達・生成、UI到達・可視反映、会話再開可能及び最終表示同期を別の観測点・区間として定義した。
- 正常更新・照会、拒否、失敗、部分到達、競合・古い参照、結果不明、再試行・重複要求及び再同期の観測点を、L6-M4の結果意味と対応付けた。
- 存在しない観測点を欠測・ゼロ時間・代替区間として扱わず、非該当とすることを確認した。
- 規模・負荷・環境、数値指標・閾値、実施・証跡、技術的計測方式を後続Ownerへ残し、未解決の契約差異又はTBDがないことを確認した。
