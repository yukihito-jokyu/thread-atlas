# L7-M2-S2 規模・負荷・状態・測定環境プロファイル

## 目的

L7-M2-S1の観測点・測定区間に対し、比較可能な規模、混在操作、同時進行、利用状態及び測定環境のプロファイルを定義する。本書は負荷条件の意味上の分類だけを定め、数値の閾値・標本数・実施回数・計測方式は定めない。

## 共通規則

- 各測定結果は、該当する規模、負荷、利用状態、測定開始時の冷温状態及び環境プロファイルを対応付けて確認する。異なるプロファイルの結果を同一条件として代替又は合算しない。
- プロファイルは単一の議論Session内を対象とする。複数ユーザー又は複数Sessionを同時に操作する負荷要件は追加しない。
- 未記録の規模、状態又は環境を既定値で補完しない。実施可否、欠測及び除外はL7-M2-S4が所有する。
- 統計標本数、percentile、閾値、Timeout及び未完了率はL7-M2-S3、実施回数・順序・外れ値はL7-M2-S4、Clock・Trace・Cache・通信方式・端末計測はL8が所有する。

## プロファイルの組合せ

- 各測定は、少なくとも規模（P-S）、負荷（P-L）、利用状態（P-U）、冷温状態（P-T）及び環境（P-E）から該当する条件を明示して識別する。各観点で該当しない条件は非該当とし、欠測として別条件へ置き換えない。
- 冷状態又は温状態は、利用状態・規模・負荷・環境とは別の測定開始時分類として対応付ける。冷温の差だけから結果の優劣、閾値又は実施順を導かない。
- P-L-03又はP-L-04では、L6-M4の同一論理要求、最大1業務変更、正本非推測及び再同期の契約を維持する。負荷プロファイルだけから更新、再試行又は会話再開を許可しない。
- P-U-02では、復元したSessionの通常進行を開始するかはL1-M4、L2及びL3の既存経路に従う。復元直後であることだけから現在地、正本又は理解停止Guardを補正しない。

## 責務境界

- L7-M2-S1は結果別観測点・区間、S3は結果・区間・本プロファイル別の性能指標、標本及び合格閾値、S4は実施・証跡・採否・再試験を所有する。
- L2は状態・遷移・構造、L3はActor・承認・Guard、L4は正本・履歴・復元、L5は表示内容、L6はCapabilityと同期結果意味を所有する。本書はそれらをプロファイル条件として参照するだけである。
- L8は端末・ネットワーク・AI/Tool接続・UIの具体的な計測、Clock・Trace・Cache、冷温の実装上の準備方式、通信・再接続・保存方式を所有する。
