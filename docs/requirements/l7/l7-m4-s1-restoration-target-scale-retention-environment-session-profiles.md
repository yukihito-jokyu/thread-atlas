# L7-M4-S1: 復元対象・規模・保持・環境・Session条件

## 目的

FR-020の復元対象を会話、議論マップ、現在地、決定事項、保留事項、新規提案及び未完了論点の7項目に固定し、受入時に値あり／正当空／欠落を区別する。同時に、規模、保持、正常終了前の確定点、環境及び対象Sessionの条件を固定する。

本書は正常終了後の復元・再開の合否を定めない。また、複数ユーザー、異常終了、Version Migration、保存方式、復元順又は欠損補正を追加しない。

## 共通条件

- 対象は、正常終了前に正本が確定した一つの既存Sessionとする。対象Sessionの識別、7対象と正本の対応は`L4-M5-S1`、同一Session内の参照閉包は`L4-M5-S2`を入力とする。
- **値あり**は、対応する既存正本又はRelationを確認できること、**正当空**は既存規則により値がないこと自体を確認できること、**欠落**は値あり又は正当空のいずれとも確認できないことを指す。欠落を空として扱わず、AI、表示又は旧履歴から補完しない。
- 7対象以外の履歴、Event／ChangeSet、Undo及び一時Guardは横断参照又は既存規則であり、第8の復元対象・追加状態にしない。

## 7対象の値あり／正当空／欠落表

| 復元対象 | 値あり | 正当空 | 欠落として扱う条件 | 非導出事項 |
| --- | --- | --- | --- | --- |
| 会話 | 対象Session所属の発言・ターン及び既存順序を確認できる。 | 会話Relationが0件であることを既存正本から確認できる。 | 順序又は所属を含む会話正本を確認できず、空とも確認できない。 | 会話文面・表示近接から状態、親子又はDecisionを補わない。 |
| 議論マップ | Topic、ルート、親子・派生Relationと既存経路を確認できる。 | 正当空を設けない。各Sessionは既存ルート構造を参照する。 | ルート、必要なTopic又はRelationを確認できない。 | Projectionを正本又は欠落補完元にしない。 |
| 現在地 | 通常進行時の一意な現在地Topicと既存経路を確認できる。 | 通常進行しない時点の現在地0件を既存正本から確認できる。 | 0件又は一意な1件のいずれかを確認できない。 | 復元だけで現在地を設定・移動しない。 |
| 決定事項 | Topicに関連するDecisionと内容を確認できる。 | Decision Relationが0件であることを確認できる。 | Decisionの有無を確認できず、理由・根拠の不在からも空を推測できない。 | Decisionから完了、現在地又は親復帰を導かない。 |
| 保留事項 | 通常Topicに関連する現行保留判断結果を確認できる。 | 現行保留判断結果が0件であることを確認できる。 | 保留の有無を確認できない。 | 保留を中断、対象外又は通常進行再開と同一視しない。 |
| 新規提案 | 未承認Proposal、必須情報及び現行3判断を確認できる。 | Proposalが0件であることを確認できる。 | Proposalの有無、必須情報又は判断を確認できない。 | Proposalを通常Topic、現在地、Decision又は現スコープへ昇格させない。 |
| 未完了論点 | 未完了の通常Topic、状態軸、条件・未確認事項との既存Relationを確認できる。 | 正常完了済みで未完了通常Topicが0件であることを確認できる。 | 未完了の有無又は必要な文脈を確認できない。 | 未完了を第8状態にせず、再開・完了を導かない。 |

## 規模・保持・環境・Session条件表

| ID | 受入で固定して確認する条件 | 非導出事項・詳細Owner |
| --- | --- | --- |
| `R-P-01` | 規模は、対象Session内の7対象に対応する既存Topic階層、会話、Decision、保留、Proposal、未完了論点及び横断参照の量として記録する。値から新しいEntityを生成しない。 | 上限値、計測方法及び性能評価はL8／L7-M2が所有する。 |
| `R-P-02` | 保持期間は、正常終了前の確定点から復元受入で参照する時点までの既存Sessionの保持条件として記録する。 | 物理保存期間、削除、GC及びRetention実装はL8が所有する。 |
| `R-P-03` | 確定点は、7対象及び必要な横断参照がL4の記録済み正本として確認でき、通常進行又は更新を新たに開始していない正常終了前の時点とする。 | Event採番、Snapshot、Transaction又は確定処理の方式はL8が所有する。 |
| `R-P-04` | 環境は、同じ対象Sessionを復元受入で確認するために記録済みの実行・保存参照条件として扱う。環境差異は値あり／正当空／欠落の意味を変更しない。 | OS、DB、ネットワーク、Clock、暗号化又は構成方式はL8が所有する。 |
| `R-P-05` | 対象Sessionだけの正本・Relationを確認し、別Sessionの会話、Topic、Decision、Proposal、Event又はChangeSetを混入させない。混入候補は対象Sessionの値として採用しない。 | 参照閉包と破損判定は`L7-M4-S3`、安全停止は`L7-M4-S4`が所有する。 |

## 受渡しと責務境界

- `L7-M4-S2`は、本書の値あり／正当空／欠落、確定点及び対象Sessionを入力に、正常終了・再起動・復元・通常進行再開の合格条件を定める。
- `L7-M4-S3`は、現行正本、履歴、由来及びUndoを7対象の横断参照として照合する。本書は現行／旧の選択をしない。
- `L7-M4-S4`は、欠落又は不整合が確認された影響Sessionの安全停止を定める。本書は欠落時の復元継続・補正を定めない。
- 状態・階層・現在地・完了はL2、Actor・承認・GuardはL3、Entity／Relation・正本・履歴・UndoはL4、提示はL5、操作・APIはL6、受入集約は後続S5、物理保存・復元方式はL8が所有する。
