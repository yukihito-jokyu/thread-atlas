# L2-M3-S1: 階層・現在地・復帰先の共通不変条件

## 目的

正常完了、中断、再訪、復元後再開および再対象化の各経路で、議論構造の階層、論理上の現在地、復帰先が常に追跡可能であるための共通不変条件を定める。

本書は構造上成立していなければならない条件だけを定める。下位進入・上位復帰を行う契機、許可、状態遷移、Actor、データ表現、保存、表示および操作方式は確定しない。

## 用語

| 用語 | 本書での意味 |
| --- | --- |
| ルート | 一つの議論構造の起点となる論点。親を持たない。 |
| 論点 | ルートまたは他の論点に属する、議論の対象。具体的なEntityやIDの表現は定めない。 |
| 論理上の現在地 | 通常進行の対象として構造上特定される論点。表示上のフォーカスとは区別する。 |
| 到達経路 | ルートから各論点へ親子関係を順にたどる経路。 |
| 復帰先 | ある論点を離れた後に通常進行を再開する候補として、当該論点との階層関係を確認できる論点。 |

## 共通不変条件

| 対象 | 不変条件 | 防ぐ不整合 |
| --- | --- | --- |
| ルート構成 | 各議論構造は起点となるルートをちょうど一つ持ち、ルートは親を持たない。全ての論点、通常進行の対象、復帰先およびその到達経路は同じルートに属する。 | 複数起点、架空の親、別の議論構造への混入 |
| 親子関係 | ルート以外の各論点は親を一つだけ持つ。論点が複数の親へ同時に属することはない。 | 親経路の分岐、復帰先の曖昧化 |
| 循環 | 論点は自分自身の祖先または子孫にならない。親子関係を繰り返した経路を作らない。 | 循環参照、ルートからの経路不能 |
| 孤立 | 構造に属する各論点は、同じルートから到達できる。親子関係の変更後も切断された論点を残さない。 | 参照不能な論点、孤立した枝 |
| 現在地 | 通常進行を行う時点では、論理上の現在地は一つだけである。その論点にはルートからの到達経路がある。 | 重複現在地、現在地不明、到達不能な進行 |
| 任意深度の経路 | 階層数は固定しない。任意の深さの現在地についても、ルートから親子関係を順にたどる一意の到達経路を確認できる。 | 深い下位論点での上位接続喪失 |
| 復帰先 | 復帰先を持つ論点では、復帰先は同じルートに属する既存の親論点である。ルートは復帰先を持たず、自分自身、子孫、不明な論点、別枝・別ルートの論点を復帰先にしない。 | 不正な復帰先、別枝・別構造への飛び先 |
| 復帰先と現在地 | 通常進行の現在地と復帰先を同一視しない。復帰先が存在することだけから、現在地変更、親復帰、完了または通常進行開始を導かない。 | 復帰先の暗黙実行、完了と中断の混同 |

## 経路の前後で維持する条件

下位論点へ進入する、上位へ戻る、または再開する経路では、処理後にも前節の不変条件を満たすものとする。特に、処理の前後で次を生じさせない。

- ルートから到達できない現在地または復帰先
- 親を二つ持つ論点、親子関係の循環、孤立した論点
- 同時に複数の論理上の現在地
- 出所または階層関係を確認できない復帰先

これは構造上の成立条件であり、各経路の事後条件は個別Ownerが定める。正常完了・親復帰・ルート完了は L2-M3-S2、中断・再訪・復元後再開は L2-M3-S3、状態・提案起点の再活性化は L2-M3-S4 が扱う。

## 責務境界

- 下位進入・上位復帰・現在地変更の Trigger、許可可否および状態遷移は L2-M4 が扱う。
- 完了可否は L2-M2、状態語彙と有効な状態組合せは L2-M1 が扱う。本書は新たな状態語彙を追加しない。
- Actor、承認およびAIの更新権限は L3、論点・親子・復帰先のEntity表現、履歴、保存・復元は L4/L8 が扱う。
- 論理上の現在地と異なる表示フォーカス、到達経路・復帰先の提示方式は L5、操作・APIは L6、受入基準・測定は L7 が扱う。
