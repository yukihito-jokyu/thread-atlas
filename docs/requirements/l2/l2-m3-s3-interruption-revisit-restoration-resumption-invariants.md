# L2-M3-S3: 中断・再訪・復元後再開の階層不変条件

## 目的

未完了の下位論点を中断して親論点を継続する場合、同一セッション内で中断論点を再訪する場合、およびアプリ終了後に未完了セッションを再開する場合に、論点を正常完了扱いにせず、階層・現在地・復帰先と途中内容との意味上の対応を保つ事後条件を定める。

本書は各経路の構造上の結果を定める。中断を新しい永続状態にはせず、実行のTrigger、許可・遷移、Actor、データ保持方法、保存・復元手順、表示および操作方式は確定しない。

## 共通前提

- 中断・再訪・再開の前後で、L2-M3-S1 の単一ルート、親の一意性、循環・孤立禁止、論理上の現在地一意、到達経路および復帰先の共通不変条件を満たす。
- 未完了である論点は、正常完了、決定済み、対象外または保留へ暗黙に変更しない。
- 会話、文脈、未確認事項、関連する決定・保留・構造変化について、再開対象との意味上の対応を失わない。保持単位・履歴・保存形式は定めない。

## 経路別の事後条件

| 経路 | 構造上の事後条件 | 導かないこと |
| --- | --- | --- |
| 未完了中断 | 親を持つ未完了の下位論点を中断して親論点を通常進行の現在地とする。中断論点は親子関係、ルートからの経路、復帰先および途中内容との対応を保ち、後から再訪対象として識別できる。 | 中断論点の正常完了、削除、現在地の重複、親の暗黙完了 |
| 同一セッション内の再訪 | 中断論点を再訪して通常進行を再開する場合、再訪対象は同じルート・同じ親子関係に属し、ルートから対象までの経路、親、復帰先および中断前の途中内容を確認できる。再開後の論理上の現在地は再訪対象一つだけとする。 | 親子関係の付け替え、別枝への再開、正常完了・決定・構造修正の暗黙確定 |
| 復元後再開 | アプリ終了後に未完了セッションを再開する場合、再開対象について会話、議論マップ、前回の現在地、決定事項、保留事項、新規提案、未完了論点を確認できる。再開する論点には同一ルートからの有効な経路があり、通常進行を開始する場合の論理上の現在地は一つだけとする。 | 新しいルート・親・復帰先の推測生成、未完了論点の完了化、状態・判断の暗黙変更 |

## 中断と正常完了の区別

中断は、論点単体の正常完了可能または正常完了の結果を必要としない。中断した論点は未完了のまま構造に残り、親論点への通常進行の復帰は、その子論点の正常完了による親復帰を意味しない。

中断後の親論点は、子論点が未完了である事実を保つ。したがって、親論点またはルート論点の正常完了可否は L2-M3-S2 の未完了子に関する条件を引き続き満たす必要がある。

## 再訪・復元後の経路確認

再訪または復元後に通常進行を再開する前に、対象論点とルートの間の到達経路、現在地、親、復帰先および未完了である事実を確認できるものとする。前回の現在地または中断位置を根拠に、現在地を複数設定したり、別枝へ移したりしない。

再訪しない場合は親論点の通常進行を継続でき、復元されたセッションを再開しない場合は通常進行を開始しない。この選択自体は、対象論点の完了、状態変更または構造変更を導かない。

## 責務境界

- 正常完了・親復帰・ルート完了の事後条件は L2-M3-S2、保留・要確認・対象外・決定済みからの再開と新規提案論点化は L2-M3-S4 が扱う。
- 中断、再訪、復元後再開を許可するTrigger、Guard、状態遷移、現在地変更の実行は L2-M4 が扱う。
- Actor、承認、AI統制は L3、会話・論点・履歴・保存対象・復元単位・Undoは L4/L8、表示方式は L5、操作/APIは L6、受入基準・測定は L7 が扱う。
- 異常終了、強制終了、電源断時の無損失復旧、欠損時の補正および永続化方式は L8 が扱う。
