# L2-M4-S1: 基本開始・決定更新・正常完了の許可遷移

## 目的

既存論点の通常開始、議論中の決定更新、正常完了を、起点、Trigger／事前条件、抽象Guard、遷移先、論理上の現在地への効果および復帰先に分けて定める。

本書の「許可」は、状態組合せと構造・完了可否が満たす意味上の条件である。誰が実行または承認するか、AIが自動実行できるか、操作・保存・表示の方法は定めない。

## 共通前提

- 起点と遷移先は、L2-M1-S1〜S3 が定める7語彙、軸内排他および対象類型別の有効組合せを満たす。未設定の値を推測で補わない。
- 通常開始、決定更新および正常完了の対象は、未承認の新規提案ではなく既存論点である。新規提案の登録・三判断・論点化は L2-M4-S3 が扱う。
- 論理上の現在地、親子関係および復帰先は L2-M3-S1 の共通不変条件を満たす。各遷移は同一ルートの到達経路、現在地の一意性、親の一意性、循環・孤立禁止を損なわない。
- 「正常完了可能」は L2-M2-S3 の抽象判定であり、決定済みであることだけから導かない。

## 許可範囲と後続境界

- T-01 は未着手から議論中への基本開始だけを扱う。保留・要確認からの再開、中断・再訪・復元後再開は L2-M4-S2、対象外化・再対象化・決定済みからの再開は L2-M4-S3 が扱う。
- T-02 は決定済みを反映するだけであり、決定済みと論点完了を同義にしない。完了条件の設定・変更・充足判定は L2-M2、状態組合せは L2-M1 が扱う。
- T-03 と T-04 は正常完了可能および階層上の事後条件をGuardとして参照する。完了後の保留、要確認、対象外、決定済みの再活性化や提案論点化を決めない。
- Triggerの発火、Actor、承認、AI統制および理解停止中のGuardは L3、Entity・履歴・保存・復元は L4/L8、表示は L5、操作/APIは L6、受入基準と測定は L7 が扱う。
