# L2-M2-S3: 完了条件の充足判定・正常完了可否規則

## 判定入力

論点ごとに、現在有効な完了条件集合、現スコープ、確認済み決定事項および未確認事項を照合する。判断に必要な入力が未評価・未記録なら、AIの推測で補わない。

完了条件の設定・条件なし例外は L2-M2-S1、条件変更・旧判定非流用は L2-M2-S2 を参照する。

## 条件ごとの判定

| 判定 | 意味 |
| --- | --- |
| 充足 | 条件が求める到達点を、現スコープ・確認済み決定事項・未確認事項との照合で満たすと確認できる。 |
| 未充足 | 条件が求める到達点をまだ満たさない、または条件に関係する未確認事項が残ると確認できる。 |
| 判断不能 | 充足か未充足かを確認する根拠が不足・曖昧であり、いずれとも確定できない。 |

判断不能は第8以降の永続状態語彙ではない。必要に応じて L2-M1 の要確認を参照できるが、この判定から状態変更・解除を行わない。

## 複数条件の集約

| 条件集合の状況 | 集約判定 |
| --- | --- |
| すべて充足 | 充足 |
| 一つ以上が未充足 | 未充足 |
| 未充足はなく、一つ以上が判断不能 | 判断不能 |

条件なしの論点は、L2-M2-S1 が認めた例外であっても自動的に充足としない。既知内容の確認が完了し、新たな検討対象がないことを意味上確認できる場合にだけ、充足として判定できる。それ以外は判断不能または正常完了不可とする。

## 論点単体の正常完了可否

論点単体は、現在有効な条件集合の集約判定が充足であり、現スコープ・確認済み決定事項・未確認事項との照合に矛盾がない場合に、正常完了可能とする。

| 状況 | 正常完了可否 |
| --- | --- |
| 集約判定が充足、照合に矛盾なし | 正常完了可能 |
| 集約判定が未充足 | 正常完了不可 |
| 集約判定が判断不能 | 正常完了不可 |
| 決定済みだが集約判定が充足でない、または照合に矛盾がある | 正常完了不可 |

決定済みの存在だけでは正常完了可能としない。正常完了可能／不可は抽象判定として L2-M3 の階層上の事後条件および L2-M4 の遷移Guardへ渡す。本書は状態変更、親復帰、現在地更新を行わない。

## 後続境界

- Trigger、状態遷移、禁止遷移、Guardの具体的な適用は L2-M4、親復帰・現在地・階層不変条件は L2-M3 が扱う。
- Actor、承認、AI統制、判断不能時の解除は L3、Entity・保存・履歴・Undo・復元は L4/L8、表示は L5、操作/APIは L6、製品試験・合格指標は L7 が扱う。
