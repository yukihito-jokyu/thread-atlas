# L2-M3-S2: 正常完了・親復帰・ルート完了の階層不変条件

## 目的

L2-M2-S3 が正常完了可能とした論点について、正常完了後の親子関係、論理上の現在地および復帰先が、L2-M3-S1 の共通不変条件を保つための事後条件を定める。

本書は論点単体の正常完了可能を構造上受け渡す条件だけを扱う。正常完了を実行する契機・許可・遷移、Actor、結果の保存、表示および操作方式は確定しない。

## 前提

- 完了対象は L2-M2-S3 により論点単体として正常完了可能である。
- 完了対象、親子関係、論理上の現在地および復帰先は L2-M3-S1 の共通不変条件を満たしている。
- 「正常完了可能」は実行済みの完了、現在地変更または親復帰を意味しない。

## 正常完了後の事後条件

| 場面 | 構造上の事後条件 | 導かないこと |
| --- | --- | --- |
| 親を持つ論点の正常完了 | 完了した論点は同じ親との親子関係を保ったまま参照可能である。親、完了した子、既存の兄弟および到達経路を失わない。 | 子論点の削除、別枝への移動、親子関係の付け替え |
| 親を持つ論点からの復帰 | 正常完了の直後に通常進行を継続する場合、論理上の現在地は完了対象の直接の親となる。復帰先と到達経路は、同じルート内で確認できる。 | 祖先・子孫・別枝への復帰、複数現在地 |
| 親の文脈への結果接続 | 完了した子の結果は、親論点との意味上の関連を失わず確認できる。結果があることだけから、親論点の完了、決定済み、または次論点への移動を導かない。 | 親の暗黙完了・決定、次論点の自動開始 |
| 未完了の子を持つ親 | 親が未完了の子を持つ事実だけでは、親を正常完了としない。親の通常完了を検討するには、既知の未完了子が構造上残っていないことを確認できなければならない。 | 未完了子を残した親の正常完了、子の暗黙完了 |
| ルート論点の正常完了 | ルートは親も復帰先も持たない。ルート完了後に架空の親、復帰先または新たな現在地を生成しない。完了したルートとその配下の構造は参照可能である。 | 架空の親復帰、別ルートへの移動、現在地の推測設定 |

## 未完了子を持つ親の条件

親の正常完了可否は、親自身についての L2-M2-S3 の判定に加え、既知の子論点の構造上の状態を確認して扱う。少なくとも未完了の子論点がある間は、親を通常の正常完了対象にしない。

親を正常完了対象として検討できるのは、全ての既知の子が正常完了済みである場合、または親の正常完了を妨げない状態として別Ownerが明示した場合だけとする。後者でも、子を暗黙に完了、削除、対象外または保留にせず、子の親子関係・到達経路・未完了である事実を失わない。どの状態がこの例外に該当するか、許可・Guardおよび遷移は状態組合せ・L2-M4・個別経路のOwnerが扱う。

## ルート完了の条件

ルート論点を正常完了として扱うには、ルート自身の論点単体の正常完了可能に加え、既知の未完了子を残さないことを確認できなければならない。ルート完了は親への復帰を伴わず、構造に別のルートや架空の通常進行先を追加しない。

ルート完了後にセッションをどのように扱うか、表示するか、保存するか、または新たな議論を開始するかは本書では定めない。

## 責務境界

- 論点単体の充足・未充足・判断不能と正常完了可能は L2-M2、状態語彙・組合せは L2-M1 を参照する。
- 正常完了・親復帰・ルート完了を起こすTrigger、許可・禁止、状態遷移およびGuardは L2-M4 が扱う。
- 中断・再訪・復元後再開は L2-M3-S3、保留・要確認・対象外・決定済みからの再開と提案論点化は L2-M3-S4 が扱う。未完了の親復帰を正常完了と混同しない。
- Actor・承認・AI統制は L3、論点・結果・親子関係・履歴・保存は L4/L8、提示方式は L5、操作/APIは L6、受入基準・測定は L7 が扱う。
