# L2-M1-S1: §10の7状態語彙の意味・適用境界

## 目的

Issue #1 §10で最低限として示された7語彙を、利用者が確認できる共通語彙として保持する。各語彙が何を表すか、どの論点・提案・確認場面に意味を持つか、および似た概念と何が異なるかを定める。

この文書は語彙辞書である。状態軸への配置、語彙どうしの併存・排他、遷移、完了条件の充足、Actorの権限、保存方式、表示方式は確定しない。

## 共通の適用範囲

- 7語彙は、議論に現れる論点、その扱い、または確認を要する内容を利用者が把握するための意味上のラベルである。会話メッセージ、操作、セッションそのものを表すラベルとしては用いない。
- いずれの語彙も、ユーザーの明示または確認可能な議論内容を根拠に解釈する。AIが発話を決定とみなしたり、曖昧な発話から決定を補ったりしない。
- §9の「却下」は判断の結果記録であり、§10の「対象外」と同義ではない。両者が同時に成立し得るかなどの関係は L2-M1-S3 が定める。
- FR-002およびFR-020の完了／未完了は、この7語彙とは別に論点の完了状況を表す。完了・未完了を第8以降の状態語彙として追加しない。

## 語彙辞書

| 語彙 | 意味 | 意味上の適用対象・条件 | 非適用境界と類似概念との差異 |
| --- | --- | --- | --- |
| 未着手 | 通常の議論としてまだ取り上げられていない論点であることを表す。 | 論点の議論開始前の扱いを確認するときに用いる。論点が構造上存在すること自体は否定しない。 | 保留のように後回しにすることが確認された意味は含まない。要確認のように内容の曖昧さを表す語でもない。 |
| 議論中 | 現在の通常進行で内容を検討している論点であることを表す。 | 通常進行で内容を検討し、背景・目的・未確認事項を確認しながら議論している論点に用いる。現在地との関係は定めない。 | 議論中であることだけから決定、完了、保留解除、次論点への移動を意味しない。現在地であること自体を意味せず、理解停止や中断を追加の永続状態として表すものでもない。 |
| 決定済み | 議論の結果として確認された決定事項があることを表す。 | 論点に関して確認済みの決定内容を参照するときに用いる。決定内容そのものやその記録形式はこの語彙と区別する。 | 論点が正常完了していること、以後の再確認や修正が不要であることを意味しない。決定済みと論点完了の関係は L2-M1-S3、完了可否は L2-M2 が扱う。 |
| 保留 | 現時点では扱いを確定せず、後で取り上げる余地を残すことが確認されていることを表す。 | 論点または扱うべき内容について、当面の判断・検討を先送りしたことを確認するときに用いる。 | 未着手とは異なり、後回しにする扱いが確認されている。対象外のように現スコープから除く意味や、決定済みのように結果が確定した意味は含まない。再開の可否・条件は定めない。 |
| 対象外 | 現在の議論スコープでは扱わない論点または提案であることを表す。 | 現スコープとの関係を確認するときに用いる。将来に別のスコープで扱う可能性までは否定しない。 | §9の却下という結果記録と同義ではない。保留のように現スコープ内で後回しにする意味でもなく、未着手のように開始前であることだけを表す語でもない。 |
| 新規提案 | 既存の通常論点とは区別して発見された、扱う候補であることを表す。 | AIが議論から提案を発見し、内容・派生元・理由・目的との関係・現スコープとの差異を確認可能にした場面に用いる。 | 新規提案であるだけでは、現スコープの論点、承認済みの論点、または決定事項にはならない。提案を扱う判断や論点化の条件は後続の L1-M2、L2-M4、L3 が扱う。 |
| 要確認 | 内容、意図、前提または扱いに曖昧さがあり、確認が必要であることを表す。 | ユーザーの意図や決定の有無を確認しなければ意味を確定できない論点・内容に用いる。 | 要確認であることから決定、保留、対象外、または新規提案を推定しない。AIが推測で解消したり、ユーザーの発話を決定として解釈したりしない。確認の進め方や解除条件は定めない。 |

## 語彙間で保持する区別

- 「新規提案」は候補の発見を表し、「未着手」は既存論点の議論開始前を表す。新規提案を暗黙に通常論点へ昇格させない。
- 「保留」は扱いを後回しにする確認済みの扱いであり、「対象外」は現スコープで扱わない扱いである。
- 「要確認」は意味を確定できないことを表し、「議論中」は通常進行で検討していることを表す。要確認だけから通常進行の再開や停止の扱いを決めない。
- 「決定済み」は決定事項の存在を表す。「却下」は結果記録であり、決定済み・対象外・論点完了との関係をこの文書で確定しない。

## 後続タスクへの引渡し

- L2-M1-S2 は、この7語彙を削除・弱化・無断改称せず、状態軸への配置だけを確定する。
- L2-M1-S3 は、語彙の併存・排他、却下と対象外、決定済みと論点完了の有効な関係だけを確定する。
- L2-M2 は完了条件の意味・充足・正常完了可否を、L2-M4 は Trigger、遷移元・先、解除操作を扱う。
- L3 は Actor、承認、理解停止のGuardを、L4/L8 は保存・復元を、L5 は表示方式を、L6 は操作/APIを扱う。

## 要件対応

- Issue #1 §9〜10: §10の7語彙を利用者が確認できる語彙として保持し、§9の却下を対象外と混同しない。
- FR-002、FR-008〜FR-012、FR-015、FR-020: 議論マップ・論点の扱い・決定事項・完了／未完了・復元に関わる語彙を、状態軸・遷移・保存設計を追加せずに区別する。
- AR-005〜AR-007: 決定、対象外、提案、曖昧さをAIの推測で確定しないための意味上の境界を保持する。
