# L2-M4-S4: 横断Guard・禁止遷移・到達可能性監査

## 目的

L2-M4-S1〜S3 の許可遷移を横断し、不正な状態組合せ、正常完了の誤実行、未承認提案の昇格、状態や構造を迂回した通常進行、および理解停止中の議論進行を防ぐ抽象Guardを定める。

本書は許可遷移を新設・変更しない。各表のTrigger、Actor、承認主体、AI統制、理解停止Guardの成立・解除、Entity・履歴、表示、操作および試験は、それぞれのOwnerに残す。

## 横断前提

- すべての遷移の起点・遷移先は、L2-M1-S1〜S3 の7語彙、軸内排他、対象類型別の有効組合せおよび不正組合せを満たす。未設定値を推測で補わない。
- 各遷移の前後では、L2-M3-S1 の単一ルート、親の一意性、循環・孤立禁止、現在地の一意性、到達経路および復帰先の不変条件を満たす。
- 完了・未完了、理解停止および中断を第8以降の永続状態にしない。完了可否は L2-M2、理解停止の成立・維持・解除は L3、中断は L2-M4-S2 が扱う経路として参照する。
- 本書のGuardは意味上の禁止条件である。誰が実行・承認するか、どの時点で発火するか、AIの許可・禁止動作をどのように統制するかは L3 が定める。

## 責務境界

- 本書は横断禁止条件と到達可能性の監査だけを所有する。個別の許可遷移、起点、遷移先および現在地効果は L2-M4-S1〜S3 が所有する。
- 状態語彙・有効組合せは L2-M1、完了条件と正常完了可能は L2-M2、階層・現在地・復帰先の不変条件は L2-M3 が所有する。
- Actor、承認、AI統制、理解停止Guardの成立・維持・解除は L3、Entity・履歴・保存・復元は L4/L8、表示は L5、操作/APIは L6、受入基準・測定は L7 が所有する。
