# L2-M3-S4: 状態・提案起点の再活性化における階層不変条件

## 目的

保留、要確認、対象外または決定済みの論点を再び扱う場合と、必要な承認が成立した新規提案を論点として扱う場合に、元の関係と有効な到達経路を失わず、孤立・循環・重複現在地・不明な復帰先を生じさせない構造条件を定める。

本書は再活性化または論点化の後に成立する構造だけを定める。Trigger、許可・禁止遷移、Guard、Actor・承認、Entity同一性、履歴、表示および操作方式は確定しない。

## 共通前提

- L2-M3-S1 の単一ルート、親の一意性、循環・孤立禁止、現在地一意、到達経路および復帰先の共通不変条件を満たす。
- L2-M1 の状態語彙・有効組合せを参照し、再活性化を根拠に状態値、決定、完了または現在地を暗黙に変更しない。
- 再活性化の対象と、その元の階層・決定・提案由来との意味上の関係を確認できる。
- 通常進行へ接続する構造条件は、L2-M4 が許可した明示的な遷移の後に限り適用する。本書だけで保留・要確認・対象外・決定済みの解除、通常進行の開始または現在地変更を導かない。

## 状態起点の再活性化

| 起点 | 再び通常進行を扱う場合に保つ構造条件 | 導かないこと |
| --- | --- | --- |
| 保留 | 対象論点は元のルート、親子関係、到達経路および復帰先との対応を保つ。通常進行の現在地にする場合は対象論点一つだけとする。 | 保留の解除、完了、決定の変更、別枝への移動 |
| 要確認 | 対象論点の要確認であった文脈と親子関係を失わず、再び扱う場合も同じルートから到達できる。 | 要確認の解除、決定・完了の推測、現在地の重複 |
| 対象外 | 再対象化される場合でも、元の対象外判断と元の階層関係を確認できる。通常進行へ接続する場合は有効な親・復帰先・到達経路を持つ。 | 対象外の暗黙解除、元の判断の消去、別ルートへの混入 |
| 決定済み | 再確認・修正のため再び扱う場合、元の決定と対象論点・親子関係との意味上の関連を失わない。 | 決定の破棄、論点完了の取消、親復帰の実行 |

## 新規提案の論点化

必要な承認が成立した新規提案を通常の論点として扱う場合、提案由来であること、派生元、親、復帰先および通常進行への接続を意味上追跡できるものとする。

| 条件 | 不変条件 |
| --- | --- |
| 派生元 | 提案の派生元と、論点化後の論点との意味上の対応を失わない。提案由来を既存論点由来へ読み替えない。 |
| 親とルート | 論点化後の論点は同じルート内の既存の親を一つだけ持つ。親を持たない新しいルート、複数親、循環または孤立を作らない。 |
| 現在地 | 通常進行を開始する場合、論点化した対象だけを論理上の現在地とする。承認前の通常進行を並行して自動進行させない。 |
| 復帰先 | 論点化した対象の復帰先は同じルート内の親であり、提案判断前に進行していた論点との接続を失わない。 |

提案の発見、「今議論する／後で議論する／今回は対象外」の判断と承認主体は L1-M2 および L3 が扱う。本書は未承認提案を論点化せず、承認の成立を判定しない。

## 経路の確認

再活性化または論点化後に通常進行へ接続する前に、対象からルートまでの到達経路、論理上の現在地、親、復帰先および対象の由来を確認できるものとする。これらが確認できない場合、別の論点への推測接続、現在地の重複、親子関係の補正を行わない。

## 責務境界

- 状態遷移、再対象化・再開・論点化のTrigger、許可・禁止、Guard、現在地変更の実行は L2-M4 が扱う。
- 正常完了・親復帰・ルート完了は L2-M3-S2、中断・再訪・復元後再開は L2-M3-S3 が扱う。
- Actor、提案承認、AI統制は L3、提案と論点のEntity関係、履歴・保存・復元は L4/L8、表示は L5、操作/APIは L6、受入基準・測定は L7 が扱う。
