# L2-M2-S2: 完了条件の変更・再判定規則

## 変更が必要になる意味上の契機

通常論点の完了条件は、次のいずれかが意味上変化した場合に見直しを必要とする。

| 契機 | 見直す理由 |
| --- | --- |
| 論点の目的または決めたいことの変化 | 何を到達点とするかが変わり、従前の条件だけでは終了を説明できない。 |
| 現スコープの変化 | 扱う範囲が変わり、条件が対象とする内容を再照合する必要がある。 |
| 未確認事項の追加・解消・意味上の変化 | 残る確認事項と終了の関係が変わる。 |
| 確認済み決定事項の追加・修正・撤回 | 条件を評価する根拠が変わる。 |
| 条件なし例外の前提の変化 | 新たな検討対象が生じた場合、条件なしの扱いを維持できない。 |

変更するかのActor、AIが自動で変更できるか、承認方法は L3 が扱う。この表は変更後に必要な意味上の見直しだけを定める。

## 有効期間と再判定

- 完了条件は、設定または直近の変更後から、上表の契機による意味上の変化が確認されるまで有効とする。
- 意味上の変化が確認された時点で、旧条件に対する充足・未充足・判断不能の判定を現在の条件へ流用しない。
- 変更後の条件集合について、現スコープ、確認済み決定事項、未確認事項を改めて照合し、再判定を要求する。
- 再判定の結果、集約方法、正常完了可否は L2-M2-S3 が扱う。変更自体から完了、未完了、決定済み、現在地変更または親復帰を導かない。

## 正常完了後の扱い

正常完了が成立した論点の完了条件を直接変更しない。再び扱う必要が生じた場合は、再開可否・階層上の現在地と復帰先を L2-M3、許可遷移・Guardを L2-M4 へ渡す。正常完了後であることを理由に旧条件を復活させたり、新しい条件を暗黙に設定したりしない。

## 後続境界

- 条件の初期入力・必須性・条件なし例外は L2-M2-S1、現在条件集合の充足判定・正常完了可否は L2-M2-S3 が扱う。
- 状態遷移、変更の操作、Guardは L2-M4、Actor・承認・AI統制は L3、履歴・旧版・Undo・復元単位は L4、永続化は L8 が扱う。
- 表示、API、試験方法および数値指標はそれぞれ L5、L6、L7 が扱う。
